# THROWAWAY — 重构交互原型

当前方向已由用户确认：A 作为资料库主界面，C 作为专注查看；B 的检索能力并入
查看流程，不再保留独立方案。新增悬浮卡片，统一通过底部三段玻璃切换器进入。
本轮是该方向的交互原型，尚未接入正式应用或原生桌面窗口。

后续正式接线位于 `components/library/WorkspaceModes.tsx`、
`components/asset/AssetCardPanel.tsx` 和 `src/main/asset-card/`。
本目录保留为设计参考，明确排除于生产源码上下文覆盖；正式代码不导入本目录。

运行：仓库根执行 `node scripts/preview-refactor-prototype.mjs`，打开输出的
loopback 地址。单独 Vite 开发入口使用既有 HashRouter 路径，不加载正式 App、
stores 或 Electron，不进入现有应用构建入口。

| 模式 | URL 参数 | 功能 |
| --- | --- | --- |
| 资料库 | `mode=library` | 组织侧栏、搜索筛选、素材网格与检查器 |
| 专注查看 | `mode=focus` | 大图预览、搜索、底部缩略带与检查器 |
| 悬浮卡片 | `mode=card` | 可拖动的卡片、图片、基础信息、工具、AI 编辑与反推草稿 |

三个模式共享素材、选中项、筛选、设置草稿；卡片草稿按素材保留。
旧 `variant=A` 映射到资料库，旧 `variant=B/C` 映射到专注查看。
从采集/工具区域点击模式会回到素材工作区。设置采用同一套分类浮层。
模式切换器内的左右键及 Home/End 可切换，输入框和素材导航不会被全局抢键。
点击右下角“交互状态”检查状态并演示减少动态效果。

## 玻璃与动效

- 底部圆角矩形使用半透明材料、背景模糊、亮边、内阴影及反光；选中块通过
  spring 位置过渡和高光扫过形成流动感。此处为浏览器材质模拟，不声称原生效果。
- 0–190ms：旧画面逐渐增加 Gaussian blur（最大 22px）、降饱和与淡出。
- 190–460ms：在毛玻璃背景上显示目标模式名称与图标。
- 460–960ms：替换内容并逐渐恢复清晰，标题渐隐；静止素材不保留模糊。
- 快速切换取消旧计时，只收敛到最后请求；切换中画布 inert，底部切换器可响应。
- 系统或演示的减少动态效果使用约 130ms 淡入淡出，不做大范围模糊、缩放或标题
  停留。减少透明度/增强对比度时使用更实的材料。

## 悬浮卡片

参考用户提供的圆角图像窗口结构：标题栏 → 图片 → 基础信息 → AI/工具 →
提示词反推。参考图片仅用于目视设计，没有复制进仓库或发送外部服务。
标题栏可拖动，图钉仅固定浏览器内卡片位置；放大进入专注查看，关闭回资料库。
示例调色、旋转和固定暖色 AI 编辑预览可保留为内存副本，原素材不被覆盖。
提示词演示生成预设文案，允许编辑和复制；草稿跨模式、按素材保留。

边界：16 张初始样张由 CSS 构成，没有外部图片、真实私有素材或持久化。
AI 编辑/反推按钮明确显示演示性质，未运行模型；没有模拟下载进度或成功记录。
桌面背景是浏览器内构成，不是用户桌面截图。原生置顶、跨应用显示、多屏移动、
真实图像编辑/推理、IPC 生命周期及实际数据保护须在正式实现中单独接线验证。
后端恢复继续按[功能恢复清单](../../../../docs/product/REFACTOR-FUNCTION-MAP-20260911.md)
推进，本原型不构成恢复证明。
