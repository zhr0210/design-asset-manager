# 本地中英文图文检索

颜色占比和近色条件复用 Host 确定性预览测量，并在语义候选截取前过滤。文字来源只限制文字命中，画面向量来源分别解释；切换查找方式保留颜色及文字来源条件。整页结果在最后一个异步步骤后再次核对，防止填充后页期间旧素材已回收却仍返回。

用户从“AI 与模型 → 本地模型与 OCR”获取并验证独立 SigLIP2，从素材工作区选择文字、画面含义、混合或单图找相似。安装不自动启用，向量生成必须明确选择所选素材或全库；暂停和重开后必须明确恢复。

2026-10-08 D 补充：MP4 不计入图片覆盖、生成、复用或派生索引重建，不以首帧代表整段视频；库内视频不能作为以图示例。旧持久记录不删除，视频名称/人工文字的词法与混合文字命中仍可使用，视频/帧由工作模式管理。真实公开视频 Host 回归与既有三图语义回归覆盖这个相邻边界。

`retrieval-model-library.ts` 使用 ModelScope 境内固定提交及完整文件哈希，复用归属明确的可恢复传输。逐跳拒绝 HF、hf-mirror 和国际 CDN，不执行仓库代码。许可为 Apache-2.0。模型库存校验在加载前核对受支持的结构，`retrieval-runtime.ts` 使用用户明确选择的可信 Python 环境和 App 自有私有 stdio Worker。实际路径为 CPU float32、768 维、L2/cosine；原语言 64 token 上限，超限明确拒绝，不截断或翻译输入。真实中英文/混合与图像资格分别记录，不把下载完整或纯色弱项当语言质量证明。

运行器通过唯一 Host Governor 准入，与 Qwen、OCR、查询和索引维护共享资源。活跃/准备中的任务受保护；取消、闲置回收或压力调节仅在实际进程 close 后释放驻留，未确认退出保持占用。已验证、文件/环境未变化且未撤信任时继续离线可用。

`asset-retrieval-store.ts` 把 canonical vectors、任务及空间写入当前库 `.dam` 的独立 SQLite，并以归属 registry 绑定物理文件。派生 flat cosine 索引可以重建，不成为原件、人工内容或持久向量的权威。空间参与每次向量读写；代际、输入视图与生命周期在返回结果前复核。查询最多 200 语义候选，精确文字命中独立保留，混合使用 RRF 排名并展示具体依据；分页 cursor 有界、有所有者及期限，文件夹硬条件不得被语义排序扩大。

明确准备兼容的已有向量时，仅修复它在派生索引中的投影；保留 canonical 原字节、输入摘要和实际生成时间，不以复用时间冒充新模型执行。缺失或内容/视图变化时才实际生成新证据。

`retrieval-runner-archive.ts` 只保存已实际资格绑定的 App 自有 stock Worker 快照，逐脚本/环境/制品指纹检查。新空间准备不破坏旧空间，已准备空间可以明确切换/回退。撤信任清执行证明，保留已保存向量。外部示例由 `query-file-grants.ts` 限定为用户正式选择的一张 PNG/JPEG/WebP，不扩大到任意路径、隐式收录或外发。

聚焦检查：`retrieval-model-workspace`、`retrieval-package-format`、`retrieval-runner-archive`、`asset-retrieval-host` 和 `query-file-grants`。正式 Windows Browser 的指定公开样本、中英/混合/跨语言与以图命中、暂停恢复、重开和空间回退分列在本轮 PROGRESS；损坏实验仅使用可恢复副本。当前限制、未验收项与父级完成状态以 TASK/CURRENT-STATE 为准，不以内部检查代替用户结果。
