# Host 素材检索与颜色查询

普通素材搜索由 `asset-search-index.ts` 查询有界分页。标题/文件名、确认标签与别名、AI 建议、当前描述、OCR 和反推可以分别限定；人工描述覆盖旧 AI 描述。命中依据通过共享 `asset-discovery.workflow.ts` 展示，不把建议写成已确认标签。

文字 n-gram、排序快照和颜色直方图都是当前库 `.dam` 内可重建派生数据，原件、人工内容及分析证据仍由素材库拥有。原主库 schema 不为颜色改变。颜色测量复用详情的 128 像素 sRGB、4-bit alpha 加权采样；搜索使用完整直方图而非五个展示色块。近色为 D65 Lab / CIE76，比例分母是可见像素权重，透明权重为零。结果明确是预览抽样估计。

首次查询按候选分批测量并缓存精确内容修订/预览/算法版本；确定性解码失败显示不可测，维护重建允许重试。文件、权限、准入和撤权失败直接返回，不持久冒充颜色结果。准备和查询复用唯一资源账本；分页只读同视图缓存、核对当前权限。所有累积命中在最后一个 await 之后再次同步核对生命周期、文件夹和文字硬条件。

颜色、标签与文件夹是图文查询的硬条件，在语义 Top-200 前筛选；当前返回前再次复核。后台通知只刷新已展示行，保留快照分页、选择和滚动；明确重新查询才重新确定成员与排名。请求取消或失败保留已接受快照，后续分页仍可继续。新查询和切库撤销当前实际派发，旧响应不能覆盖新代次。

schema 备份由 Host 维护边界排空读者后，临时移除搜索和后台计数自己的主连接 TEMP 触发器；备份的空 TEMP/唯一 main 校验保持。维护中的核对只读，结束后重新接入追踪，并补同步停跟踪期间的变更。查询快照不因此清空；不需要备份的普通权限更新保持现有索引就绪。

聚焦回归：`asset-search-host`、`asset-retrieval-host`、`asset-discovery-workflow`、`measure-preview-colors` 和 `search-schema-backup.integration`。实际用户证据见 TASK / CURRENT-STATE 和 C 交接；小型公开副本不代表十万素材基准或 Native 专项验收。
