## 三个缺陷及修复

1. `WorkspaceClient.retrieval.cancel` 原先把完整查询作为 scope 展开，多出 query/mode 等字段，正式 Host 的三字段校验拒绝取消。现在只发 `libraryIdentity/generation/id`。契约测试先红后绿，Host 单槽、撤权、取消及释放回归通过。查询取消终态仍显示“正在取消”、新请求沿用旧提示和去抖窗口未清 timer 一并修复：新查询清提示，结束后明确取消终态；未派发时清 timer，旧 epoch 错误不能污染新请求。
2. 工作集搜索误用当前画布页作为全库：改为复用正式 Host 分页查询，并按成员 ID 窄读取。实际红例候选 0，新产物在不改变画布第一页时候选 1；保存、草稿及库代次保护保留。
3. 文件夹控制条与顶栏同层且后置，`编辑文件夹` 覆盖 AI 按钮中心。右侧留位 100 → 220px；原真实点击错误与 DOM 命中保留，修订后宽屏及 1268×826 命中/真实导航通过。

主 Agent 对这些新增差异进行了同会话规范/规格自审；不是独立人员对整个产品的新审查。必要 typecheck/build、8 个受影响回归文件与新只读 fixtures 已执行，未降低 Host 验证或伪造运行资格。
