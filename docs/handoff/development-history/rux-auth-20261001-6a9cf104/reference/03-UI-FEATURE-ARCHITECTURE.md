# 目标 UI 与功能层级：一个功能只有一个主要归属

本章是建议的目标设计，需随执行计划批准后落地；不是当前交付状态。保留 `DESIGN.md` 的 Gallery & Glass、素材四视图和既有原生窗口风格，不用新的管理后台替换素材工作台。

## 1. 顶层结构

```text
应用全局层（未开库／开库／关库／开库失败都可见）
├─ 素材工作区
│  ├─ 全部素材
│  ├─ 文件夹：普通 / AI 动态分类 / 色板
│  ├─ 工作模式：工作集 / 原生参考窗口
│  └─ 回收站
├─ AI 与模型
│  ├─ 连接与账号（默认落点）
│  ├─ 任务用哪个模型
│  ├─ 本地模型与 OCR 环境
│  ├─ 后台分析与资源
│  └─ 诊断（高级；仅当前有效能力）
├─ 任务中心：下载 / AI分析（仅展示已有任务与控制，不凭空实现新队列）
├─ 设置：外观 / 快捷键 / 普通偏好 / 高级维护
└─ 帮助与关于：当前构建、操作手册、脱敏诊断导出
```

“AI 与模型”是明确可见的固定入口，不只藏在省略号中；新用户第一次启动无需创建资料库即可配置账号。资料库四图标保持原语义，新增全局入口不能挤掉原素材动作。建议将全局入口放在已有固定导航区／顶部工具区中稳定的位置，采用可见“AI 与模型”标签；窄窗口可使用图标＋短标签，但不能只有无法识别的星形图标或只靠 aria-label。

## 2. 路由与页面所有权

路由名称是内部目标建议；只有一个 registry 声明它们。禁止每个 Shell 手写一份跳转表。

| 目标 | 建议路径 | 数据归属 | 普通入口 | 兼容处理 |
|---|---|---|---|---|
| 素材四视图 | `/library`＋现有视图状态 | 当前库 | 原四图标 | 不重写现有素材身份和历史 |
| 连接与账号 | `/ai/connections` | App | 全局 AI 与模型；设置摘要；素材配置 CTA | `/ai-console` 默认转此；旧链接不404 |
| 任务模型 | `/ai/task-models` | App，执行仍库授权 | AI 子导航 | 旧任务分配按钮迁入，保留 aiTaskModels 数据 |
| 本地模型／OCR | `/ai/local-models` | App安装状态＋Runtime | AI 子导航 | `/model-library` 转相应功能，不混成API模型目录 |
| 后台／资源 | `/ai/background` | App预算与库策略分区 | AI 子导航；任务中心“管理规则” | 无库时库策略解释不可用，不阻止App配置 |
| 诊断 | `/ai/diagnostics` | 当前有效服务的只读状态 | AI高级子导航 | 原控制台有价值的状态逐项迁移 |
| 下载与已有分析任务 | `/tasks` | 跨域投影，操作回原 owner | 全局任务入口 | `/downloads`保留别名到下载tab |
| 标签管理 | 保留 `/tag-manager` | 当前库 | 资料库组织入口 | 不是账号配置页子项 |
| Eagle／旧库 | 先保留原路径 | 专属权威边界 | 资料库管理／导入恢复 | 不能因名字legacy直接删除 |
| 设置 | `/settings` | App偏好 | 固定齿轮 | `section=ai`只导航到统一AI入口或薄摘要 |

注册项至少包含：id、可见标签、route、归属、需要库与否、可见条件、不可执行原因、父级与返回规则。权限仍由 Main 决定；registry 只提供展示和导航，不能成为授权凭据。

默认进入AI连接页不是“默认自动刷新全部模型目录”。初次页面读取只取现有安全配置及状态。网络探测、登录、图像验证是分别显式动作。

## 3. 旧入口逐一处理，不留第二套编辑器

| 现有位置 | 新处理 | 必须保护 |
|---|---|---|
| `LibraryCanvas`顶部AI按钮 | 使用registry生成可见标签和目标 | 全部/文件夹/工作模式/回收站均一致 |
| `LibraryCanvas.menuItems`与`GlobalNavigationMenu` | 共用全局目的地；库内动作分组保留 | 不能混淆“新建文件夹”和“打开AI账号” |
| `WorkspaceRail` | 调整全局入口一致性；库内四视图不复制一遍 | 不恢复用户已否定的宽树形导航 |
| `Library.tsx`的onConfigure | 统一去连接或指定任务配置页，携带安全returnContext | 素材选择、文件夹、搜索、滚动位置、草稿 |
| `AppShell`的configureAi返回 | 同一目标，不再跳旧backend form | 原生卡片返回只含已有受控身份 |
| `Settings.tsx`的AiBackendSettingsPanel | 用摘要＋“管理AI连接”替代；不保留第二个CRUD | 现有连接ID、key引用、revision、用户模型配置 |
| AiConsole旧“外部服务连接”块 | 迁入唯一连接页或删除重复界面 | 旧连接仍可只读/编辑；原transport兼容保留 |
| 旧PromptTemplate编辑块 | 核对实际消费者后迁“高级任务配方”或只读旧记录 | 不丢用户自定义模板，不声称旧模板影响新配方 |
| `PiConnectionsPanel` | 拆为可复用连接页/表单/账号状态组件，不改变底层身份 | 不在各页创建新service或独立账号缓存 |
| `AiServiceAcceptancePanel` | 工程验收移诊断高级区域；普通模型测试单独简化呈现 | 不把工程预算表强迫给普通用户填写 |
| `AiConsolePage` | 功能迁走后改薄路由兼容，最后退役旧容器 | 不再挂载旧轮询/安装订阅 |

## 4. 连接与账号的正常模式

默认入口按用户任务呈现，而非SDK参数表：

- “连接本机服务”：服务地址、模型、是否需要密钥；说明回环服务也可能是代理，不能伪称绝不外发。
- “使用模型 API”：选提供方、填入专用安全密钥、选模型；原生适配与兼容协议由系统规则选择。
- “使用 ChatGPT 账号”：先说明登录作用，再启动受控流程；成功后展示身份/权限状态，模型验证另行确认。

只在高级编辑中显示自定义 endpoint、协议覆盖、特殊兼容参数；Pi是实现技术，不是普通用户需要选择的产品概念。`legacy`切换不放在常用表单里，更不能通过切换绕过Provider政策。未支持的厂商保留明确状态，不能保存后才在每次执行中含糊失败。

每条连接卡片分开显示：
1. 配置：已保存/有未保存修改。
2. 账号或密钥：未配置/已保存/需要重新登录/安全存储不可用。
3. 权限：身份已验证/计划使用未授权/账号可用于指定动作。
4. 模型：未选择/目录声明/生成输入验证通过或失败。
5. 当前操作：等待浏览器/交换中/验证中/保存中/已完成/失败及操作建议。

这些维度不能合成一个绿色“已连接”。目录有模型也不能证明实际账号获准调用它。

保存、登录、目录请求、模型验证必须使用已提交配置或明确绑定的编辑快照；未保存地址不能携带旧账号密钥去探测。dirty状态下操作应提示先保存，不在背后改用旧地址。

## 5. 任务配置与素材操作

“任务用哪个模型”只放默认路由和模型选择。标签、描述、提示词反推各自清楚；OCR仍走专用环境。未独立实现的描述任务要明确显示现状，不能为匹配新页面外观而凭空标成可用。

素材详情保留当前 DESIGN 顺序：预览、颜色、基本元信息、人工标签/描述、AI建议/来源、分析动作、OCR、工作集/素材工具。不要把账户管理、安装脚本、CPU探测塞在每张素材的详情里。无可用模型时提供“配置此任务的模型”CTA，完成后返回原位置。

“一键基础分析”的最终产品目标仍保留；本批不顺带实现尚未落地的自动caption或全能力队列。用户手动编辑永远独立于AI重跑。

## 6. 任务中心与资源页面的限界

任务中心复用已有下载、标签批次和后台OCR投影，按来源明确显示；如果暂缺统一取消接口，转到所属功能完成操作，不能实现一个绕过Host的“取消所有”。不能把手动运行、库内计划、真实执行、等待资格、UNKNOWN统一成“运行中”。

资源页将“用户偏好”“实测遥测”“已批准执行包络”“当前实际占用”分别显示。没有生产资格的滑块不得标为已控制显存。B01开关仍只生成计划，执行许可独立；本批不解除qualification=null。

## 7. 所有页面状态都要有明确路径

| 状态 | 允许且必须可达 | 明确不可用的内容 |
|---|---|---|
| 未开库／首次启动 | AI账号、模型配置、设置、帮助、创建/打开库 | 素材搜索/分析/库内组织，说明需要库 |
| 已开空库 | 以上＋导入 | 无选择的素材动作，说明先添加/选择 |
| 已开有素材 | 当前范围内完整功能 | 不受支持的格式/资格说明 |
| 关库 | App配置仍可用、重新打开 | 旧库回执/旧预览不能继续授权 |
| 开库失败／恢复状态 | 诊断、另选库、App账号配置仍可用 | 不把Host恢复状态伪装成ready，不释放UNKNOWN |
| Runtime缺失 | 基础管理与账户配置 | 等待实际执行依赖；不自动安装 |
| 断网／凭据失效 | 本地管理、查看旧证据、重试登录入口 | 不清空结果，不静默切API计费 |

当前账户登录不应被普通页面离开取消；当前库变更只撤销库内容执行范围。完整应用退出必须停止自有认证listener/Worker，且不因Promise结束冒称子进程已退出。

## 8. 可量化的UI门槛（目标，不是已测成绩）

- 从首次普通启动可见界面到“连接与账号”最多两次可见点击，不输入路由、不打开调试器。
- 未开库、开库、关库、开库失败四状态都有同名同义的全局入口。
- 同一连接只有一个主要编辑实现，其他位置只导航或只读摘要。
- 所有“配置AI”动作指向同一目标体系，并可回原素材上下文。
- 默认AI主页不呈现永久禁用的模型安装/GPU清理按钮，不每5秒调用已禁用IPC。
- 1024和1440宽度、明暗、键盘Tab/Enter/Escape均验证；按钮不处于drag区，不被资料库弹层盖住。
- 登录失败必须告诉用户失败阶段和安全下一步；浏览器收到回调不是应用认证成功。
- 新页面不能牺牲已有工作集、标签、笔记、OCR修订和回收站功能。通过共享组件继续保持既有视觉基础。
