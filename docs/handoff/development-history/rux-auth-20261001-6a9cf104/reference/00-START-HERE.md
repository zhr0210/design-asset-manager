# DAM 仓库整合、界面路径与 Pi 认证修复执行包

版本：1.0 · 2026-10-01 · 状态：**PROPOSED，尚未实施**。
现场：`<DAM_WORKSPACE>`，macOS。
本包依据本轮远程只读源码审阅、统计、静态依赖分析、一项本机合成认证反例和官方资料编写，不依据历史“通过”推定当前产品可用。

## 本轮目标

把“代码里有功能”变成“用户从普通启动界面找得到、用得完、能理解结果”，同时收敛重复配置、旧控制台和不可达代码。修复 ChatGPT 登录的可诊断性与应用侧闭环；不为了显示成功而降低认证或资料库保护。

本包不是候选代码补丁，不会自动修改仓库、删除文件、登录账号或开启后续 DP 阶段。

1. [现场审阅](01-CURRENT-AUDIT.md)：已证实、待复现和未知分别列出。

3. [目标 UI／功能归属](03-UI-FEATURE-ARCHITECTURE.md)、[安全清理](04-REPOSITORY-CLEANUP.md)、[Pi 认证修复](05-PI-AUTH-REPAIR.md)。
4. [Computer Use 验收](06-COMPUTER-USE-ACCEPTANCE.md)：交互验收不得通过代码跳转或调用 IPC。

## 本包与旧计划的关系

本次用户反馈成为近期优先级：先完成导航、账户、清理和验收方法整合，再回到 DP02–DP10。不是废止独立描述、资源调度、语义搜索、设计助手或移动端目标。旧 DP01、Pi 收尾与 OCR 报告保留为限定历史证据；不重写它们，也不按旧队列自动继续。

2026-10-01 的首页修复已经存在：本计划必须在其上核实和统一，不能假设代码仍与 9 月 30 日打包快照相同。旧 Remote 候选中的 OCR 修复已被 DP01 报告记录为落地，**不得再次盲套旧候选包**。

## 唯一真相分工

- 用户需求和获批计划：规定做什么、不能破坏什么。
- 当前源码与运行构建：证明实际上是什么。
- 单元／SDK／Host 测试：证明限定内部契约。
- Computer Use 轨迹：证明人能从可见入口完成任务。
- 实际账号验收：证明指定账号／设备的真实连接；不能用假令牌替代。
- `TASK.md` 是当前活动指针；`LATEST.json` 是最近登记的完成记录，只有重新核验后才能称“对应当前源码”。

## 本次审阅没有做什么

没有编辑、删除、移动或暂存业务代码；没有读取真实凭据、浏览器 Cookie、账号令牌、用户素材库；没有启动模型或请求厂商推理；没有执行 Computer Use 用户验收。Remote 提供了文件／终端能力，但本次未获得并执行专门的屏幕操作轨迹。唯一认证运行是自有 loopback 的合成拒绝回调，厂商网络调用为零，已取消并关闭自有尝试。

本包是详细行动计划，不是保证所有错误都可由一次重构消除。未知项必须按阶段取证，不得编造登录失败根因或“全部可用”。
