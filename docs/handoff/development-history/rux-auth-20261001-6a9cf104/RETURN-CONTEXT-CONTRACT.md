LibraryCanvas 使用暂存的 canvas-session，保存 history/cursor/density/quick/category/scrollTop。read 只接受同一已验证 Host scope；换库、close/reset 会清除。仅内存，不写查询永久档案，不保存原件路径、账号URL或凭据。选择和草稿保留由现有 store/Host 持有，返回后重新按当前素材与会话核对；不恢复失效权限。

证据：r02-context 的同scope/不同scope/关闭 1 组，r08-canvas-formal 的草稿离开/返回、close/reopen/restart。后者是正式组合 integration，不是 CU。U08/U09 的全部屏幕与原生卡片链路仍 BLOCKED。
