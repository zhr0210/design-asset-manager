## 01 · 给接手同事的产品摘要

这是面向设计师、剪辑师、编导等视觉创作者的本地优先素材工作台。主工作流是：**收进素材 → 理解与整理 → 搜索找回 → 查看与比较 → 安全复用**。AI 用来补充标签、描述、文字和检索线索，不应成为打开素材库和查找素材的前提。

现在可以围绕本地图片库的创建、复制导入、浏览、关键词搜索、手动标签、描述、回收站与恢复设计基础闭环。网页、Eagle、AI、模型和维护已有页面或模块，但完成度不同，不能把按钮存在理解为功能已交付。

前期记录已确认的界面方向是三种模式：**资料库为主界面、专注查看承接大图与检索、悬浮卡片服务于跨应用参考**。旧 A 方案对应资料库，C 对应专注查看，B 已并入查看流程，不再需要设计独立 B 页面。底部三模式切换采用液态玻璃与“模糊 → 模式名 → 清晰”的过渡。

此次源码发现两处比旧文档更新的事实：正式 Library 已调用三模式组件，原生悬浮卡片已有 Main/Preload/Renderer 接线；AI 服务配置、连接检查和模型列表的五个通道已独立注册。它们在本报告中列为“接线”，不沿用旧文档“只有原型/全部禁用”的判断，也不声称新增代码已通过真实桌面验收。

### 交接中的状态标识

| 标识 | 含义 | 设计与开发处理方式 |
| --- | --- | --- |
| 接线 | 当前路由、组件及直接调用链存在；仅浏览行为可由 Renderer 独立完成 | 可以按现有行为设计，但仍需联调；不代表发布验收通过 |
| 受限 | 页面或模块存在，但当前组合禁用、缺条件或未形成完整闭环 | 保留功能需求，设计不可用原因与下一步；不要展示虚假的执行成功 |
| 原型 | 隔离合成数据、演示或临时内存行为 | 用于讨论布局和手感，不接到真实业务成功状态 |
| 目标 | 已记录的产品方向或本报告明确提出的建议，尚未证明当前实现 | 独立标注待设计/待实现；不是本次新增实施授权 |
| 待核验 | 尚未完成当前路径的实际运行或调用证据不足 | 不能归为已完成，也不能据此删除需求 |

本报告的功能表中，“交互/验收要求”是交付给同事的设计要求；只有“当前状态”列描述现状。现有代码未必满足每条验收要求。

### 六条必须保留的产品语义

1. 默认导入是复制；外部来源文件不移动、不覆盖、不删除。
2. 本地受管库、Eagle 连接库、旧 DAM 只读库是三种不同工作区，必须显示当前归属与可用权限。
3. 候选、下载记录、已入库素材分别表示三个阶段；互相不能用“已保存”代替。
4. AI 建议与用户确认分开；重新分析不能覆盖用户描述、确认标签或已提交编辑。
5. 保存 AI 服务地址不代表允许上传素材；外发必须在具体动作或批次中披露并确认。
6. 原件、受控预览、派生副本和兼容导出必须明确区分；100% 缩放不证明展示的是原件。

| 页面 | 当前路由 | 当前入口/职责 | 交接后的建议归属 |

| 网站来源 | `/sites` | 网站配置与登录状态 | 采集下的网站与账号 |
| 来源发现 | `/search` | 搜索配置的网站，获取外部图片结果 | 采集下的来源搜索 |

| 模型库 | `/model-library` | 发布目录、模型存储状态与选择审阅 | 设置 → AI → 模型库子页 |
| AI 控制台 | `/ai-console` | 总览、模型、服务、运行时、提示词、日志 | 设置 → AI → 高级管理 |

| 重构原型 | 独立开发入口 | 三模式、采集/工具示例、合成素材和设置草稿 | 设计参考；不是正式发布路由 |

建议的信息架构如下，属于交接建议，尚未替换当前导航：

```text
我的素材
  资料库菜单：本地库 / Eagle 连接 / 找回旧素材
  组织：全部 / 未标记 / 标签 / 回收站
  搜索与筛选 → 结果 → 检查器
  查看模式：资料库 / 专注查看 / 悬浮卡片
采集
  网页浏览 / 来源发现 / 网站与账号 / 下载与入库任务
工具箱（目标，具体首批工具待定）
设置
  外观与操作 / 资料库 / AI 与模型 / 采集与下载 / 快捷键 / 高级维护
```

## 04 · 三种查看模式与悬浮窗口

证据：E08。当前正式页面与隔离原型均有三模式，但能力不同。正式卡片的旋转仅影响显示；原型里的暖色 AI 示例和“保留副本”不能移植成正式完成提示。

| ID | 功能 | 交互/验收要求 | 当前状态 |
| --- | --- | --- | --- |
| MODE-01 | 资料库模式 | 组织侧栏、搜索、网格、可开启检查器；作为默认工作表面 | 正式接线 |

| RT-04 | Llama 安装与服务 | 硬件检测、安装规划、来源选择、取消安装、启动/停止/测试、打开安装位置 | 受限；CDN 选项只是方案预览，不能当生产服务 |
| RT-05 | Python/OCR 依赖 | 环境检查、安装、取消、安装日志 | 受限；不因开启 AI 页面自动安装 |

建议采用两套相互关联的状态，而不是一个“AI 已就绪”绿点：

```text
模型资产：未获取 → 获取中 → 已存储 → 验证通过 → 已安装/可选择
执行能力：未配置 → 已配置 → 依赖检查 → 服务启动 → 探测结果 → 真实能力验证
素材任务：未提交 → 待执行 → 执行中 → 结果待确认 → 已采用 / 失败 / 已取消
```

上述是设计用状态分层；具体合法状态与转换必须由当前契约/后端投影提供，不要求前端自造状态机或自动启动依赖。

## 09 · 核心用户流程与交互验收

这些流程可直接转成 Figma 原型路径或前端联调用例。流程中的未完成能力以对应功能表状态为准。

### 流程 A：首次使用到第一次找到素材

1. 打开应用，默认进入我的素材，显示未打开库引导。
2. 选择创建 → 选空文件夹 → 审阅位置与复制说明 → 确认创建。
3. 添加素材 → 选择混合格式样本 → 审核中看见可收录和排除项。
4. 确认复制 → 提交中禁止重复操作 → 展示实际收录结果。
5. 点击素材检查信息，添加手动标签，填写描述并保存。
6. 搜索名称/标签/描述，结果说明命中字段；无模型也完成整个流程。

验收：取消任何尚未提交的审核都不应新增素材；不支持格式不悄悄消失；来源文件保持不变；关库重开后已提交信息仍在。

### 流程 B：检索、查看、卡片参考

1. 输入搜索词与标签条件；chip 显示当前条件。
2. 选中结果 → 检查器；双击/空格打开快速查看。
3. 使用缩放与适应视口；Esc 回到原焦点。
4. 底部切到专注查看，保留筛选结果；再切卡片。
5. 打开桌面浮窗，置顶并查看前后素材；返回主窗口。

验收：无匹配时不得显示上一个不在结果集的素材作为当前结果；快速切换无重复面板；卡片返回对应库和素材；暂时旋转不改文件；原生浮窗用真实 Electron 单独测。

### 流程 C：手动组织与批量标签

1. 勾选多个素材；底部显示数量，不自动打开详情。
2. 批量添加或移除标签 → 浮层选标签 → 确认。
3. 成功刷新并清选择；失败保留选择与输入。
4. 点击某标签查看同标签素材；可单独撤销筛选。

验收：输入/下拉不被全局快捷键打断；“删标签”明确只移除本次关联；批量半失败处理必须与后端语义一致，不能一律显示全部成功。

### 流程 D：回收与恢复

1. 检查器点击移到回收站 → 查看确认说明 → 确认。
2. 返回正常网格，焦点回到可用位置。
3. 打开回收站 → 恢复该素材 → 回到素材列表。

验收：同一素材、标签和受管内容可恢复；回收与永久删除有不同语义；提交失败不隐去该素材或假称已删除。

### 流程 E：网站采集与来源发现

1. 配置网站；如需账号，打开登录窗口后返回确认。
2. 浏览网页/搜索指定来源；查看图片候选。
3. 触发采集请求；当前版本明确提示下载不可用。
4. 后续执行器恢复时，再联调真实下载 → 候选审核 → 当前库收录。

验收：网站无结果、未授权、网络失败、下载不可用各自可区分；没有真实文件不得发入库成功事件。

### 流程 F：AI 服务设置与素材任务

1. 设置 → AI 添加服务，填写名称/类型/地址/模型等。
2. 保存或撤销；主动检查连接/获取模型列表。
3. 返回素材，选择具体能力；未就绪显示缺少条件。
4. 能力恢复后，对外部处理显示本次素材与发送范围，确认后才发起。
5. 结果作为建议预览并选择采用；失败/取消不覆盖人工内容。

验收：服务保存、连接检查成功、模型可列出、模型安装、真实推理成功是五种不同证据；各阶段不得互相替代。

### 流程 G：Eagle 离线与冲突

1. 检查连接条件 → 审阅整库范围与权限 → 确认连接。
2. 索引素材，在本地检索并保存名称修改；显示待同步。
3. 离线仍保留索引与待提交记录；重连后继续同步。
4. 同一字段两端改变时展示双方版本，用户选择或搁置。

验收：本地保存不立即标为远端已提交；冲突只阻塞相关项；不确定响应不触发破坏性清理。当前用合成 provider 验证，真实配对另有前置条件。

## 11 · UI 设计系统与动效交接

证据：E20。现有视觉语言为轻量桌面工作台：素材本身是视觉焦点，玻璃材质集中在导航和控件，内容区域以稳定底色承托。以下是可复用的当前规范，不要求照搬现有所有布局。

| 项目 | 当前基准 | 设计交付要求 |
| --- | --- | --- |
| 配色 | CSS `--ui-*` 语义变量；浅深两套 | 交付基础、文字、边框、强调、成功、警告、危险、禁用 token |
| 浅色核心 | canvas #f2f5fa；surface #ffffff；text #192333；accent #0064ce | 不在业务组件散写近似色；检查透明叠加后的对比 |
| 深色核心 | canvas #171e2b；surface #222c3d；text #f2f6ff；accent #8ec3ff | 信息密度与层级对应浅色，不只是反色 |
| 字体 | 系统无衬线；正文 13/1.5，说明 12，辅助 11，页标题 29 | 元信息不能过密；长中英文、数字与未知值均给样例 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 | 页面、组件、分组采用一致节奏 |
| 圆角 | 控件偏胶囊，卡片 18，检查器/浮层约 23–25，框架 27 | 重要性由层级表达，不堆叠无限圆角容器 |
| 尺寸 | 常用按钮最小高度 36；缩略图宽 160–280 | 保证焦点与点击范围，图标按钮提供可读名称 |
| 桌面窗口 | 默认 1280 × 832；内容下限 1120 × 720 | 主稿建议 1440 宽并补 1120 内容宽；不要要求移动端布局替代桌面验收 |
| 内容滚动 | 侧栏稳定、素材区滚动、检查器独立滚动 | 明确滚动容器与粘性工具栏；浮层不被父容器裁切 |
| 图片 | 尽量完整比例，透明图片需可识别背景 | 不把 object-cover 裁切用于所有检查/比较；主素材恢复清晰 |
| 可访问性 | 状态文字+图标，键盘焦点，减少动态/透明度回退 | 补高对比、键盘全流程、读屏名称与 live 状态 |

### 动效规范

| 动效 | 当前实现/基准 | 验收重点 |
| --- | --- | --- |
| 页面进入 | 约 220ms，7px 淡入位移；旧路由立即卸载 | 不双挂页面、轮询、快捷键或原生网页 |
| 选中导航/分组 | 弹簧移动选中背景 | 焦点与当前页一致；无跳动残留 |
| 更多菜单 | 约 240ms 进入、140ms 退出 | 退出立即 inert，不可继续点击或 Tab 命中 |
| 检查器 | 18px 轻位移，退出约 140ms | 保留网格定位，不挤掉主导航 |
| 批量条 | 底部 12px 淡入，退出约 140ms | 不遮住模式条或最后一排素材操作 |
| 高级筛选 | 高度/透明度展开 | 条件仍能清楚识别，退出控件不接收键盘 |
| 三模式 | 0–190ms 模糊；190–460ms 模式名；460–960ms 清晰 | 快速切换只保留最后目标；切换画布 inert，模式条继续可操作 |
| 减少动态 | 常规动效即时/无位移；正式三模式约 120ms 简短切换 | 不保留大范围 blur、缩放或标题停留 |
| 透明度回退 | 更实背景/边框，无 blur 可用 | 文本与图片始终可辨认 |

一般浏览不在素材像素上持续做模糊；三模式切换中的短暂全画面模糊是已记录的特定设计要求，结束必须恢复。不要把动画存在视为 60/120fps 保证；真实大库、GPU、打包版本的性能另测。

当前代码中需要设计和联调共同关注的具体差距：

- 旧文档记录 97 个禁用通道；本次读取集中表为 **92 个唯一通道**。五个 AI 服务配置/检查相关通道已单独注册；仍有 Active Library 内额外显式拒绝，不应把通道数量等同于用户功能数量。
- 正式三模式、原生卡片、新设置结构已出现，而原型 README 与 TASK 的部分状态仍停留在前一轮。接手以本报告所列源码快照为起点，再核验工作区后续变更。
- 当前标签维护页偏浏览，不能按旧 TagEditDialog/TagMergeDialog 的存在承诺能编辑；标签输入错误反馈亦未统一。
- 新卡片提供局部未保存保护，但模式条、侧栏、路由和系统关闭是否全覆盖，需专门联调。主设置表单也需要一致离开策略。
- 新 AI 服务面板与旧控制台都可呈现配置；需要统一保存范围，避免用户分不清“保存服务”“保存偏好”“保存 AI 设置”。
- 快速查看使用受控预览，但仍有旧“原始尺寸”等措辞；设计中应准确区分缩放与文件身份。
- 回收站行目前信息较少，建议补可读标题、回收时间及操作反馈；批量条与三模式条需要叠放和键盘顺序验收。
- 来源发现、浏览器采集、候选 store 和下载记录并未构成真实采集入库闭环；不能仅通过重排页面宣布完成。
- 真实大库分页/虚拟化、长期滚动性能、主窗口/原生 BrowserView 焦点与跨屏浮窗未获本轮验证。

### 联调边界

前端通过 Preload 的窄 API 与 Main 交互，不持有真实数据库、可信本地路径或执行模型的权限。调用意图应以“当前库内这项素材”为中心，不通过 Renderer 自报任意文件路径完成写入。异步返回必须属于当前库/会话；用户切库、关闭或更改素材后，旧返回不能污染新页面。

可以先用合成数据设计全部状态，但发布接线必须逐项标记实际能力。后端未恢复的功能不要求 UI 同事伪造执行器，也不应因为当前不可用就从保留清单中消失。
