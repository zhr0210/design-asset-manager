## 决策记录

### I01 · 已确认：两端同步交付

2026-10-13用户明确选择“两端同步”。共享界面统一改造，macOS桌面与同机Browser分别验证正式入口、明暗主题、键鼠、浮层、保存重开与相关失败保护。需要OS行为的单素材卡片、系统窗口/文件选择和拖窗使用桌面证据；浏览器不能替代原生资格。Windows保持未验，不宣称全平台交付。

验收遵循[真实验收流程](../../agents/ui-ux-acceptance.md)。复用已指定非隐私素材和可恢复副本；具体当前profile/库/服务身份须在正式运行前重新核对，不扫描私人目录、不读取秘密配置，不把旧候选PASS转记为新产物。

### I02 · 已确认：完整支持的窗口宽度

2026-10-13用户采纳以浏览器内容宽1024px与1440px作为完整功能验收尺寸，macOS桌面保留当前最小窗口策略并验证最小/常用尺寸；更小浏览器宽度保留辅助预览布局，不列入本轮完整功能验收。辅助页面应适配浏览器1024px，不继续用桌面1120px内容minWidth阻止布局收缩。

视觉适配规则已归DESIGN“配置、任务与其他应用页面”；本记录保存当前任务的验收范围。尚未修改窗口策略或源码，内部如何拆分桌面约束与共享页面布局由实施者核对全部消费者。

## 可执行的实施方案

### 1. 准备环境与保护当前工作

留在本工作树，保留前轮文档差异与其他WIP。正式实施时登记当前任务范围、候选身份和下一动作，并只对本任务差异建立可恢复检查点；不全量reset/clean/stash/add，不自动切换分支、推送或发布。

按锁文件恢复必要开发依赖，核对Electron ABI与实际Node/构建工具；不为shell Node重编应用使用的原生依赖。运行design:check与最小相关检查建立新基线，记录真实失败原因；缺js-yaml时修复必要直接依赖或消费路径，不手改生成结果使检查假通过。此阶段不准备无消费者的模型或新计费服务。

### 2. 先统一基础角色并限定影响范围

以DESIGN为颜色、文字、间距、圆角和组件的唯一基准。复用现有生成器与组件，收敛Gallery、--ui-*和局部硬编码；主要确认/创建、普通工具、素材选择、导航当前位置、警告/错误分别对应正确角色。修复图像工具未定义变量、常规状态颜色和不完整的明暗/透明度回退。

先核对所有共享样式消费者。WorkSetWindow与WorkShelfFocus当前也导入Gallery tokens/样式和部分正式集成样式；本轮规则须限定作用于纳入页面，必要的作用域隔离可自主实施。只修改主工作台文件并不能证明被排除窗口不受影响。保留被排除窗口的既有呈现与行为，不借共享token同步实施其延期设计；边界检查使用指定公开内容，不扩张为工作窗功能整改或完整资格验收。

### 3. 落地导航、检索与页面信息层级

统一主工作台及辅助页面的窄导航外壳，应用已确认入口分组；资料库内四个目的地与全局页面定位明确，不丢失返回路径或未保存保护。清理辅助页面的重复外壳标题，内容区保留标题、必要说明与主要动作。

搜索框、查找方式和筛选入口集中底部；以图与维护按需浮层。当前查询进度、错误与影响结果的限制及时可见，覆盖/空间/重建/恢复细节默认折叠；顶部恢复前后导航、添加和适用的多选操作条。保持真实搜索字段、示例图范围、分页/取消、素材顺序和保存状态，不以减控件代替能力接线。

配置表单、任务列表、标签、连接/旧库、帮助、详情、大预览和单素材卡片统一通用控件、文字层级、菜单/焦点、明暗及可访问性回退。按1024px/1440px适配共享页面；桌面最小窗口策略与浏览器布局约束分别处理，保留真实系统窗口控件/拖窗行为。

### 4. 聚焦内部检查、类型与正式构建

先运行受改动影响的检查：design:check、test-workspace-design-system、test-app-navigation-workflow、test-desktop-viewport-policy、test-library-canvas-state及相应样式/焦点检查；涉及素材卡片、描述、组织、笔记、设置/转场时补其已有保护测试。修改过的测试全部执行，保持仍有效的断言，不把旧原型像素对照当作新设计的唯一准则。

类型检查与正式构建必须完成。有失败先定位和修复，按风险扩大测试；不为设计改动自动运行所有长期模型/平台矩阵。内部检查只证明其覆盖的接线与保护，不关闭实际用户路径。

### 5. 从两个正式客户端验收

通过普通start:desktop/start:browser及应用菜单进入，绑定本工作树的新构建身份；不向路由/Store/IPC注入状态跳过用户入口。浏览器按1024px/1440px核验，桌面按最小/常用窗口核验。

| 用户路径 | 可见结果与保护 | 所需证据 |
| --- | --- | --- |
| 主导航与所有辅助页面 | 入口可发现、单一标题、当前页明确、返回素材上下文、无整页裁切 | 两端、两种主题、适用宽度与键盘 |
| 浏览/文件夹/色板/回收站 | 图片比例/颜色完整、详情/多选不遮入口；不支持的查询明确说明 | 两端正常、空/无匹配/失败状态 |
| 底部文字/语义/以图检索与筛选 | 实际结果、命中解释、进度/限制可见；维护折叠可发现，取消保留已有结果 | 指定素材与适用实际本地检索服务，不能用假响应关闭 |
| 标签/描述/组织/笔记与设置 | 正常编辑与保存重开；取消、冲突、未保存离开和迟到结果保护 | 两端正式操作，受影响持久结果与恢复 |
| AI/模型/任务相关入口 | 正确配置/权限/资格/等待/失败状态，适用受改动影响的真实执行仍能完成 | 既有实际服务与已批准输入/费用范围；不声称重新验证所有模型 |
| 公共菜单/浮层 | 点击外部/Escape、焦点进入/恢复、键盘选择、长内容滚动、背景输入保护 | 两端键鼠、明暗、减少透明度/动态效果 |
| 单素材卡片与系统行为 | 普通入口打开/返回、原功能与草稿、系统按钮/拖窗/选择器正确 | macOS桌面；Browser只能证明发起动作与共享页面 |

实际运行缺工具、服务或明确数据身份时只标相应项BLOCKED_UX_ACCEPTANCE/NOT_RUN，继续其他独立工作；必需路径未完成则整体交付保持未完成，不将复测转交用户。

### 6. 验证资料与唯一Host

CURRENT-STATE已指定公共profile与DAM-T23-macos-library；2026-10-13本轮只核对这两个明确路径存在，没有读取profile秘密或库内容。后续通过正式应用确认当前库/模型/服务身份，复用既有非隐私材料许可，准备可恢复的任务验证副本；不克隆凭据profile，不扫描其他资料。已有许可范围明确就持续使用，不重复请求普通测试权限。

先核对同profile已有Host，按正式退出/接续规则确保唯一写入者；不杀身份不明进程，也不让新源码启动器只聚焦旧Host后冒称新产物运行。具体来源、副本、任务profile与服务非敏感别名在实施阶段TASK/证据中登记，不读取账号令牌或完整配置调试。

### 7. 完成标准与收口

所有纳入页面按现行规则实现，design:check、受影响检查、类型与必要构建通过；两端正式用户路径取得相应结果、保存重开及失败/取消证据，排除窗口的共享样式边界保留。保存足以复核的截图、操作与构建身份，明确实测/未测平台和服务。

视觉规则继续归DESIGN，用户行为归模块规格；TASK/任务台账记录当前实施状态，CURRENT-STATE仅记录新候选的真实能力与限制，执行证据归对应报告。不能以测试数量、禁用控件、模拟状态或旧版本证据宣称整体完成。
