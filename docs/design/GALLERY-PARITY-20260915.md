# 原型反向规范与正式界面对齐

2026-09-15，按用户“以 UI 原型反向重写 design.md、像素级复刻并清理相关 ADR”的请求实施。
这是一轮界面迁移与规则纠偏，不把界面存在等同于全部存储/模型/原生能力交付。

## 规范与代码

- DESIGN.md重写为布局、材料、页面、输入、交互、状态与验收规格；mobbin.md保留精确 token，
  正文重写为同一设计的材料说明。删除旧固定卡片尺寸/360ms模糊重排、专注渐变及卡片细边规则。
- ADR 0486确立已批准设计和共享展示组件；修订0483的“视觉随后完善”表述与0009的主表面说明。
  AGENTS及产品基准同步；旧规范添加历史状态，修改前DESIGN/mobbin/TASK在history中保留。
- 从原型抽取gallery展示层：AnchoredGrid、BottomDock、FolderCard、FocusCanvas、FocusView、
  ColorTools和笔记类型。原型与正式适配器共用样式；只在原型wrapper保留样例/浏览器保存。
- LibraryCanvas改用四图标、原型的330密度、磨砂封面文件夹、共享底部搜索与菜单、标签消散、
  小尺寸滑条、灰色选择和无模糊自适应重排。资料库管理收到品牌入口，默认不再撑开内容。
- LibraryDetails采用预览、配色、格式、理解、提示词/OCR的顺序；原标签/描述/AI/图片工具放入
  显式编辑展开区，保留操作和失败路径。来源缺少结果时显示真实空状态，不填演示百分比。
- LibraryFocus复用硬切、缩放/平移、笔记页、绘图/文字/便签和画廊；正式笔记目前是库会话草稿，
  保存按钮禁用并说明，关库/退出清除。原图字节不被绘图修改。
- 收窄旧全局深色输入/根颜色覆盖，移除正式容器残留14px左边距；共享样式不泄漏其他页面。

原型缺陷的必要修正：多选条原先top54会遮挡第一排复选框，迁移为top10、高40的上下文行。
原型和正式共用修正；不把阻塞多选当作必须复刻的视觉细节。

## 可见能力差异

以下是真实数据能力缺口，不能靠像素对照宣称完成：

| 项目 | 当前正式状态 |
| --- | --- |
| 普通/AI文件夹 | 可按已保存标签浏览引用、封面与子页；独立文件夹/AI规则持久化未接通 |
| 色板 | 文件夹和颜色菜单入口保留；收藏/新建/窗口色板尚不能正式保存 |
| 图片笔记 | 工具与多页会话草稿可用；正式持久化禁用，不使用prototype localStorage |
| 工作模式 | 工作模式页进入既有单个原生桌面卡片；多工作集/多原生窗口恢复未完成 |
| 回收站检索 | 共用视觉操作层，原接口无名称/标签，因此对应查询与筛选不可用 |
| 配色与AI | 展示真实记录或缺失状态；未运行真实模型，未凭界面伪造测量 |
| 文件格式 | 不改变正式入库和预览支持范围；原型字体/文档样张不证明正式解码 |

安全语义保留：Main/Preload/shared和schema未因本轮改变；受控预览URL不回退文件路径；
Copy来源不移动；旧请求/选择随库权限变化撤销。此次测试只使用生成素材，没有访问真实Eagle库。

## 视觉证据

基线从本轮修改前源码快照抽取，不以同时修改后的原型作为唯一参照。
独立视觉测试使用生成素材与明确的测试媒体适配器，同时加载正式全局样式以检测污染。
这不是正式数据库验证。三个窗口宽度1379/1440/1024，高1042，DPR1；每个宽度覆盖五组：

1. 导航、主内容、搜索、标签、滑条、卡片的几何与材料。
2. 占位侧栏与保留列数的缩小布局。
3. 文件夹对象与前盖位置/大小。
4. 专注窗口、工具、笔记页与画廊尺寸。
5. 深色材料与菜单。

15组均通过，坐标/尺寸差异≤1 CSS px，0页面异常。1379宽首卡片裁剪的RGBA通道比较中，
差值大于4/255的通道占0.308%；这是一个裁剪区域的指标，不是全应用“99.692%一致”。
文字抗锯齿、正式内容、不可用能力提示与不同系统渲染仍可能产生差异，未声称全状态零像素差。
将修改前全部页截图保存为固定基线；后续测试同时检查它，防止原型与正式组件一起漂移。
