# 轻玻璃与纯净预览修订

后续材料减淡、无描边、侧栏与专注模式由[最新修订](INSPECTOR-FOCUS-20260914.md)补充；
以下保留上一轮批注的记录。

2026-09-14，依据用户在原型上的8条浏览器批注。当前规范仍为根mobbin.md；
本轮只调整隔离原型，不改变正式应用、真实素材或运行权限。

| 批注 | 结果 |
| --- | --- |
| 搜索、操作、标签和子菜单要半透明毛玻璃，减少底色 | 移除底部整片渐变托底和叠加渐变，采用单层半透明底色、背景模糊及轻高光；菜单/标签用相同材料体系 |
| 布局滑条过大 | 约104px高、2px细轨道、9px滑块，移除常驻图标，数值仅悬停/键盘操作时出现；实际命中区域保留 |
| 去掉上下预览说明 | 默认隐藏；左下设置内“显示预览说明条”可恢复；说明仍可在设置中查阅 |
| 图片显示标签 | 图片下沿显示最多3个玻璃胶囊，可点击筛选；与图片打开/多选操作分开 |
| 删除实色材料切换 | 移除侧栏入口、设置选项和手动状态；旧保存的solid字段不再生效；系统无障碍或无模糊支持时仍自动回退 |
| 删除侧栏边界线 | 窄导航透明，无分隔描边 |
| 隐藏滚动条 | 素材、文件夹、色板、窗口内容和弹出菜单隐藏轨道，滚动本身继续可用 |
| 选中态改灰色 | 导航、标签、快捷筛选、多选边框及焦点统一中性灰；素材本身的颜色保持 |

材料取值：底部浅色54%/深色68%，标签58%/74%，弹层64%/74%；背景模糊14–24px。
减轻底色同时保留阅读条件，未用整体opacity稀释文字。图片胶囊在选中时有独立的灰色材料，
不会将蓝色作为选中标记。菜单在空白背景前看起来较平静，滚动到素材上方可见背景颜色透出。

验证：现有14项交互回归通过，0页面异常、0外部请求；新增浏览器检查覆盖全部八条批注，
包含滚动条隐藏后仍能滚动、说明条隐藏/恢复、图片标签点击、灰色选中态和缩小后的滑条。
1379×1042的浅色、深色、标签菜单及更多菜单已目检。typecheck及差异空白检查通过。
