# 素材工作台：交互与 UI 设计系统

> 2026-09-15：本页保留历史实现/验收记录。新界面的布局、材料和交互以 [DESIGN.md](../../DESIGN.md)
> 与 ADR 0486 为准；旧模糊、固定尺寸和简化正式界面不是当前验收基准。


本轮目标是提高日常素材工作的可发现性、一致性和可用性，并建立可复用的
原创界面规范。“获奖级”是设计追求，不是已获得奖项或通过商业发行认证。

2026-09-14补充：核心模式范围以[工作模式规格](../product/WORK-MODE-AND-MOTION-REFERENCE.md)
及ADR 0485为准。既有“卡片模式”是单窗口实现基础，后续目标包含可保存的多素材工作集、
多窗口、视频参考与跨应用交接；不把旧三模式原型作为数量或功能上限。视觉规范仍适用。

2026-09-14视觉更新：当前视觉token、字体、玻璃/渐变和动效以根目录
[mobbin.md](../../mobbin.md)为准；下文保留既有正式CSS与交互的历史背景，不作为
第二套视觉规范。旧全屏模糊时长、固定旧导航及旧能力快照不约束新原型；
素材权限、数据恢复与键盘语义继续按产品规范和真实调用方执行。

## 当前方向：Apple 风格的桌面工作台

用户否定此前平面视觉，明确要求磨砂液态玻璃与 Apple 式前端交互。
本轮由 Astra 直接设计、实现和审查。风格依据为 Apple 官方
[Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与
[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。
玻璃用于导航和控制层，内容保持清晰；以系统字体、稳定位置、直接操作、
渐进显示细节和可预测返回组织工作流。本项目是 Electron/CSS 实现，
不声称使用 SwiftUI/AppKit 的原生 Liquid Glass 材料或具备系统光学折射。

- 宽侧栏持续展示文字与图标，库连接/找回可直接发现。
- 控制面使用半透明色、背景模糊、细高光边缘和克制阴影。
- 素材卡片保留实色底和原始比例，不把模糊滤镜施加给素材。
- 集合筛选置于稳定的横向栏；右侧检查器出现时保留导航位置。
- 创建/导入在临时任务浮层确认，完成或取消后回到原位置。
- 常用动作使用蓝色主按钮，风险和失败仍有独立状态色与文字。

## 信息架构

固定工作区导航：素材、连接库、找回、标签、采集；设置位于底部。
次级功能通过“更多功能”进入，现有路由保留，未启用能力仍明确不可用。

本地库主面由“库状态/操作 → 搜索/筛选 → 素材网格 → 检查器”构成。
未打开库时给出创建/打开选择，以及外部库与旧库的明确入口。
Eagle 连接库按“连接状态 → 素材 → 需处理冲突 → 同步记录”组织。
旧库找回呈现数据库选择、素材目录选择、只读确认三步，不混用 Eagle 入口。

颜色通过 --ui-* 变量消费。Positive/Warning/Danger 分别表达已完成、需关注、
失败/危险，不能仅靠颜色传达结果。主题是同一信息结构的两种表达。

- 字体：系统无衬线，正文 13px/1.5，说明 12px，辅助信息 11px，页标题 29px。
- 间距：4、8、12、16、24、32；优先减少嵌套而不是无限缩小间距。
- 圆角：常用控制胶囊形，卡片 18px，检查器/浮层 23–25px，主框架 27px。
- 控件：常用按钮最小高度 36px，原生键盘焦点可见；只读与禁用要有解释。
- 动效：160–200ms 颜色、轻微位移与浮层进入；尊重系统减少动态效果。
- 材料：系统减少透明度或增强对比度时退回实色，不支持 blur 时提供实色回退。
- 素材：保留原比例，不默认裁掉设计边缘；缩略图列宽 160–280px 可调整。

## 组件契约

src/renderer/components/ui/WorkspacePrimitives.tsx 提供 Button、StatusBadge、
PageHeader、EmptyState、Notice、ReviewSheet 和共享模态焦点工具。样式类 ui-card/ui-input/ui-field/ui-section-heading
等用于一致布局。业务组件负责状态与授权，基础组件不执行 IPC 或文件操作。

每个区域仅有一个首要动作。次要动作使用边框或弱化按钮，危险动作独立着色。
错误在发生处解释并提供下一步，不把原始英文异常、私有路径或 SQL 暴露给用户。

## 行为与安全约束

- Loading、未打开库、真实空库、筛选无结果、加载失败必须区分。
- 创建与 Copy 仍经过既有评审/确认；视觉更新不扩大文件写入权限。
- 用户输入、确认标签、来源及同步冲突仍由现有权威模块控制。
- 单击或 Enter 查看详情；卡片上按空格或双击打开快速查看。预览只消费既有
  受控 preview，不新增原件路径、外发或源文件操作。
- ⌘F（其他平台 Ctrl+F）聚焦并选中搜索内容；打开模态任务时不抢走焦点。
- 关闭检查器回到原卡片；快速查看和确认浮层限制 Tab 在内部循环，背景 inert。
  Escape 只关闭当前层并恢复焦点；输入编辑与子菜单保留自己的按键语义。
- 创建/导入执行中禁止取消；失败信息留在浮层内部可见，不藏在遮罩后面。
- 批量选择有数量与独立动作，取消选择可直接访问。
- Eagle 未配对、模型未启用、下载无执行器等状态仍如实表达。
- 本轮不启用真实 Eagle、AI/Runtime、下载执行器，不迁移真实用户库。

## 验收标准

以临时 profile 和生成素材验证完整 Electron 工作流，不使用真实素材做样例。
检查浅色/深色、默认/最小窗口、空态/有素材/检查器/多选、键盘焦点、菜单
点击与 Escape、缩略图大小变化、连接库冲突与旧库只读流程。
生成截图须目检，构建成功不能代替 UI 可用性。设计系统 HTML 为独立可查看
工件，不作为生产产品中的工程配置页面。

## 全软件与动效深化

设置、标签、总览、来源发现、网站、下载、模型与 AI 工作区已统一页面层级。
动效、逐层焦点、退出交互隔离及具体测试见
[工作台动效与全局交互](WORKSPACE-MOTION.md)。动效模块只表达状态，不拥有
业务写入、网络、Runtime 或原生窗口权限。
