## 当前导航与操作

| 表面 | 本轮交互 |
| --- | --- |
| 全部 | 图像、视频、文字、字体样张和文档示意混排；默认不展开检查器，让素材占主画面 |
| 文件夹 | 磨砂文件夹卡片露出内容预览；普通文件夹、AI文件夹与色板文件夹集中在此 |
| 文件夹子页 | 与全部共用素材网格、底部搜索/标签/快捷筛选和右侧尺寸滑条；支持嵌套与前进后退 |

| 回收站 | 左侧第四个图标，与全部共用网格与底部控制；合成恢复操作不触及真实Trash |
| 色板子页 | 从文件夹进入；复用底部输入进行HEX搜索，保持颜色收藏、菜单与工作窗口色板 |

用户提出未来可能合并回收站与全部，当前保留独立入口和明确的恢复语义，未提前合并。
“全部”展示活动素材，回收站内容仅在其专属范围出现。格式支持仍按各模块验证结果声明；
原型中的字体使用系统字体样张，文档是合成封面，不宣称读取任意OTF/TTF/PDF。

底部控制分两行：上方“标签筛选”和已选标签，下方搜索、随机打乱、未标签、未分类与菜单。
点击已选标签立即撤销筛选，450ms内完成粒子消散并清理节点；减少动态效果时直接移除。
多个标签使用AND匹配；快捷筛选限制在当前素材范围，不把文件夹查询变成全库查询。
右侧垂直滑条调整真实网格列宽，150–430px；回收站、普通/AI文件夹子页复用同一控件。
文件夹根页筛选名称，色板页筛选色值；不适用的素材标签/未分类快捷项在这些上下文禁用。

菜单容纳格式选择、清除筛选、加入工作集、色板入口、标签管理、外观和演示设置。
图标导航有可访问名称和悬停/键盘提示。原型标识保留于细窄工具条，正式产品无需展示开发说明。
文件夹前进后退保留当页搜索文字和已选标签；不复用持久权限或触发下载/分析。

## mymind 首页视频研究

公开来源：[mymind首页](https://mymind.com/)。本轮读取页面HTML中明确引用的媒体URL，
按用户授权下载至独立临时研究目录。没有登录、读取用户账户或打开真实素材库。

| 视频 | 公开媒体来源 | 时长 / 下载大小 | 检视方式 |
| --- | --- | --- | --- |
| 首屏环境动画 | carbon-media资源 iOt8YOTZL5jdyQMI5It4iw，2160×2160版本 | 约19.97秒 / 3,091,800字节 | 每4秒抽样，5个有效画面 |
| 产品浏览演示 | carbon-media资源 ji9KfXI5e4Bby7egHtQulR，2200×1560版本 | 约22.03秒 / 5,679,180字节 | 每2秒抽样，11个画面 |
| 搜索演示 | carbon-media资源 lGf6kOyeDKjeAZdenRgWv2，原始WebM版本 | 约10.03秒 / 2,747,249字节 | 每2秒抽样，5个画面 |

首次搜索HEVC版本（资源9E8Z7rKoE6Xc23a89AQopQ，3,232,272字节）在本机ffmpeg无法解码，
改用同一首页声明的公开VP9/WebM版本完成抽帧。合计下载约14.75MB（包含未能解码的版本）。
原视频与抽帧联系图保留在临时研究目录`dam-minimal-navigation-29w0v0ld`，媒体未嵌入产品。
联系图中不足一整页的黑色格子是排版空位，不是对视频画面的观察结论。

观察与采纳：

- 首屏动画以缓慢变化的柔和色晕营造环境感：本原型把低饱和环境色放在控制层周围，
  不在素材本身上叠加滤镜，也不默认持续播放装饰动画。
- 浏览演示把图片与文字放在同一视觉集合里，弱化持续占位的工具：扩展合成文字/字体/文档
  示例，检查器默认关闭，导航收成四个图标，次级功能放到菜单。
- 搜索演示中条件收成标签并继续组合：底部展示可撤销标签，搜索范围与状态始终可見。
  用户要求的消散动画是本项目新增表达，不宣称来自其原实现。
- 内容详情按需展开、集合有可辨识的视觉封面：采用上下文检查器及用户参考图2的磨砂文件夹，
  保留原有AI分类依据、普通目录、色板和工作集的不同含义。
- 未采用网站“无需文件夹”的完整产品立场；用户要求的文件夹结构和宿主数据边界继续有效。
  不复制商标、页面代码、第三方图像或视频进入原型，也不把广告演示当作性能证据。

这些是从视频抽样做出的设计判断，不是对mymind完整功能或实现源码的审计。

## 验证与交付边界

新统一检查命令：`node scripts/check-minimal-prototype.mjs`（先运行`npm run prototype:work-mode`）。

快捷筛选/打乱、布局滑条、目录层级与历史恢复、AI资格过滤、回收站共用布局及合成恢复、
