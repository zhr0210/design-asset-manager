# 工作台动效与全局交互

> 2026-09-15：本页保留历史实现/验收记录。新界面的布局、材料和交互以 [DESIGN.md](../../DESIGN.md)
> 与 ADR 0486 为准；旧模糊、固定尺寸和简化正式界面不是当前验收基准。


本轮前端由 Astra 直接设计并实施。视觉基础继承
[Workspace UI System](WORKSPACE-UI-SYSTEM.md)，生产源为
`src/renderer/styles/design-system.css` 与 `components/ui/WorkspaceMotion.tsx`。
使用已安装的 Motion for React，不增加动画依赖。

## 动作与空间关系

| 表面 | 行为 | 正常动态 | 减少动态 |
| --- | --- | --- | --- |
| 页面 | 路由提交后旧页立即卸载，新页进入 | 220ms、7px 上移淡入 | 无位移、即时显示 |
| 主导航 | 选中背景跟随目的地 | 阻尼弹簧移动 | 即时切换 |
| 分组选择 | 背景随选中项移动，支持方向/Home/End | 阻尼弹簧 | 即时切换 |
| 更多菜单 | 锚定按钮展开/收起 | 240ms 进入、140ms 退出 | 即时 |
| 检查器 | 从工作区右侧进入 | 18px 淡入、140ms 退出 | 即时 |
| 批量操作 | 从底部出现，选择清空后离开 | 12px 淡入、140ms 退出 | 即时 |
| 高级筛选 | 工具栏下方展开/收起 | 高度与透明度过渡 | 即时 |
| 确认浮层/快速查看 | 聚焦临时任务 | 轻微进入；完成即释放 | 无装饰进入动画 |

退出中的 PresencePanel 设置 inert、aria-hidden 与 pointer-events:none。
路由不保留退出页，所以不会为了动画重复挂载轮询、快捷键或原生 BrowserView。
大素材网格不逐帧改变列宽，不在素材像素上动画 blur，避免大量重排或重新栅格化。
原生 BrowserView 的坐标不参与 React 路由动效；网页采集的来源侧栏显式点击
展开，不再由悬停反复触发布局变化。原生视图跨进程隐藏/焦点时序仍是独立边界，
本轮没有重写该协议，也不声称已验证所有原生网页焦点交接。

## 各页面的设计深化

- **主素材库/连接库/旧库**：保留可信的检查与确认链，统一工作区进入、
  检查器、筛选和批量动作。冲突与只读语义不受动效影响。
- **设置**：外观、存储与采集、维护与诊断分组；分类切换保留未保存路径草稿。
  外观直接切换；存储偏好显示更改状态并明确保存。移除没有真实执行器的
  “缓存清理成功”界面路径，不把假完成包装成动画。
- **标签**：聚焦浏览/搜索/类别/排序，提供回到素材中编辑的入口。
  未启用的别名/层级/合并/永久删除在说明中披露，不用一排无效按钮占据主面。
- **总览**：展示已加载素材和记录，不把历史下载称作今日成功入库。
- **网站来源/来源发现/下载记录**：统一页头、操作层级、状态和输入；
  网站新增使用 ReviewSheet，失败后保留输入。来源搜索与本地检索仍分离。
- **模型库**：共享页头与控件材料，目录/存储/发布限制继续按正式投影显示。
- **AI 控制台**：统一按钮与分类选中动效，设置面板按需挂载为焦点浮层；
  关闭后不再存在可被 Tab 命中的隐藏控件，保存失败就地说明并保留草稿。

## 验证

`node scripts/run-ts-test.mjs scripts/workspace-motion.test.ts` 使用真实 App/routes，
显式加载仓库 Tailwind/PostCSS，在临时浏览器环境提供合成 API；拦截外网，
不读真实素材或 Runtime。覆盖分类键盘、草稿、模态、主题、正常/减少动态
及快速路由切换。该测试不是实际模型、库、原生选择器或 Electron IPC 证明。

`node scripts/active-library-electron.e2e.test.mjs` 与
`node scripts/external-connected-library-electron.e2e.test.mjs` 验证正式
Main/Preload/Renderer 的合成库流程；键盘边界另用
`npm run test-asset-library-keyboard`。测试截图须在完整生产样式下目检。

不将动画存在等同于 60/120fps 保证；真实大库、长时间运行、各 GPU/操作系统
及打包版本的性能属于后续真实环境验证。当前已安装应用未自动替换。
