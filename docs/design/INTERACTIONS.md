## 共通规则与作用域

- 按用户正在操作的表面判定输入：文本框中的空格/删除保持文本语义；主库专注与工作集专注的缩放、切图和控件分别读各自章节，不能因合并文件而互相覆盖。
- 通用反馈与材质由DESIGN定义；具体动作的开始/进行中/成功/失败/取消、焦点与保存后果按下列场景。失败与无内容、未分析与有效无字、请求结束与持久提交不得合并。未知保存结果先核对，不引导盲重发。
- 新组件/交互缺少已批准行为时先明确预期与边界，不能以当前实现或自生成截图反向定义正确答案。修改行为同步本文件具体场景；只改外观不偷改保存/输入/权限语义。
- 下文按原三份规格保留有效正文、来源和例外；“本次”“旧记录”等沿用其来源语境，不自动成为当前实施队列。旧入口仅转向此处；迁移前字节与逐段去向见[迁移记录](../checkpoints/interaction-visual-acceptance-20261015/README.md)。B候选规则不等于普通默认路径已改成原生；机制与实际资格另查GUI系统和当前状态。

## 主工作台与独立大预览交互规格

本页维护页面、输入、状态和用户流程，不维护视觉token或运行资格。视觉规则见[DESIGN](../../DESIGN.md)，数据语义与权限继续遵循各产品规格。B悬浮窗及其专注差异以[悬浮工作窗交互规格](INTERACTIONS.md#work-window)为准；受测产物与缺口见[当前状态](../handoff/CURRENT-STATE.md)。

本页从原DESIGN中的功能描述归位，不把规格文字当作已交付证明。[迁移来源与分工](../history/design-system-restructure-20261013/README.md)。

<a id="workspace-产品表面"></a>
### 产品表面

主流程：收进素材 → 渐进理解 → 找回并解释命中 → 检查比较 → 安全复用。
左侧主区从上至下为品牌/资料库入口、全部、文件夹、工作模式、回收站；底部仅保留设置和主题切换。应用级功能集中到设置，不再提供独立AI入口、任务中心或更多功能菜单。
普通文件夹、AI 文件夹、色板集中在文件夹页；工作集集中在工作模式，不恢复宽导航树。

| 页面 | 主内容 | 搜索与操作 |
| --- | --- | --- |
| 全部 | 当前库所有已支持格式的素材；模型未就绪不阻塞浏览 | 底部搜索、标签、随机、未标签、未分类、菜单 |
| 文件夹根页 | 普通/AI/色板的视觉文件夹；封面用真实成员引用 | 搜索文件夹名称；不适用的素材筛选禁用并说明 |
| 文件夹子页 | 与全部相同的素材网格；保持文件夹上下文 | 同一底部组件；前进/后退恢复目的地 |
| 色板页 | 按文件夹管理已收藏颜色；支持新建与选择目标 | 搜索颜色；不冒充素材原件 |
| 工作模式 | 保存的工作集、多素材参考窗口；成员移除不删除素材 | 参考查看/笔记/色板/复用；不承担库整理 |
| 回收站 | 与全部相同的内容和底部布局；恢复动作显式 | 名称/标签不在当前正式接口时禁用对应查询并说明，不能显示无效可用搜索 |

未实现的数据能力保留正确的视觉位置和说明，不能用“已有标签视图”冒充普通/AI 文件夹，
不能用单个原生卡片冒充多窗口工作集。新增功能的上线状态见模块 README，不由本表证明。

<a id="workspace-应用页面导航"></a>
#### 应用页面导航

打开设置后，设置占满整个主窗口，隐藏主页导航、工具条及素材搜索栏；保留“返回素材工作区”入口。设置分类直接呈现外观、资料库、AI与模型、标签管理、仪表盘、只读旧素材找回、快捷键、高级维护和帮助与关于。草稿恢复与退出整个DAM也在设置分类区内可发现。

设置分类切换共用同一设置生命周期，未保存路径输入保持；跨端设置变化仍通过原基准检查与明确采用处理。返回主工作区不会切换资料库身份。退出仍使用参与者审查、保留草稿与排空流程。设置搜索仅搜索设置分类，不承担素材检索。

AI及原更多功能路径统一为`/settings/*`；旧AI、标签、仪表盘、旧库、帮助地址仅作为兼容跳转。`/tasks`与`/downloads`退回素材工作区，不恢复任务模块。素材下载执行入口与采集下载偏好已移除；本地复制导入、模型下载、AI内部运行记录和已有库数据保留。工作集悬浮窗及其专属大预览使用独立规格。

页面标题、简短说明与主要操作统一在内容区呈现，外壳不再重复显示标题横条。系统窗口按钮及拖窗区域保持可用，页面操作不触发拖窗；视觉避让见DESIGN。

<a id="workspace-单素材卡片"></a>
#### 单素材卡片

保留工作模式中“原单素材卡片与工具”的现有入口和功能，单素材卡片纳入软件统一设计规范。它是单份素材的参考视图，不等同于展示已保存工作集的悬浮工作窗；术语见CONTEXT中的Single-Asset Card与Work Window，实际实现见[单素材卡片模块](../../src/main/asset-card/README.md)。

本次规范对齐保持其预览、描述编辑、提示词草稿及现有工具行为，保留资料库身份、草稿和提交保护；不扩展为功能重做或入口移除。视觉规则见DESIGN，工作集悬浮窗及其专属大预览继续排除在本轮范围外。

<a id="workspace-搜索与检索信息"></a>
#### 搜索与检索信息

常规素材浏览保留清晰可发现的搜索方式与筛选入口。查询进度、失败以及影响结果范围或完整性的限制及时显式呈现，不要求用户先展开维护信息才能知道当前查询是否可靠；首次失败、无匹配和刷新保留内容分别说明。

搜索框、当前查找方式与筛选入口集中在底部搜索区域；以图检索与索引维护从该区域按需打开浮层。索引覆盖统计、索引空间标识、重建及恢复细节默认收起，不在顶部持续展示整块检索面板。查询反馈与影响结果的限制继续及时可见，打开维护浮层不是查看这些反馈的前提。

顶部保留前后导航和添加素材；选中素材时显示多选操作条，提供当前选择的操作。搜索/维护浮层与多选操作条不互相覆盖入口，具体几何见DESIGN。收起维护信息不暂停或取消已执行任务，也不隐藏影响当前结果的限制；向量准备、重建、暂停和恢复继续遵循现有范围确认与任务语义。

<a id="workspace-交互与动效"></a>
### 交互与动效

- 单击图片打开右侧占位详情。保留数组顺序及原有列数，按剩余空间向小缩放；
  尽量保持选中项纵向视口位置。取消“绝对原位置和大小”的旧要求，避免留白与遮挡。
- 侧栏重排保留上下文与视口位置；显式密度调整清除旧尺寸锚点。视觉动效以DESIGN为准。
- 空格或双击进入专注模式；按打开时实际筛选与排序浏览，左右键、箭头按钮、缩略图等价。
  图片直接硬切，不保留淡出图片、不加 blur/opacity 动画。
- 点击多选圆点只改变选择；点击图片标签加入/取消筛选。取消顶部标签立即更新结果，
  视觉移除反馈与减少动态效果遵循DESIGN。
- 菜单/筛选在点击外部或 Escape 时收起。颜色菜单支持右键、Context Menu、Shift+F10；
  左键复制 HEX，菜单提供复制、添加到选定/新建色板、添加到工作窗口。
- 详情顺序：预览 → 配色条 → 来源/尺寸/文件大小/收录日期 → 标签管理与可编辑描述
  → AI来源/建议 → 分析工具/提示词 → OCR/视频参考 → 工作窗口与素材工具。基础信息默认展开，
  不放入“编辑标签、描述与素材工具”收纳区；不重复展示同一组标签和描述。无结果时说明缺失。
- 基础标签与描述编辑直接可用；AI配置、图片工具仍按操作需要展开，保留错误与保存状态。
- 前进/后退保留目的地语义；普通文件夹和 AI 分类引用素材，不复制原件。

<a id="workspace-专注画布与笔记"></a>
### 专注画布与笔记

| 输入 | 行为 |
| --- | --- |
| + / −、Shift＋鼠标滚轮 | 放大/缩小，滚轮以指针位置为中心 |
| 0 / 1 | 适应居中 / 预览像素 1:1；只有拿到原件才可称原件像素 |
| 默认拖动 / 绘图时空格拖动 | 平移 / 临时平移，不落笔 |
| Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z | 当前页撤销/重做 |
| Delete/Backspace | 删除选中标注；输入控件保持文本语义 |
| Escape | 先取消文字编辑或收起便签，再关闭专注，恢复触发焦点 |

图片下方为原图、多张笔记页、末尾添加笔记。每页独立笔迹、名称和撤销记录，支持画笔、
矩形、椭圆、文字、便签、颜色/粗细、选择/删除。便签在图中显示编号点，点击展开文字。
图片和标注一起缩放平移；归一化坐标不改原图。视频绘图需参考帧，不能假装静态图片工具可编辑视频。
未提交文字/绘制中阻止切图或整体保存；保存失败保留草稿。正式保存须绑定素材和库权限；
会话草稿、原型浏览器保存、正式持久化分别标明。图片笔记按正式库保存流程执行；首次保存说明v5升级兼容影响，取消不写库。保存中继续编辑仍标未保存，失败保留草稿；版本冲突保留为新草稿页再核对。

<a id="workspace-普通文件夹与色板的正式交互"></a>
### 普通文件夹与色板的正式交互

文件夹支持引用加入、移除成员、同类子文件夹、改名/移动/删除叶文件夹；根页与底部菜单提供新建。
文件夹编辑按钮悬停或键盘聚焦可见。文件夹路径与当前操作以轻量浮动控制显示，不恢复整条固定顶栏。
选择素材后可加入已有文件夹或新建并加入；“未分类”基于实际普通文件夹成员关系。
色板支持HEX搜索、系统颜色选择器、新建、收藏、复制和移除；与图片右键菜单相连。
首次保存明确说明v6升级，取消不修改结构，失败保留输入。AI分类按当前有效分析标签动态引用；色板颜色可加入选定工作集，并在原生工作窗口备注上方显示。
图片颜色标“预览测量”，透明像素按alpha加权；不是模型猜测或原件全分辨率分析。

<a id="workspace-ai-结果与找回"></a>
### AI 结果与找回

侧栏「素材理解」显示用户描述及当前分析来源；两份描述不一致时单独展开AI画面描述。
建议标签使用灰色胶囊和10px星形图标，图标/文字同行。点击可确认，未确认也可检索；
确认标签不带建议标记。模型与时间独立一行换行，不紧贴用户描述说明。
AI执行在侧栏单独展开，不藏进旧编辑器二级展开区；执行确认、错误与无服务提示保留。
搜索命中说明区分「AI 建议标签」「AI 画面描述」「反推提示词」「OCR」等来源。
文件夹根页按普通、AI、色板排列。AI包括全部已分析、标签待确认、当前标签分类，
复用星形FolderCard与现有封面/计数；子页轻量标「动态引用」，不提供普通成员移除或子夹创建。
支持筛选、前后导航及空格专注；不因AI建议缺少确认阻塞浏览。

<a id="workspace-专用-ocr"></a>
### 专用 OCR

详情中的「画面文字」区复用中性灰按钮和轻量玻璃控件。区分「专用 OCR · 受控预览」、
「视觉模型文字推测 · 尚未经专用 OCR 核验」、已修订、未检出文字、失败/取消；无字不等于未分析。
选择可信的已安装本地OCR环境后，先披露素材数量、预览范围和首次v8升级，再确认执行。
每批最多8份，提供进度与取消；不在浏览时自动推理。支持复制、修订、保存和恢复原识别文字。
修订失败保留草稿，关闭侧栏/切换页面后可继续；关闭素材库前提示未保存修订。
再次识别不覆盖同预览的用户修订，原识别文字可展开核对。窗口/库切换、无服务和错误状态保留。


<a id="workspace-配色与基础信息区域"></a>
#### 配色与基础信息区域

配色条下不再排列HEX、百分比或复制/收藏操作说明。色值与占比保留为色块悬停提示，
单击复制与右键菜单不变，测量来源仍由标题旁简短徽标标明。
来源、尺寸、文件大小、日期、标签与描述紧接配色，默认可见，复用实际编辑能力。
元数据区域只有外侧详情滚动，不再有65vh内层滚动框或overflow隐藏裁切。
标签候选菜单通过独立浮层定位；保留明暗与中性灰样式，键盘/鼠标均可选择，
候选菜单的焦点/阴影不被编辑器裁掉。专注模式同样展示基础信息，不恢复额外折叠层。

<a id="workspace-ai与模型入口"></a>
### AI与模型入口

设置内的“AI 与模型”直接呈现连接与账号，任务模型、本地模型/OCR、后台与高级诊断
各一子页，始终保留设置分类区与返回入口。连接编辑器只有一套 CRUD。旧路由保留别名；技术协议选项
仅高级编辑出现。工程验收预算放高级诊断。账号配置不依赖开库，结果按配置、身份、计划权限、
模型证据分列，不能合为泛化绿色可用。实际屏幕、键盘、主题与宽度资格按验收流程记录，不由本页宣布完成。

<a id="workspace-主窗口与状态行为"></a>
### 主窗口与状态行为

macOS主窗口顶部透明区域与导航空白可用于拖窗，按钮和链接不拖窗；素材滚动由内容接收。系统按钮与视觉位置见DESIGN及实际平台布局，其他平台不继承macOS资格。

区分初次加载、空库、无匹配、首次失败、刷新失败但保留内容、预览不可用和库关闭。切库与关库撤销旧请求和视图，不将失败伪装成空库；文件Copy、用户编辑与恢复保护继续遵循产品契约。

<a id="work-window"></a>
## B悬浮工作窗交互规格

本页是B紧凑、展开、停靠与独立大预览的用户行为契约；不记录二进制身份或PASS。视觉规则见[DESIGN](../../DESIGN.md)，实现分工见[工作模式模块](../../src/main/work-mode/README.md)，交付状态见[CURRENT-STATE](../handoff/CURRENT-STATE.md)。[迁移与历史来源](../history/design-system-restructure-20261013/README.md)保留原文；原记录中的24点阈值、72×160胶囊、展开窗停靠、32点恢复及旧图层/HEX输入不作为当前规则。

<a id="work-window-入口与展示状态"></a>
### 入口与展示状态

工作模式中的工作集打开或恢复同一个原生工作窗，重复打开聚焦该窗。工作集内容与设备窗口布局分别保存；关闭窗不删除工作集，移除成员不删除素材原件，离线或回收站引用保留身份。

- 紧凑态：顶部关闭与菜单常显，中间素材堆叠，底部工作集名称点击展开。顶部空白及周边背景拖窗，素材区域拖出素材；两种拖动不同时触发。具体尺寸与材质由DESIGN定义。
- 展开态：同一窗口的素材网格、色板、工作备注；左上返回收起，右上操作菜单。展开窗移动到边缘保持展开，收起后才能停靠。
- 停靠态：紧凑窗保持原宽高，约84%移到屏外、16%露出。覆盖层模糊并叠加颜色，全部内容按钮视觉退出，停靠抓手接管恢复入口。
- 大预览：按需打开独立窗口，保留既有图片笔记和编辑能力；不等同于悬浮窗的展开态。

默认置顶；没有闲置自动回缩。弹出停靠窗后保持紧凑态，不自动回到屏边。窗口最大数量与成员/颜色上限遵循工作集产品规格。

<a id="work-window-拖动边缘候选与松手"></a>
### 拖动、边缘候选与松手

左右停靠目标分别为`screen.minX − 0.84 × width`、`screen.maxX − 0.16 × width`，不改变尺寸。进度为越出屏幕的距离除以`0.84 × width`，限制到0–1；松手时有越界进度且最后横向增量指向屏外，或进度严格大于0.4，才进入停靠。否则保持或恢复屏内紧凑窗。目标侵入相邻屏幕时拒绝该侧停靠。

展开态、素材拖出期间和程序移动不触发吸附。拖离停靠后保持紧凑尺寸；完全进入屏内保留松手位置，仍跨边则使用同一进度和方向规则。

<a id="work-window-动画与覆盖层"></a>
### 动画与覆盖层

停靠使用EaseOut，按最后拖动事件原始`deltaX`的绝对值选择时长，不解释为点/秒：1–小于1.5用0.6秒，1.5–小于2用0.45秒，2–小于3用0.35秒，其余用0.3秒。弹出使用0.2秒EaseInEaseOut，恢复至对应边缘内侧12 pt。

移动与覆盖层分别管理生命周期；淡入、淡出、内容交互及抓手按停靠阶段交接，移动完成前不让停靠抓手抢先接管。禁止提前缩窗及截图轴向拉伸。窗口背景Liquid Glass与窗内停靠覆盖模糊是不同层次。

新输入中断旧动画，从实际显示位置接管，不跳回旧目标；旧完成不得覆盖新操作。系统减少动态效果适用时减少或关闭过渡，不改变功能终态。设备流畅性须按实际候选与设备验收。

<a id="work-window-素材选择与文本"></a>
### 素材、选择与文本

普通点击单选，Shift逐项增减。拖动已选项保持多选，普通点击释放才缩为单选。Delete/Backspace只移出所选引用；文本输入保持删除文字语义。窗口接受素材拖入，输入控件仍接受普通文本；同时含文件及文本路径的来源不把文件路径写成备注。

⌘V为图片接入入口，不新增粘贴按钮。素材拖出提供独立原件副本，文件任务、取消、接收与原件保护遵循工作集和交付契约，不把拖动手势结束视为接收成功。色板和备注在网格下方，不新增Finder定位、云分享、摇晃或刘海入口。

<a id="work-window-颜色与自动保存"></a>
### 颜色与自动保存

色板“添加”打开参考风格的颜色选择浮层，仅包含饱和度/明度区域、色相条与只读HEX；保存不透明六位HEX。浮层选择是草稿，确认才加入并自动保存；取消、关闭、冻结或退休取消未提交选择，迟到确认不能复活草稿。重复颜色提示并禁止再次添加。

备注、颜色、成员及完整笔记编辑按既有自动保存流程执行。失败或修订冲突保留输入并显式恢复；关窗、退出、切库须处理未结束输入法、未保存编辑与实际文件任务，不能以关闭窗口删除工作集。

<a id="work-window-独立专注预览"></a>
### 独立专注预览

Space只打开或关闭大预览，文本输入仍输入空格；图片切换前保留当前内容直到下一图可用，失败不丢草稿。Shift＋滚轮缩放，普通滚轮不缩放。

工作集专注取消顶部数量/名称及上一张/下一张控件组，关闭在左上；缩略条位于左侧笔记区下方。主资料库专注布局不因此改变。图片笔记按当前成员保存，关闭、切图及取消仍保留文字/绘制草稿保护。

<a id="work-window-仍待确认的设计项"></a>
### 仍待确认的设计项

菜单交付/ZIP是否按“紧凑态全部、展开态有选择时所选、否则全部”决定范围，以及如何明确显示范围与数量，仍是未确认建议；不得作为已批准规则实现。整体性能门槛与原生进程合并策略同样待确认。

## Legacy Library interactions

This note records the read-only recovery page and its user-facing behavior.

<a id="legacy-legacy-read-only-library"></a>
### Legacy Read-Only Library

The page consistently labels the session **Read-only access** and gives a
three-step path:

1. choose a legacy Design Asset Manager `.db` or `.sqlite` file;
2. choose the corresponding asset folder;
3. review counts and confirm read-only opening.

Search and preview remain available after opening. An empty database, an empty
search result, and an unavailable preview use separate messages; none is shown
as successful content recovery. Closing removes the current read-only view.

<a id="legacy-shared-interaction-rules"></a>
### Shared interaction rules

- Existing IPC calls, receipts, grants, and `data-testid` values remain intact.
- Busy and error feedback appears in the section that owns the next action.
- Actions disable while one request is active, preventing duplicate submission.
- UI colors come from the shared workspace variables through
  `WorkspacePrimitives`; these pages do not define theme colors.
