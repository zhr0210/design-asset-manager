# 自适应排列、硬切与图片笔记

2026-09-14。按用户本轮要求，替代上一轮“固定旧卡片宽度/模糊重排”和“专注渐变切换”。
本轮仍为隔离原型；没有写入真实素材库、修改原图或增加正式IPC/schema。

## 布局与查看

侧栏展开时保留原有列数，卡片自动向小缩放并填满剩余宽度，排序不变。
1440×960样例中卡片由约418px缩至313px，三列最右端与剩余网格边缘对齐，没有旧布局造成的
大块留白。原“选中卡片绝对原位置和尺寸”让位于本轮自适应要求，尽量保留纵向视口锚点。
重排仅使用约200ms移动与缩放；没有filter blur。专注模式切图直接替换，无旧图淡出层。

专注模式的快捷操作：

| 操作 | 行为 |
| --- | --- |
| + / −，或滚轮 | 放大/缩小；滚轮以鼠标位置为中心 |
| 0 | 适应窗口并居中 |
| 1 | 原始像素尺寸 |
| 默认手形工具拖动 | 平移画布 |
| 绘图时按住空格拖动 | 临时平移，不画线、不关闭专注模式 |
| 左右键 / 画廊缩略图 | 按打开时的筛选或工作集顺序硬切 |
| Ctrl/Cmd+Z，Shift+Ctrl/Cmd+Z | 当前笔记页的撤销/重做 |
| Delete / Backspace | 删除选中标注；输入框保留文本编辑语义 |
| Escape | 先取消标注编辑或收起便签，再关闭专注模式并恢复来源焦点 |

## 笔记页与便签

图片下方是“原图”、多个笔记页和末尾“添加笔记”的小矩形。笔记页可改名、切换，
每页拥有自己的标注；原图页不显示标注且不可绘图。每份素材独立保存笔记集合。

工具包含画笔、矩形、椭圆、文字、便签、颜色和线宽，支持选中/删除标注及撤销/重做。
画笔和图形通过拖动创建；文字/便签在图片上选位置后输入，点击“保存标注”提交。
便签以图片上的编号点显示，点击后展开文字，还可继续编辑。手形工具状态下也可打开便签。

图像与标注一起缩放/平移。标注用归一化坐标表达，不写入图片字节，不生成覆盖原件。
切换笔记页只切换标注层，切换图片使用其自己的笔记。绘图能力当前针对静态预览；
视频继续使用参考帧功能，未宣称已实现视频时间轴笔记或任意格式原件编辑。

未提交的文字/便签编辑会阻止切图、关闭按钮和整体保存，先应用或取消，避免静默丢草稿。
已提交但尚未整体保存的标注保留在当前页面会话，退出专注再进入仍在；刷新前须显式保存。
保存使用原型专用`dam-focus-notes-prototype-v1`，与工作集/色板键分开。保存失败保持当前内容，
不冒充成功；撤销记录仅属于当前素材的编辑会话，不宣称跨刷新保留。
