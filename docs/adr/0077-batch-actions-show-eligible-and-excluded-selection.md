# Batch Actions Show Eligible and Excluded Selection

Candidate Batch Action flows should show a Batch Selection Summary before
execution when selected candidates have mixed eligibility. Batch Promotion
should apply only to the Eligible Selection of Batch-Eligible Candidates and
leave Excluded Selection Items in Capture Inbox with their exclusion reasons
visible in Batch Inspector. Partial Batch Action copy must state the affected
and skipped counts, such as "promote X, skip Y," so users are never left to
infer whether a batch action handled the whole selection.
