# Structured Assets Persist One Primary Overview

Multi-page, multi-artboard, animated, and other structured visual assets persist exactly one Primary Asset Overview for Asset Grid, Candidate Grid, search results, collections, and immediate Asset Preview entry. Preview Broker enumerates internal visual units through the On-Demand Render Manifest but does not render and store every page, artboard, frame, or sampled analysis unit during import.

Automatic Primary Asset Overview selection is deterministic and evidence-based. A valid explicit cover, poster, or primary-artboard declaration in the source format is preferred; otherwise the format-defined first visible page, artboard, composition, or initial frame is used. Filename, AI tags, semantic appearance, neighboring assets, and popularity do not infer a cover. The selected stable visual-unit identity and selection reason are recorded with preview provenance.

Opening page, artboard, frame, or unit navigation requests thumbnails only for visible navigation items and a small adjacent range. These Unit Navigation Thumbnails enter an evictable Unit Thumbnail Cache keyed by original content, worker/capability version, stable visual unit or time offset, composition/color/alpha generation, rendering policy, destination, and dimensions. It uses byte budget, TTL, LRU, active-navigation pinning, low-disk response, stale-request rejection, and orphan reconciliation. It never expands into import-time all-unit rendering.

Users may create an Asset Cover Selection for one validated page, artboard, visible composition, or frame. The selection is reversible library sidecar metadata and never rewrites the PDF, AI, PSD, TIFF, animation, or other original. Applying it renders a new Primary Asset Overview atomically, updates grid/search/collection presentation after validation, and makes the superseded overview reclaimable after rollback and active-reference checks. Reset returns to deterministic automatic selection.

If a Source Content Generation removes or changes the selected unit, the sidecar becomes Cover Selection Stale, preserves its non-content provenance, and falls back to deterministic automatic selection after validation rather than pointing to the wrong page or frame. A cover-render failure keeps the last valid overview when compatible and exposes retry; it does not activate a partial or blank overview.

Cover choice affects presentation only. It does not change Analysis Coverage Plan, cause AI to treat the cover as the whole asset, confirm tags, alter page order, change animation timing, or imply that hidden layers were analyzed. System Preview Ready requires the active Primary Asset Overview and the artifact's On-Demand Render Manifest; non-primary Unit Navigation Thumbnails may be absent or evicted without affecting readiness.
