# Batch Profile Assignment Is Explicit Compatible And Item Atomic

Batch Profile Assignment is allowed only after the user explicitly chooses one exact Managed Color Profile for the current selection. Profile Compatibility Preflight validates every item independently against the profile color model and channel count, decoded pixel model, supported sample type and bit depth, alpha handling, format worker, and bounded transformation path. Before execution, Batch Inspector shows eligible, excluded, and risk-bearing counts plus item-level exclusion reasons. Incompatible items remain unchanged and cannot be forced into the operation.

The system must not infer or recommend a shared assignment from folder location, filename, extension, pixel appearance, selection majority, neighboring files, or an existing assignment on another item. The chosen profile content hash and explicit user intent are recorded once for the operation, while each successful Sidecar Profile Assignment retains item-specific provenance and preceding evidence state.

Execution is item-atomic rather than all-or-nothing across the selection. Each eligible item commits its new assignment and Color Derivation Generation only after its own validation succeeds; one failure does not roll back successful items or activate partial derived media for the failed item. Mixed results reuse Inline Batch Result and Batch Result Detail to report succeeded, excluded, and failed items with stable reasons and focused retry. A batch undo or reassignment applies only to successfully changed items and restores each item's own preceding assignment or evidence state.
