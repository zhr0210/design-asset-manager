# Asset Workspace Defaults to Asset Grid

The Asset Workspace should open by default in a dense Asset Grid with
Collection Group navigation on the left. ADR 0026 supersedes this ADR's earlier
right-side Capture Inbox placement: Capture Inbox uses a dedicated left-side
Workspace Entry and Candidate Review Page, while the right side remains
Inspector space. Collection Board remains a first-class mode for project
review, moodboards, inspiration boards, and creative arrangement, but it
should not be the default entry view.

This prioritizes the application's core job: managing, finding, comparing, and
confirming large volumes of design assets efficiently. Users can switch into
Board mode when they want a more spatial, editorial, or presentation-oriented
workflow without sacrificing everyday library speed.
