# Original Artifacts Have No Fixed Size Cap

Once a format has Capture Format Capability, Candidate Artifact acceptance must not impose a fixed product-level byte-size cap on the original, so large PSD, layered TIFF, and other professional assets can be preserved intact when their format paths are introduced. Gateway fetch and producer upload stream directly into managed candidate storage under Capacity-Aware Artifact Admission, which protects a dynamic Storage Safety Reserve instead of buffering the whole file or enforcing an arbitrary 100–500 MB ceiling. Original integrity validation remains separate from derived preview work. Thumbnail, metadata, and preview generation run under an isolated Derived Media Budget for memory, time, and decoder work; exceeding that budget produces Preview Deferred or preview-unavailable state without deleting, transcoding, or by itself rejecting an otherwise safe original Candidate Artifact. Corrupt, mismatched, dangerous, or storage-exhausting input still fails explicitly, and format support remains gated by ADR 0119 rather than inferred from file size. ADR 0146 applies the same reserve to storage accounting while keeping originals outside every cache cleanup path.
