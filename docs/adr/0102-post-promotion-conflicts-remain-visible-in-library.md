# Post-Promotion Conflicts Remain Visible in Library

Post-Promotion Conflict Carryover should remain visible after an Asset
Candidate becomes a Design Asset. Asset Grid cards may show Asset Conflict
Carryover Badge, Asset Inspector should expose an Asset Inspector Conflict
Section, and the library should provide a system Library Conflict Smart Filter
for unresolved carried-over conflicts. Carryover Resolution should reuse the
Conflict Review Surface with Design Asset context, so low-risk conflicts can be
resolved after promotion without being hidden or forcing users back into
Capture Inbox.
