# Referenced Source Delete Undo Reuses Receipt-Scoped Restore

After Delete Referenced Source File succeeds, the application exposes **Referenced Source Delete Undo** for 30 elapsed seconds. Invoking it within that window submits the same explicit, receipt-scoped Restore Referenced Source File operation available from Asset Trash; it is not a filesystem rollback, a separate fast path, or a promise that the operating-system trash item is still recoverable. Once accepted before the deadline, the restore request may finish after the affordance expires. If the user does not invoke it, the Design Asset and its governed restoration state remain available through their normal Asset Trash lifecycle.

The restore request still applies ADR 0295 receipt and platform verification, ADR 0296 destination-conflict handling, and ADR 0071 if a separate Design Asset conflict remains. A conflict opens the normal explicit resolution flow; missing evidence, an unavailable trash item, unsupported context, or failed validation reports the truthful restore outcome and never repeats deletion, chooses another trash item, overwrites a file, or silently falls back to relink. Dismissing the feedback, closing or restarting the application, switching libraries, or letting the 30-second window expire removes only the transient undo affordance and does not retire the receipt or shorten Asset Trash retention.

For a batch, undo applies independently only to Design Asset items whose source deletion succeeded, following ADR 0078's successful-item boundary and ADR 0079's separation of failure recovery from undo. ADR 0346 makes a successfully deleted Referenced Compound Original one eligible item whose Referenced Compound Source Delete Undo requests restoration through its complete receipt set; individual members and partial group deletion recovery are never independently eligible. Each item executes the same restore workflow and the result reports restored, conflict/attention, failed, and no-longer-eligible outcomes without pretending batch atomicity or rolling back another item's completed restoration. The current project has no Asset Trash, referenced-source operation journal, receipt persistence, platform restore adapter, or this undo affordance. This ADR records target architecture only and accesses or changes no runtime/user file, public IPC, database schema, or AI Worker API.
