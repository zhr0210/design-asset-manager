# Referenced Source Path Batch Undo Only Reverses Eligible Simple Relocations

When a Referenced Source Path Batch finishes its execution pass and first presents its result, **Referenced Source Path Batch Undo** is available for 30 elapsed seconds only when at least one single-file item successfully completed a simple same-volume relocation into a vacant or reviewed unique-name path without displacing another file. The affordance identifies the eligible count and excludes cross-volume transfers, ADR 0345 Referenced Compound Source Path Operations, identical-destination adoption, destination replacement, conflict-review, failed, recovery and cancelled items because those outcomes either made no reversible path change or require their own explicit group operation or recovery boundary.

Invoking the affordance within the window requests an independent freshly validated reverse Relocate Referenced Source for every then-eligible item under ADR 0313. Each reverse relocation commits separately: one newly occupied prior path enters that item's Referenced Source Relocation Conflict Review, and changed or unprovable evidence makes only that item no longer eligible. Neither condition blocks, rolls back nor changes the result of another reversal. The batch-undo result truthfully groups reversed, conflict-review, failed, no-longer-eligible and excluded items instead of claiming an atomic rollback; cross-volume movement back remains a new explicitly confirmed transfer under ADR 0309.

A request accepted before the deadline may finish afterward. Expiry, dismissal, restart or Library Switch removes only the transient batch affordance and performs no file action; ordinary relocation, transfer and Local File Recovery entry points remain governed by their own lifecycles. The current application has no referenced-source path batch, reverse-relocation coordinator or batch-undo result surface. This ADR records target architecture only and accesses, copies, restores, moves, renames, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
