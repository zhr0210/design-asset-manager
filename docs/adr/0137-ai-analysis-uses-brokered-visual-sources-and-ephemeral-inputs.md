# AI Analysis Uses Brokered Visual Sources and Ephemeral Inputs

Every declared non-text visual Capture Format Capability is eligible for AI analysis through an Analysis Visual Source produced or validated by Preview Broker. The source has validated composition, orientation, dimensions, alpha evidence, decoder provenance, and color state before a model adapter receives pixels. When Authoritative Color Evidence exists, the analysis source is converted into tagged sRGB RGB samples through the active Color Derivation Generation. Unprofiled Color remains analyzable through explicitly unmanaged RGB samples, but neither Preview Broker nor a model adapter may relabel those samples as sRGB or infer a missing profile; color-dependent results retain an Unprofiled reliability warning. P3 display media remains available for human preview but is not a separate AI input lane.

ADR 0182 external Search By Image uses the same boundary through an explicitly granted Ephemeral Query Visual Source. That one-session source is not a Candidate or Design Asset, is never imported by implication, and receives no durable analysis result or persistent proxy; its temporary renders and query vector follow the stricter query-session cleanup rules.

The contract standardizes pixel meaning, not one permanent resolution or one file per model. Common safe bitmaps may decode directly into memory when the broker validates that path. PSD, PSB, layered TIFF, RAW, AI, PDF-compatible artwork, and other routed formats reuse their existing sRGB System Preview or broker render rather than writing an additional full-size AI copy. Each model adapter applies its required resize, padding, channel normalization, and encoding in memory. Global tagging or classification may use a bounded overview, while OCR, small visual elements, and large canvases may request deterministic crops or preview tiles so a 512-pixel Grid Thumbnail never becomes the universal quality ceiling. Transparent sources use the related dual-background Analysis Input Views defined by ADR 0139 instead of silently losing alpha. Remote-provider JPEG or PNG request payloads and local tensor inputs are ephemeral and are released after the request or job.

Model-specific input images are not persisted by default. Under ADR 0168, a waiting Analysis Intent contains no visual input and Preview Broker does not generate one merely because a model/runtime/storage capability is missing. Repeated admitted work may opt into one shared, replaceable Analysis Proxy Cache instead of separate caches for each provider. Its content-addressed key includes original content hash, Preview Fidelity and decoder capability revision, Color Derivation Generation or explicit Unprofiled state, analysis recipe identifier, and the selected page, artboard, frame, or tile scope. A changed original, profile assignment, composition renderer, preview capability, or analysis recipe therefore creates a new key and makes older proxies evictable without ambiguous in-place reuse.

Analysis Proxy Cache cleanup combines a byte budget, time-to-live, least-recently-used and regeneration-cost-aware eviction, low-disk-pressure eviction, active-job pinning, immediate disposal of one-use intermediates, and startup orphan reconciliation. Periodic cleanup is a backstop rather than the only reclamation mechanism. ADR 0146 exposes this as a distinct user-visible storage class with Auto or explicit budget and TTL controls. Cleanup may delete only reproducible analysis proxies; it never deletes Original Assets, required System Preview media, active job inputs, or durable AI results such as embeddings, tags, captions, OCR output, palettes, and their model or recipe provenance. Analysis results are invalidated or recomputed according to their own source and recipe generation, not kept valid merely because an old proxy file still exists.

All AI providers consume this boundary. Direct provider-specific opening of arbitrary original paths is legacy behavior to remove because it makes format coverage, color handling, orientation, resource safety, and invalidation inconsistent. Structured visual assets select and report their Analysis Unit coverage under ADR 0138; one successful overview never implies exhaustive page, artboard, layer, or frame analysis. Support claims require fixtures proving that each declared visual format reaches the same model-adapter contract or produces a structured analysis failure; a filename extension alone never proves eligibility.
