# System Preview Uses Master Display And Tile Levels

Professional-format System Preview must preserve full composition fidelity while separating storage and display workloads. ADR 0147 supersedes permanent full-source-dimension sRGB and P3 preview files: PSD, PSB, layered TIFF, and similar sources persist a faithful approximately 512-pixel overview, while full detail is rendered from the read-only original through an isolated On-Demand Render Manifest. Under ADR 0149, an approximately 2048-pixel Quick Preview appears only opportunistically from a validated embedded or already-produced raster and remains evictable rather than triggering separate import-time render work. A validated Embedded Composite Preview may accelerate the overview when its dimensions and composition metadata match, but it cannot replace artifact-specific validation of the full-detail worker path. Visible regions, zoom levels, pages, artboards, or frames generate only the requested sRGB or eligible P3 tiles, and a bounded Preview Tile Cache replaces a permanently complete Tiled Preview Pyramid. Every preview artifact is replaceable derived media and never mutates the professional original.
