# Color Profile Conflicts Require Reviewed Promotion

Color Profile Conflict is Required Review because multiple usable color declarations disagree and the system has no authority to choose among them. A conflicting candidate is excluded from Quick Promote and default Batch Promotion, but it is not permanently barred from the Asset Library when the original is safe, artifact and composition validation pass, and a validated Unmanaged Structural Preview is available. Promotion Sheet exposes each conflicting evidence source, validation result, declared color space, and provenance without presenting an automatically preferred winner.

The user may explicitly select one valid Source Color Profile or choose to keep the conflict unresolved. Selecting a profile records the user decision, validates the resulting color transform, and regenerates replaceable color-managed derivatives without modifying the original. Keeping the conflict unresolved permits reviewed Candidate Promotion with the Unmanaged Structural Preview and carries the Color Profile Conflict, Color Accuracy Warning, and evidence provenance into the Design Asset. The unresolved state reuses Post-Promotion Conflict Carryover, Asset Inspector Conflict Section, and Library Conflict Smart Filter rather than becoming an invisible informational label.

The system must never resolve the conflict through metadata precedence, pixel appearance, filename convention, platform defaults, or successful decoding alone. Failed file-safety, artifact-integrity, composition-rendering, or selected-profile transform validation remains blocking and cannot be overridden by reviewed promotion.
