# Cross-Volume Transfer Collisions Open Visual Conflict Review

If the intended final path becomes occupied before Referenced Source Transfer Staging publishes, the application opens **Referenced Source Transfer Conflict Review** instead of overwriting, silently suffixing, discarding staging or treating the occupant as the transfer result. The dedicated page compares the current transfer source and destination occupant with validated visual previews where available, safe filenames and locations, format, size, dimensions/structure, modification evidence and a clear complete-content relationship. Missing or unsafe preview evidence remains explicit and never weakens file identity checks. The current source and staging remain protected, and the old source is not moved to trash while review is unresolved.

When complete validation proves the occupant byte-identical to the expected Source Content Generation, **Use Existing Identical Destination** is the recommended but still explicit choice: it adopts that file as the same Referenced Asset's new source and removes only the proven duplicate staging. For a different or unverified occupant, **Publish Transfer With Unique Name** is recommended and presents a safe unoccupied suggested name that the user may review or edit before fresh validation and publication. The page also offers **Replace Transfer Destination**, Choose Another Destination and Cancel Transfer. Replacement is destructive, never preselected, and must enter its own consequence-specific confirmation. ADR 0305 moves the occupant to operating-system trash before publication and forbids permanent overwrite; recovery after trash success followed by publication failure remains a child decision.

Every choice is rebound to current source generation, staging, destination volume, directory and occupant identity immediately before execution. Drift returns to the updated conflict review instead of applying a stale choice. Unique naming never creates another Design Asset or changes Source Content Generation, and no remembered choice, batch default, prior collision, filename resemblance or identical-content detection executes an option automatically. The current application has no referenced-source transfer model, staging publisher or visual transfer-conflict page. This ADR records target architecture only and inspects, previews, renames, replaces, publishes, removes or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
