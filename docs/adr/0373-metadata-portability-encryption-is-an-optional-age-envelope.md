# Metadata Portability Encryption Is An Optional Age Envelope

Metadata Portability Export defaults to an **Open Metadata Portability Export** because its primary purpose is explicit interchange with documented third-party schemas and tools. Metadata Portability Export Review lists every selected metadata, OCR, description, provenance, relationship, region, vector and other data class plus destination consequences before that unencrypted choice is confirmed. Open output remains the ordinary `.dammeta`, `.json` or `.csv` representation and makes no confidentiality claim.

The user may instead choose **Encrypted Metadata Portability Export**, which wraps the complete already serialized logical export in the publicly documented age passphrase-encryption format and publishes `.dammeta.age`, `.json.age` or `.csv.age`. Encryption covers the complete inner file, including the `.dammeta` manifest, record/payload names, counts, schemas and checksums, rather than encrypting individual ZIP entries or leaving a plaintext catalog. Only unavoidable outer file existence and approximate byte size remain visible. Decryption yields the exact ordinary inner representation; encryption never changes, forks or privately extends its schema.

The passphrase is entered and confirmed in an application-owned surface and held in memory only for the bounded export/verification operation. It is never written to the output, library database, settings, logs, telemetry, crash reports, subprocess arguments, environment variables, clipboard history or application account and is not remembered in the operating-system credential store. There is no recovery backdoor, vendor escrow, reset link, device-bound key requirement or fallback derivation from the user's login. The confirmation explicitly states that a forgotten passphrase makes the encrypted export unrecoverable and recommends the user's chosen password manager.

The implementation uses a vetted maintained age implementation and the standard passphrase recipient mode with fresh cryptographic randomness and bounded parameter validation. It streams the complete inner artifact through authenticated encryption, finalizes operation-owned destination staging and verifies that the encrypted output can authenticate/decrypt to the expected inner identity before publication. Wrong passphrase, truncation, modification, unsupported parameters or authentication failure never falls back to parsing ciphertext, partial plaintext or treating an encrypted package as an open ZIP.

Cancellation or failure removes only proven operation-owned plaintext/encrypted staging and passphrase memory. A destination occupant is never silently overwritten or renamed, and encrypted/open collision choices remain ordinary visual destination review. Public progress and notifications expose only opaque operation identity, open/encrypted mode, aggregate bytes and terminal status, never the passphrase, KDF material, selected field names, asset names, destination path or authentication internals.

This open-by-default policy deliberately differs from ADR 0186 Full Library Backup, which defaults to encryption because it necessarily contains originals and broad authoritative library state. Metadata Portability Export is a field-selected interchange artifact; choosing open output remains explicit and informed, while age provides a portable whole-file confidentiality option without making ecosystem support depend on this application.

The current application has no open/encrypted portability choice, age envelope writer/reader or export-passphrase surface. This ADR records target architecture only and selects, serializes, exports, packages, compresses, encrypts, decrypts, attaches, imports, stages, writes, rewrites, converts, moves, deletes or changes no runtime/user file, credential, sidecar, directory, database, cache, backup, metadata value, analysis result or source relationship and changes no public IPC, database schema or AI Worker API.
