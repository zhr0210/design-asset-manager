# Trash Duplicates Are Weak Duplicate Signals

Duplicate Signal Scope should prioritize Active Candidates and non-deleted
Design Assets for strong duplicate review. Asset Trash may participate only by
creating a weaker Trash Duplicate signal, explaining that the item appears to
have been deleted before and can be restored from Asset Trash or continued as a
new item. Trash Duplicate should not block Quick Promote by default, but it
should be visible in Promotion Sheet and inspector contexts so users can make
an informed choice without letting deleted assets dominate normal review.
