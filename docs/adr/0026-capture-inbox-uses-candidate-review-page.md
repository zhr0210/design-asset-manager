# Capture Inbox Uses a Candidate Review Page

Capture Inbox should be reached from a dedicated left-side workspace entry and
should present asset candidates in a Candidate Review Page, not as a default
right-side panel. Users select, filter, compare, confirm, reject, and batch
organize candidates in that page, while the right-side Asset Inspector shows
details for the currently selected candidate or selected design asset.

This supersedes ADR 0012 and ADR 0020's earlier right-side Capture Inbox
placement. The new boundary keeps the right side dedicated to inspection,
gives capture review enough space for batch work, and still keeps candidate
details consistent with the normal Asset Grid selection model.
