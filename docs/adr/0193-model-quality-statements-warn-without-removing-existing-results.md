# Model Quality Statements Warn Without Removing Existing Results

A signed Model Trust Statement, publisher quality notice or bounded locally verified quality finding may stop a model from producing new work under ADR 0165, but it has no authority to rewrite the user's committed library state. Existing model-generated tags, OCR, descriptions, palettes, embeddings and other durable results remain visible, active and searchable with their original values, scores, generation identity and exact model/runtime/recipe provenance. The application does not hide, quarantine, de-rank, suppress, detach or delete them merely because a later statement questions model accuracy, calibration, bias, privacy, integrity or output quality.

Precisely scoped evidence creates a non-blocking **Model Result Advisory** on the affected model/result generation. The advisory records only trusted statement identity, reason category, affected generation/capability/scope, issue/freshness state and remediation availability; it does not copy result content. ADR 0194 centralizes scope/actions in Model Library and AI Console, shows only contextual Result Provenance Advisory in Asset Inspector, keeps grid/search rows free of default repeated badges and offers an explicit opt-in filter without changing retrieval/ranking or stored results.

The user owns the response. For the affected scope the application offers **Keep Existing Results**, explicit ADR 0143 deletion, or a separately previewed ADR 0145 Analysis Result Migration/Reanalysis Plan when a compatible chosen model is available. No option is preselected as a destructive action, no catalog refresh starts reanalysis, and acknowledging/dismissing the advisory is not permission to delete or replace values. Batch operations show affected counts and result classes; embeddings retain their model-space/index boundaries until the user explicitly migrates or deletes them.

Newly generated replacement results do not silently overwrite user-authored or previously committed values. They enter the existing generation-aware projection/migration rules, preserve old provenance through its normal user-controlled lifecycle and keep user-authored tags, corrected OCR, descriptions, suppressions and manually attached embeddings untouched. A model update, safe fallback or runtime repair does not prove old results wrong or equivalent to new results.

Critical model/runtime security revocation may still block future execution, model loading and affected in-flight uncommitted output for containment. It does not retroactively change committed-result visibility or search participation. Structurally unreadable/corrupt database or index bytes remain an integrity/recovery problem rather than a catalog quality declaration; this ADR does not require the application to execute malformed data, but it also does not authorize silent deletion.

ADR 0185 Full Library Backup continues to include committed durable results and their provenance regardless of advisory state. Restore does not auto-download a replacement model or auto-reanalyze advisory-bearing generations. The advisory can be restored from included non-secret provenance/trust identity when present or reconciled from current signed catalog state without altering result content.

The current project has no Model Result Advisory projection, generation-level warning/filter, affected-count action or user-owned keep/delete/reanalysis review flow. Existing ADR text previously described Invalidated Analysis Generation removal from active projections/search; ADR 0193 supersedes that automatic-removal behavior while retaining future-execution containment. This documentation change reads/modifies no model, result, index, asset or runtime data and changes no public IPC/schema/AI Worker API.
