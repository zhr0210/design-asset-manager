# Restore Instead Supersedes Current Candidate

When a user resolves a Trash Duplicate with Restore Instead, the matched Asset
Trash item should run Asset Restore and the current Asset Candidate should
leave active review as a Superseded Candidate. Its Cleanup Reason should be
Restored-Instead Cleanup, it should enter Capture Cleanup History with the
normal 7-day Recoverable Window, and Candidate Cleanup Feedback should explain
that the deleted Design Asset was restored instead. Restoring the Superseded
Candidate later should not automatically delete or alter the already restored
Design Asset.
