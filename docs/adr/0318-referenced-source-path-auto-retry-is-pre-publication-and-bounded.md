# Referenced Source Path Automatic Retry Is Pre-Publication And Bounded

**Referenced Source Path Automatic Retry** is permitted only after a classified transient failure in evidence-stable read, copy or complete-verification work before final-path publication. One item receives at most two automatic retries after its initial attempt, for three total attempts, with increasing delay. Every attempt reacquires its ADR 0317 volume lanes and proves the same Design Asset, Source Content Generation, source, destination boundary and operation-owned staging; a cross-volume retry resumes a proven ADR 0303 checkpoint when safe or restarts only after its exact staging is safely resolved. Restart or reconnection reconciliation does not reset this budget or count as a new retry merely for proving and resuming an unchanged checkpoint.

No automatic retry is allowed for destination conflict, permission or capacity failure, unavailable volume, changed or ambiguous evidence, publication, replacement, operating-system trash, old-source cleanup, relationship commit or any call whose outcome may already have changed user files. Those items enter their existing conflict, failure, partial-success or recovery state. In particular, Retry Old Source Cleanup remains a fresh explicit destructive request under ADR 0302, and neither startup nor the scheduler repeats it.

**Retry Failed Source Path Items** is a manual batch-result action that selects only currently failed items whose present evidence classifies them as safe to try again. It revalidates and executes each item independently, does not reset or hide exhausted automatic-retry history, and never includes succeeded, cancelled, conflict-review, recovery or ambiguous items. A retry result merges into the original Referenced Source Path Batch Result with current attempt evidence rather than creating an apparently unrelated operation or rerunning the whole selection. The current application has no referenced-source path batch or this retry classifier and budget. This ADR records target architecture only and accesses, creates, copies, removes, restores, moves, renames, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
