# Default Automatic Analysis Has Four Capability Intents

Scope clarification under ADR 0483: these four automatic model intents are not
the complete core feature list. Deterministic palette/proportion analysis supplements
them; core prompt reconstruction is normally on demand or in a disclosed configured
batch. Advanced segmentation/layer work stays optional and outside this default.

The default Baseline Automatic Analysis Profile creates local Analysis Intents for four independently controlled capabilities on every newly activated or materially changed supported non-text visual Candidate or Design Asset: Tag Suggestions, semantic Embedding, bounded OCR, and one Short Description. Eligibility comes from the declared visual format/Preview Broker path, not filename extension or a small-format allowlist. The profile does not download models, install runtimes, use external providers, block Candidate Promotion, or fabricate a result when a capability is unavailable; ADR 0168 waiting reasons remain valid per capability.

Automatic Analysis Capability Toggles expose a master local-automatic-analysis control plus separate Tagging, Embedding, OCR and Short Description controls. Turning a capability off prevents new intents and pauses its existing automatic intents under ADR 0168 without deleting completed results, user-authored values or intent history. Turning it back on resumes compatible pre-existing paused intents and applies to future/newly changed assets, but does not silently enumerate the completed historical library. Each capability retains its own Active Capability Model, recipe, coverage, failure and result lifecycle.

Baseline scope uses the Primary Asset Overview and ADR 0138 bounded deterministic representative coverage for structured sources. OCR may request bounded deterministic crops or tiles needed to read likely text regions, but large-canvas exhaustive tiling, every page/artboard, per-frame animation, individual layer analysis, extended OCR, long captions and model ensembles are not Baseline Automatic Analysis. They require an explicit visible action or a separately enabled Idle Extended Analysis policy and continue to use resource, coverage, storage and privacy admission. Idle Extended Analysis is opt-in rather than implied by enabling the baseline.

Materially changed means a new validated Source Content Generation or another change that invalidates the capability's Analysis Visual Source, coverage or recipe evidence. Renaming, moving between collections, changing unrelated tags, opening a preview, reconnecting storage or installing/switching a model does not by itself create fresh baseline intents for completed assets. Source/recipe generation deduplication and supersession follow ADR 0168, while model changes follow ADR 0145 rather than masquerading as content change.

Enabling a capability for an existing library offers an explicit Analysis Backfill Plan instead of immediately creating library-wide intents. The plan previews selected scope, eligible/already-current/stale/excluded/waiting counts, expected Analysis Units and coverage, active model/runtime, estimated compute/time/energy when evidence permits, additional result/index/cache storage, proxy behavior and embedding migration implications. The user chooses selected assets, collections or whole library and confirms; cancellation creates no backfill intents. A backfill plan never installs a missing model or authorizes external upload.

Each capability defines Valid Empty Analysis Result separately from failure or unavailable state. OCR may record No Text Detected only after its declared detector, ADR 0178 language/script capability and coverage complete; unsupported or undetermined visible script is Partial Coverage or waiting, not empty. Tagging may record No Qualifying Suggestions when all outputs fall below a versioned accepted threshold; Short Description may record No Reliable Description only when its recipe explicitly supports an abstention outcome. Embedding has no valid empty vector: wrong dimensions, non-finite output, missing normalization or no vector is failure. Empty evidence retains model/recipe, scope, coverage, threshold or abstention reason and prevents immediate redundant reruns of the same generation without pretending content was found.

Model/provider silence, malformed output, timeout, missing capability, skipped units or incomplete coverage cannot be converted to a valid empty result. A structured source may have an empty result for one analyzed unit while remaining Partial Analysis Coverage overall. Asset Analysis Projection distinguishes no evidence, waiting, failed, valid empty, partial and result-present states. Tags remain unconfirmed suggestions under ADR 0016, OCR and descriptions preserve unit/view scope under ADR 0140, and embeddings remain bound to their exact model space under ADR 0144.

Baseline and backfill intent controls are visible in Settings and AI Console, with per-asset state in Asset Inspector. Defaults are disclosed during onboarding or first use; no missing model is installed as a side effect. ADR 0170 may offer one explicit reviewed Local AI Starter Setup Plan for all four baseline capabilities, but completing it reconciles only waiting and future/newly changed work; historical analysis still requires this ADR's separate Backfill Plan. All stored queue summaries remain path-free and content-free, while completed values follow ADR 0143 manual add/edit/delete and retention rules.
