# Asset Organization Is Search-First And Does Not Require Classification Completeness

Professional independent designers need assets to become discoverable without first maintaining a complete filing system. Design Asset Manager therefore uses **Search-First Organization**: technical admission proves source integrity, identity, ownership and preview readiness, while classification completeness is never an admission, promotion, search or Original Handoff gate.

An asset may remain in the protected Unsorted Collection indefinitely as an ordinary valid state. Unsorted is a neutral fallback membership, not an error, unresolved Review Signal, mandatory queue or claim that the asset is less reusable. It creates no attention badge by itself. Users may browse or explicitly filter Unsorted whenever useful, but the application does not make filing a default recurring review obligation.

Asset Collections, Collection Groups, tags, ratings, descriptions and other authored metadata are optional organization and retrieval layers. Their absence does not make an otherwise valid Design Asset incomplete. ADR 0439 likewise prevents a preserved Out-of-Constraint Custom Field Value from becoming an admission gate when its definition and ownership remain compatible. Automatic or AI-derived tags, OCR, descriptions and embeddings may improve search progressively, but unavailable, pending, rejected or deleted enrichment never fabricates a classification requirement. Users retain the manual controls and provenance boundaries of ADRs 0016 and 0143.

ADR 0445 applies the same boundary to repeated Text Custom Field Values:
duplicate discovery is an optional filter workflow and never a schema-level
uniqueness or Promotion gate.

Candidate Promotion may assign the ADR 0033 Unsorted fallback automatically when no explicit, mapped, suggested or contextual collection target exists; the user does not have to choose a collection or confirm enrichment merely to promote. Capture Inbox remains responsible for acquisition validation, integrity/ownership conflicts and optional review, not a mandatory curation-completion queue.

The product does not compute or enforce a generic reusable/not-reusable status. Search follows normal lifecycle visibility and returns available or action-restricted matches with truthful state; later source-dependent actions apply their own availability and safety gates. ADR 0277 applies the same distinction to cross-library discovery.

ADR 0475 applies this boundary to an unexpectedly Ineligible Static Custom
Field Default. It creates one definition-level repair state, not per-owner
classification failures, and new owners remain valid with Missing while that
future-write rule is suspended.
