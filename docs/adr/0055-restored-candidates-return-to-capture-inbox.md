# Restored Candidates Return to Capture Inbox

Candidate Restore should return a cleaned asset candidate from the Recoverable
Window to the active Capture Inbox as a Recovered Candidate. It should not
promote the candidate into the Asset Library or bypass candidate review.

Recovered Candidates should keep their original source context, analysis
output, Tag Suggestions, Duplicate Signals, and Capture Batch record, and they
should show a recovered state indicator. This gives users a safety net after
cleanup while preserving the same review gates required for normal Candidate
Promotion.
