# Cross-Format Source Change Blocks Active-Library Relationship Conflicts

Status: Superseded by ADR 0348.

Before **Use Exported File as Current Source** commits anything, it revalidates the active library's authoritative current-source relationships. If the selected file is already the same Design Asset's current source, the action is a no-op: it creates no Source Content Generation and performs no old-source cleanup. If that file is the current source of another Design Asset in the active library, **Referenced Source Relationship Conflict Review** blocks relationship commit and old-source trash because silently giving two independently managed assets one writable source would make later rename, move, rewrite and delete behavior unsafe.

The conflict review identifies the two Design Assets and the exact relationship evidence without merging their metadata. Its recommended action is Cancel; the other complete path is to choose or create a different Compatible Export at a safe location and restart the full ADR 0323 validation. The source-change flow never automatically copies, renames, detaches, relinks, merges, trashes or rewrites either asset to resolve the conflict. A future Merge Design Assets capability, if designed, remains a separate explicitly confirmed workflow rather than an escape action inside this review. Changed conflict evidence invalidates the review and requires fresh validation.

Available registered-library evidence may also show that another library relates the proposed file to one of its Design Assets. That produces a **Known Cross-Library Source Relationship Warning**, including which available libraries are known to be affected and the consequence that edits from either library can change the same user-owned bytes. It does not block the active library's explicit source change and grants no authority to activate, detach, merge, relink or modify another library. Unavailable libraries are explicitly reported as unchecked, and no warning is ever presented as proof that no other library uses the file; the application does not perform an exhaustive disk scan or invent global source ownership.

Restart or resume repeats both checks from current evidence. A prior warning or conflict decision never preauthorizes the relationship commit, and an unknown cross-library relationship discovered later does not retroactively merge identities. The current application has no cross-format source-change relationship review or cross-library source warning. This ADR records target architecture only and searches, activates, accesses, creates, copies, relinks, merges, moves, rewrites, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
