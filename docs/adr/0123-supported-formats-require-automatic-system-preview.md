# Supported Formats Require Automatic System Preview

A format must not be declared supported until the backend can automatically generate a faithful System Preview on both macOS and Windows. Large PSD, PSB, layered TIFF, RAW, AI, and similar professional originals enter the format-routed Preview Broker defined by ADR 0136 rather than relying on one universal decoder. Candidate Activation may expose temporary Preview Deferred state while automatic work runs, but Candidate Promotion, Quick Promote, and Batch Promotion all require System Preview Ready. ADR 0275 Progressive Reference Indexing likewise admits a discovered source into normal Asset Grid results only after source validation and System Preview Ready; pending and failed items remain visible through scan progress or Reference Scan Exception surfaces rather than broken asset cards. Under ADR 0147, professional-format readiness means a validated persistent overview plus an artifact-specific On-Demand Render Manifest, not permanent full-size JPEG or PNG derivatives. When Authoritative Color Evidence is absent, a validated Unmanaged Structural Preview may satisfy the overview requirement under ADR 0127 while retaining an explicit color-accuracy warning; absence of color evidence is not the same as failure to render composition. Under ADR 0135, a valid sRGB preview baseline and render path can satisfy readiness while P3 rendering is degraded. A deterministic failure that leaves no valid required overview or render path becomes Preview Generation Failure and a Capture Format Capability regression that must be fixed in the backend; it cannot become a tolerated permanent Preview Unavailable state or be bypassed with manual promotion. Preview artifacts remain replaceable derived media, separate from original file ownership and integrity. Optional AI analysis never participates in this admission gate.

For an already admitted ADR 0340 Compound Original, ADR 0342 retains the last valid System Preview as identification evidence when a member later disappears or becomes invalid. That retained evidence does not represent current System Preview Ready state, satisfy complete Original Handoff, or bypass Compound Original Recovery/degraded-member restrictions. A repaired or changed group must revalidate its complete applicable member set before a current-generation preview can become ready again.
