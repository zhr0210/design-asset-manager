# Structured Visual Assets Use Explicit Analysis Coverage

Multi-page, multi-artboard, animated, layered, and other structured visual assets use an explicit Analysis Coverage Plan rather than pretending that one thumbnail represents the entire source. Preview Broker enumerates the visual structure that its format capability can validate, including total pages, artboards, frames or duration, visible composite availability, and fidelity limits. The plan selects Analysis Units deterministically and records both selected and omitted scope before model execution. A sampled result is labeled Partial Analysis Coverage and cannot be presented as exhaustive analysis of the asset.

ADR 0169 Baseline Automatic Analysis begins with the primary visible composite or overview. Multi-page and multi-artboard sources then receive bounded representative sampling that includes the primary unit and deterministic positions across the declared sequence; animation receives the initial rendered state plus bounded duration-aware key frames or scene-change samples, with evenly spaced deterministic fallback when scene evidence is unavailable. This bounded sampling may serve enabled baseline capabilities, while exhaustive units and per-layer work remain explicit or separately enabled Idle Extended Analysis. The plan records total unit count or duration, selected stable unit identifiers or time offsets, selection recipe and version, sampling budget, completion state, and reasons for any unit Preview or Analysis Failure. Semantic importance is not guessed from filenames, layer names, visual appearance, or neighboring assets. A user-selected ADR 0150 cover changes presentation only and does not narrow, expand, or imply analysis coverage.

Users and task-specific workflows may request Exhaustive Page or Artboard Analysis. Exhaustive means every declared page or artboard reaches a terminal analyzed or structured-failure state; it does not silently skip failed units and still claim complete coverage. Work is progressive, resource-bounded, resumable by stable Analysis Unit identity, and allowed to reuse Analysis Proxy Cache entries under ADR 0137. Asset-level results use the evidence-preserving projection defined by ADR 0140, aggregate only terminal unit results, and retain coverage evidence, model and Analysis Recipe versions, and failed or omitted counts so later added coverage can replace or extend the aggregate reproducibly.

Layered sources default to their validated visible composite. Individual visible or hidden layers are authoring internals and are not analyzed automatically because standalone rendering may change clipping, masks, blending, effects, fonts, linked content, and intended privacy. Layer Analysis requires an explicit user or specialized-workflow request plus a format worker capable of faithful per-layer rendering; unsupported effects and missing dependencies remain fidelity evidence. Animation similarly does not analyze every frame by default, while an explicit exhaustive-frame workflow may be added only with its own resource and storage policy.

Analysis Unit scope is part of the Analysis Recipe and Analysis Proxy Cache key. Results retain Complete, Partial, or Failed coverage status independently from whether some tags, captions, OCR text, embeddings, or palettes were produced. A later change to source structure, Preview Fidelity capability, sampling recipe, color generation, or requested coverage creates a new analysis generation instead of mutating prior coverage evidence in place.
