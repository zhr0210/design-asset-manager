# Local File Recovery Survives Forgotten Library Registration

**Local File Recovery** is a dedicated device-local utility surface that lists only application-created Transfer Destination Replacement Receipts, Relocation Destination Replacement Receipts, Conversion Destination Replacement Receipts, Transferred Old Source Recovery Receipts, Relocated Old Source Recovery Receipts, Rewritten Old Source Recovery Receipts, Retained Conversion Source Cleanup Receipt Sets and the safe evidence and actions needed to recover their exact displaced external files. It never enumerates, searches, indexes, previews, empties or manages unrelated operating-system trash and is not Asset Trash, an Offline Library Catalog or a portable library surface.

ADR 0392 also includes Asset Export Destination Replacement Receipts under the
same device-local, registration-independent boundary; ordinary Export Activity
remains outside this recovery surface.

Because replaced destination occupants and successfully trashed prior transfer, relocation, rewrite or retained-source cleanup files are no longer Design Asset sources and their recovery authority is device-local, **Forget Library Registration** retains these receipt classes by default without making them dormant. Recover Replaced Destination File, Recover Transferred Old Source File, Recover Relocated Old Source File, Recover Rewritten Old Source File and Recover Cleaned Retained Conversion Sources remain usable without reopening or re-registering the originating library and cannot read or modify that library. Retained-source restoration returns exact former files only to safe selected external locations and never changes the current Managed Asset or reverses its ownership conversion. The user may explicitly clear selected recovery records after an affected-record count and loss-of-recovery warning; clearing removes only selected application evidence and never restores, moves, deletes or empties operating-system trash content.

**Uninstall Preparation** includes these records alongside other supported device-local recovery state and has no preselected Keep or Clear answer. A user-controlled Keep choice preserves supported records for a later reinstall, while Clear removes only the selected application records. External bundle deletion, third-party uninstallers or cleaners, device erasure and out-of-band application-data removal cannot be reliably intercepted and receive no retention guarantee. Local File Recovery enters no library backup, merge, offline projection, cross-library search, export or synchronization. The current application has no Local File Recovery surface, external-file recovery receipt store or platform trash restore adapter. This ADR records target architecture only and accesses, restores, clears, moves, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
