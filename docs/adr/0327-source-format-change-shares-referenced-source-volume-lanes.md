# Source Format Change Shares Referenced Source Volume Lanes

Status: Superseded by ADR 0348.

Every executing Change Referenced Source Format item, whether started alone or through Source Format Change Batch, uses the same **Referenced Source Volume Lanes** as relocation and cross-volume transfer. It acquires the exact old-source and proposed-export physical-volume lanes in stable deterministic order, or one lane when both files share a volume. Separate schedulers are rejected because a path operation could otherwise move, rename, rewrite or trash a file while a format-change item is validating or adopting it.

The item holds both lanes through fresh source validation, the Source Format Change Commit Boundary, committed-new-source revalidation and either old-source cleanup or a durably recorded safe/attention outcome. A started operating-system trash request therefore settles or reaches truthful reconciliation before the old-source lane is released. When conflict review, unavailable media or recovery requires user input, the item first records its exact state and retains item/source guards, then releases I/O lanes; continuation must reacquire every current involved lane in stable order and freshly validate both files.

Items whose physical-volume sets are disjoint may perform read-only planning and validation in parallel. Authoritative relationship and Source Content Generation commits remain item-atomic and serialize through the active library's single-write boundary, so parallel I/O never becomes simultaneous library ownership. Library Quiescence under ADR 0278 waits for a non-interruptible commit or trash call to settle and pauses only at these safe item checkpoints.

Version one exposes progress and lane-wait reasons but no user concurrency control and does not infer higher concurrency from SSD, removable, network or professional-storage labels. A future change requires measured performance and recovery evidence and cannot create a second scheduler for the same volume. ADR 0328 automatic and manual retry attempts reacquire these same current lanes rather than bypassing the scheduler. ADR 0332 later extends the same scheduler through Rewrite Referenced Source encoding and publication rather than creating an encoder-only lane. The current application has no shared Referenced Source Volume Lane coordinator or source-format-change batch execution. This ADR records target architecture only and exports, accesses, creates, copies, relinks, moves, rewrites, restores, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
