# Successful Cross-Volume Transfer Retains Old-Source Recovery

Before a completed Transfer Referenced Source Across Volumes asks the operating system to trash its exact verified old source, the application durably prepares the evidence needed for a **Transferred Old Source Recovery Receipt**. Only a proven trash success completes and exposes that receipt in Local File Recovery; a reported failure follows ADR 0302, while ambiguous evidence remains item-scoped attention and never claims a recoverable trash item or repeats the destructive request.

**Recover Transferred Old Source File** restores only the exact receipt-linked item to its safely vacant former location or another explicitly selected safe location. Complete post-restore identity and format validation is required. The recovered file is an ordinary untracked user-owned external file: recovery does not change the current Referenced Asset, Source Content Generation, Source Tree, metadata or derived evidence, create another Design Asset, relink the asset, or reverse the completed transfer. Returning the asset to that file requires the new verified transfer defined by ADR 0309.

The receipt retires after verified recovery, explicit clearing after a recovery-loss warning, or authoritative proof that the exact trash item no longer exists. Restart, cache cleanup, storage pressure, settings reset and plugin/preview/AI maintenance do not retire it. ADR 0308 keeps it active after Forget Library Registration and includes it in Uninstall Preparation; it enters no portable library state, backup, merge, offline projection, cross-library search, export or synchronization and never authorizes enumeration of unrelated system trash. The current application has no cross-volume source transfer, old-source recovery receipt store, Local File Recovery surface or platform trash restore adapter. This ADR records target architecture only and accesses, restores, clears, copies, moves, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
