# Candidate Promotion Reuses the Captured Original

Confirming an Asset Candidate should transfer the already captured
original-quality local file in place from candidate ownership to Design Asset
ownership rather than moving or downloading the source again. Candidate
Promotion should preserve source context, lightweight
analysis output, Duplicate Signals, Tag Suggestions, user-confirmed Asset Tags,
and the user's chosen Asset Collections.

This keeps confirmation fast and avoids source drift where a remote image
changes between capture and library commit. Tags should keep their current
state during promotion: unresolved suggestions remain suggestions, accepted
tags become confirmed Asset Tags, and the promoted Design Asset enters the
chosen Collection Memberships with that state intact.
