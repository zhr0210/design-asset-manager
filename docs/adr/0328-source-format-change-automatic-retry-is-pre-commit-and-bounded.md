# Source Format Change Automatic Retry Is Pre-Commit And Bounded

Status: Superseded by ADR 0348.

**Source Format Change Automatic Retry** is allowed only when a classified transient read or parser failure occurs during read-only source identity, availability or real-format validation before the Source Format Change Commit Boundary, and both the old source and Compatible Export evidence remain unchanged. Each Source Format Change Pair receives at most two automatic retries after its initial attempt, using bounded increasing delays. Every retry reacquires the ADR 0327 volume lanes, confirms the same item/generation/pair and repeats the complete affected validation rather than trusting the prior partial read.

Waiting for a volume lane, continuing an unchanged validation checkpoint and restart reconciliation are not retry attempts. Restart, application exit, Library Switch and **Retry Failed Source Format Changes** do not reset the item's automatic retry budget. A changed file or relationship, deterministic invalid format, mismatched extension, permission failure, unavailable volume, relationship conflict, known cross-library warning, cancellation, Source Format Change Commit Boundary, relationship transaction, operating-system trash call, old-source cleanup or ambiguous outcome never retries automatically. Even a proven non-committed relationship transaction remains a failed item requiring explicit retry; an unproven outcome enters reconciliation rather than replay.

**Retry Failed Source Format Changes** acts only on explicitly selected currently failed pairs that can safely restart before commit. It preserves attempt history, reacquires current lanes and repeats all ADR 0323–0324 validation from current evidence; successful, no-op, cancelled, conflict, recovery and cleanup-attention items are excluded. It never reruns an already committed Source Content Generation or bypasses the batch review. **Retry Format-Change Old Source Cleanup** remains the only retry path for a committed item whose old source remains, and it is an independent explicit destructive request rather than part of the ordinary failure retry budget.

The current application has no cross-format source-change retry classifier, budget or result action. This ADR records target architecture only and exports, accesses, creates, copies, relinks, moves, rewrites, restores, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
