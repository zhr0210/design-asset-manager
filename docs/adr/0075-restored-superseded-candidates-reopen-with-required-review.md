# Restored Superseded Candidates Reopen with Required Review

Superseded Candidate Restore should return the candidate to Capture Inbox as a
Reopened Candidate without deleting or changing the Design Asset that replaced
it. The app should recompute Duplicate Signals after restore. Because the
replacement Design Asset is usually active, the restored candidate should
receive an Active Library Duplicate as a Superseded Restore Conflict, making it
Required Review and preventing Quick Promote until the user resolves the
duplicate in Promotion Sheet.
