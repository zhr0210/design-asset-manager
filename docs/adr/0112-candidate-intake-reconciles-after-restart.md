# Candidate Intake Reconciles After Restart

Opening the owning library must run Intake Reconciliation for persisted non-terminal Candidate Records and available application-managed intake artifacts without interrupting the active workspace. Cancelled Intake never resumes. When the source supports safe range continuation and the persisted transfer checkpoint has sufficient validators, Resumable Acquisition continues under the original Capture Request Identity and Candidate Identity. Otherwise the app cleans or treats the missing incomplete Managed Intake Artifact as absent and restarts acquisition under those same identities, subject to the existing Automatic Retry Budget. Candidate Activation still requires a safely validated atomic ADR 0280 commit into Original Asset Storage; intake that cannot be reconciled becomes an Unresolved Acquisition Failure in Capture Activity rather than producing a broken card or activating silently.
