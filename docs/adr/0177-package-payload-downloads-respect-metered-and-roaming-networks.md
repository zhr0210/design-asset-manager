# Package Payload Downloads Respect Metered And Roaming Networks

Model artifacts, Model Runtime Capability Packs, Managed Shared Runtimes, Format Capability Packs and Feature Plugins use one host-owned Governed Package Payload Download admission policy even though their package schemas, trust roots and installers remain separate. The policy does not apply by implication to Capture Artifact Transfer, ordinary user-requested web asset downloads, catalog metadata refresh or external AI requests; each retains its own purpose, privacy and consent contract.

Platform network adapters expose Network Cost Evidence as Unmetered, Metered, Roaming, Offline or Unknown with source and freshness. Metered and Roaming pause new package payload bytes by default. Offline remains waiting without retry storms. Unknown is displayed as Not Assessed rather than silently treated as unmetered; a new user-reviewed install plan may proceed only because its confirmation explicitly includes that unknown cost state and estimated traffic, not because the host guessed the connection is free.

Before ADR 0170 **Install And Enable This Setup**, an ordinary Model/Extension/Runtime install, or ADR 0188 post-library Baseline AI Runtime initialization transfers payload, the expanded plan shows total payload bytes, already-present/deduplicated bytes, remaining expected transfer, per-package source/purpose and whether sizes are exact manifest values or estimates. It also shows current Network Cost Evidence and any inability to assess it. Transport overhead and source retry uncertainty are described as a range or limitation rather than false precision. Dependency packages cannot hide their traffic inside one unexplained total. ADR 0188 may begin its already displayed baseline plan automatically only on verified Unmetered connectivity; Metered, Roaming, Offline and Unknown retain the gates in this ADR.

ADR 0221 Official Package Reacquisition after a local digest mismatch is another governed payload plan, not a repair exception. It displays the exact remaining transfer and storage impact, receives the same Metered/Roaming/Unknown transaction consent, and never counts or patches the mismatching user-owned file as resumable or deduplicated managed bytes.

Completing that already-approved transfer does not preauthorize indefinite retention. ADR 0226 separately rechecks the affected volume and Storage Safety Reserve if the later Verified Package Decision Review chooses Keep; this owner-only admission normally downloads no bytes and never reuses network consent as storage consent.

On Metered, the user may choose **Continue This Plan Once** or enable the separate default-Off **Allow Package Downloads On Metered Networks** preference. The one-plan exception is bound to the exact reviewed transaction and remaining dependency closure; it does not authorize later updates, other packages, catalog changes or asset downloads. On Roaming, each plan always requires a new explicit exception even when metered downloads are generally allowed. Unknown-state plan consent is likewise transaction-scoped and never changes the persistent metered preference.

A connection transition to Metered or Roaming pauses an in-progress governed payload at a verified resumable boundary unless its transaction already has the applicable exception. The staged partial and content digest state remain managed and non-active. When the source supports range/resume, continuation verifies prior bytes and immutable identity before requesting the remainder. If it does not, the UI discloses that restart will re-transfer the artifact and asks again when network cost requires it. Pause, application restart or network loss never promotes a partial package, accepts changed content or bypasses license/trust checks.

Small signed path-free Model, Extension and Runtime Catalog Metadata Refresh may continue on Metered or Roaming within a strict per-refresh byte/rate budget because it cannot contain package payload, repository snapshot, model weights, executable archive or benchmark dataset. Exceeding the declared metadata budget aborts refresh and requires payload-style consent rather than silently continuing. Automatic model/runtime trust refresh follows ADR 0204's stale-driven, app-active cadence, and no metadata refresh ever triggers a package download.

ADR 0209 Catalog-Bound Authenticated Time Evidence may occupy a strictly bounded part of the same signed metadata response. It does not authorize an independent time endpoint or additional refresh and cannot turn time assessment into package-payload traffic.

Network evidence changes debounce before pause/resume decisions. Returning to verified Unmetered may resume a previously approved transaction after source, manifest, license, trust, storage and power admission are rechecked; it does not create a new install plan or resume a revoked package. Public status contains opaque transaction/package identities, byte counts and typed waiting reasons only, never raw source URLs, authorization headers, credentials, private paths or network identifiers.

The current project has separate asset download state, Llama/model/runtime download paths and partial-file indicators, but no shared Network Cost Evidence, metered/roaming admission, plan-scoped exception, persistent metered preference, metadata byte budget or cross-installer transition reconciliation. Existing worker “offline” health and resumable-file markers do not prove network cost policy. This ADR records target download governance without querying the active network, downloading payloads, reading partial files or changing public IPC/database/package contracts.
