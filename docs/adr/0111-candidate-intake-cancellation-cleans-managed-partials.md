# Candidate Intake Cancellation Cleans Managed Partials

Cancelling Candidate Intake must cooperatively stop acquisition and validation, then remove only incomplete Managed Intake Artifacts or chunks inside application-controlled operational staging. It must never delete the user's source file, an ADR 0280 Candidate Artifact already committed into Original Asset Storage, or a Design Asset file. The Candidate Record transitions to terminal Cancelled Intake, leaves Capture Activity and Capture Attention Badge, and retains only Capture Request Identity, Candidate Identity, cancellation time, and a minimal cancellation reason for idempotency and traceability. Cancelled Intake cannot be retried in place: a later recapture creates a new Capture Request Identity and Candidate Identity, while retry before cancellation continues to reuse the original identities.
