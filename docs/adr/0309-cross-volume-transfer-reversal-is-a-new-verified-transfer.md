# Cross-Volume Transfer Reversal Is A New Verified Transfer

A completed Transfer Referenced Source Across Volumes has multiple independently truthful consequences: the Referenced Asset uses its verified new source, the prior source may be in operating-system trash or remain as an ordinary file, and both a successfully trashed old source and a replaced destination occupant may have independent Local File Recovery receipts. The application therefore offers no one-click or apparently atomic whole-transfer undo that attempts to restore, delete or move all of those files as one rollback.

Moving the Referenced Asset back to a prior volume starts a new **Transfer Referenced Source Across Volumes** from its currently verified source. It requires fresh source-generation evidence, destination selection and confirmation, destination-volume staging, complete verification, current collision review and its own old-source cleanup outcome. Byte-stable movement preserves the same Design Asset and Source Content Generation, but the new operation has its own checkpoint, receipts, attention states and reconciliation rather than reopening or rewriting the completed operation.

An exact old copy that still occupies the requested return destination may be selected only through the normal Use Existing Identical Destination decision after complete current verification. Transfer Destination Replacement Receipts and ADR 0310 Transferred Old Source Recovery Receipts remain independently available through Local File Recovery and are neither consumed nor cleared by moving the Referenced Asset again. Cancellation or recovery before an original operation commits remains governed by that operation's current staging and recovery states, not by this post-success rule. The current application has no referenced-source transfer or whole-transfer undo implementation. This ADR records target architecture only and accesses, restores, copies, moves, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
