# Color Profile Resolution Uses Evidence Not Assumption

System Preview color processing begins with a backend Color Evidence Pipeline and never invents a source profile from pixel appearance. The target open-source implementation separates responsibilities: ExifTool extracts ICC, EXIF, XMP, Photoshop IRB, and format metadata; OpenImageIO exposes format pixels, channels, and structured metadata without being treated as a complete layered-PSD renderer; Little CMS validates ICC v2/v4 profiles and performs transforms only when a valid Source Color Profile exists. Format-specific preview workers remain responsible for faithful PSD, TIFF, and other professional-format composition rendering and cross-platform regression evidence.

Authoritative Color Evidence resolves in descending order from a valid embedded ICC Profile, an explicit standardized format color description, and a trusted non-conflicting EXIF or XMP color-space declaration. Invalid evidence becomes Invalid Color Profile, mutually inconsistent evidence becomes Color Profile Conflict, and absence of authoritative evidence becomes Unprofiled Color. None of these states may silently assign sRGB, Display P3, generic CMYK, or another source profile.

An unresolved source color state does not disable automatic preview for a supported format. For Unprofiled Color, an unresolved Color Profile Conflict, or a Recoverable Invalid Color Profile, the backend uses a validated embedded composite when available or the format worker's decoded visual output to generate an Unmanaged Structural Preview for composition and content inspection, records the decoder and evidence provenance, and labels color accuracy as unknown. This preview must not be represented as a Color-Managed Master Preview, used to claim gamut mapping, or used to derive purportedly color-accurate P3 and sRGB variants. Under ADR 0127, a validated Unmanaged Structural Preview can satisfy the preview portion of Promotion Readiness without erasing the Unprofiled Color state; ADR 0128 governs reviewed promotion for conflicting evidence, and ADR 0129 governs invalid profile evidence. A later source-profile assignment is allowed only through explicit user action or newly discovered Authoritative Color Evidence; it then regenerates replaceable preview derivatives without modifying the original.
