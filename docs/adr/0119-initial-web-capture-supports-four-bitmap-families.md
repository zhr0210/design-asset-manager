# Initial Web Capture Supports Four Bitmap Families

The Initial Capture Format Set supports JPEG/JFIF, PNG, WebP, and GIF originals after file-signature, MIME, and real decode validation rather than filename-extension trust. GIF keeps its original animated Candidate Artifact, while the first phase may use a clearly labeled static Animated Source Preview. Screenshot Capture produces PNG. SVG is not accepted until active content, external resources, sanitization, and isolated rendering have an explicit safe path. AVIF, HEIC, TIFF, BMP, and other formats remain capability-gated until macOS and Windows decoding, metadata, thumbnail, and preview behavior pass focused validation. Unsupported formats fail explicitly and must not be silently transcoded into a lower-quality JPEG presented as the original.
