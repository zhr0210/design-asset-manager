# External Capture Producers Require Pairing

The built-in Web Capture Entry may use a Trusted Internal Capture Adapter through allowlisted preload and IPC capabilities, but every browser extension or independent local tool is an External Capture Producer that must complete explicit user-approved Capture Pairing. Pairing issues a producer-specific, revocable Scoped Capture Token held through operating-system secure storage. The future Local Capture API binds to loopback by default and grants only capture submission plus minimal status reads for that producer's own requests; library read, export, mutation, deletion, and unrelated application control are denied unless a later separately approved capability is designed. Capture Envelope must never carry browser cookies, authentication headers, or site credentials. Producer Access Management shows paired producer identity, granted scope, and last-used time and supports immediate revocation.
