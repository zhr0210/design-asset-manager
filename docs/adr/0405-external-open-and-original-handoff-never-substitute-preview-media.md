# External Open And Original Handoff Never Substitute Preview Media

Contextual preview media is optimized for inspection and may be rendered, cached, stale, incomplete, or lossy. Passing it to another application as though it were the original would silently change fidelity and ownership semantics. External open and file handoff therefore require the validated current original.

External open uses the operating-system-associated application by default and may use a device-local per-format **External Open Preference**. Open With is one-time unless the user explicitly chooses Always Use for that format. The preference is not library data and does not enter backup. If the preferred application is unavailable, the action reports that state and offers the operating-system default or another explicit choice. An unavailable referenced original routes to relink recovery. Show in Finder or Explorer remains separate.

Ordinary drag and Copy File perform **Original Handoff** of the actual current source-preserving original. They never substitute a Thumbnail, System Preview, Preview Tile, Required Preview, cached rendition, converted output, or prior Source Content Generation. **Copy Image** is a separately named Rendered Image Copy of the validated current visual unit or composition. **Compatible Export** is another explicit source-separated operation with reviewed output format, dimensions, color, and visual-unit scope.

ADR 0459 gives a Text editor an explicit rejecting drop boundary for files,
images and asset identities. Original Handoff may begin only from its own asset
drag source toward an eligible external/file target; hovering or dropping it on
a Text field never inserts a path, rendered image or relationship.

For a Compound Original, ordinary handoff is complete-set by default under ADR 0341 and preserves all included members and declared relative layout. External Open opens the declared primary in place so compatible tools can discover companions. A destination unable to preserve the group receives an explicit complete-set export route; Primary Member Only remains a separately warned action. ADR 0342 blocks complete-source actions when required members are absent, and a retained preview never substitutes for incomplete current source content.

ADR 0383 distinguishes immediate Original Handoff from destination-planned Original Asset Export and keeps both source-exact. ADR 0348 keeps compatible results and generated derivatives source-separated. If the validated current original is missing, unavailable, or incomplete, the application reports or recovers that state rather than degrading silently to preview media.
