# Smart Filters Have System and User Types

Smart Filters should have two ownership types. System Smart Filters represent
application-owned review workflows such as duplicate candidates, tag
suggestions awaiting confirmation, and candidates nearing expiration; they are
shown above user-created Smart Filters by default, may be hidden, and should
not be deleted as user content.

User Smart Filters are created only from explicit saves and can be named,
edited, deleted, and reordered by the user. This keeps durable product review
workflows available without making them feel like ordinary user-created saved
views.
