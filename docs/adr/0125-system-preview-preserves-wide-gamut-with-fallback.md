# System Preview Preserves Wide Gamut With Fallback

System Preview must be color-managed rather than globally forced to sRGB whenever Authoritative Color Evidence or an explicit Sidecar Profile Assignment establishes a Source Color Profile. The original and all embedded color evidence remain unchanged. Under ADR 0147, the persistent overview defaults to a tagged, gamut-mapped sRGB baseline for predictable grids, while wide-gamut RGB or color-managed CMYK sources can render tagged P3 Preview Variants or sRGB Preview Variants as requested tiles or optional quick previews instead of storing two permanent full-size files. Native sRGB sources remain sRGB and are not relabeled or needlessly expanded into P3. Display Gamut Selection uses verified output capability to choose the tile/preview destination and falls back to sRGB when capability is unknown; multi-display routing follows ADR 0134, and isolated P3 rendering failure follows ADR 0135. Every color-managed raster output carries its destination profile, and Asset Inspector exposes source profile, active preview gamut, and Gamut Mapping State. Screen-preview rendering intent follows ADR 0132. CMYK and other print-space conversion affects only rendered screen pixels and never rewrites or claims conversion of the original. Missing, invalid, or conflicting color evidence is governed by ADR 0126 and must never be replaced by an inferred source profile.
