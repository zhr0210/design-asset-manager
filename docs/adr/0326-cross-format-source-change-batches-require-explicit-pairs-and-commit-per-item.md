# Cross-Format Source Change Batches Require Explicit Pairs And Commit Per Item

Status: Superseded by ADR 0348.

A **Source Format Change Batch** starts only from a reviewed set of **Source Format Change Pairs**. Each pair binds one exact Design Asset, current Source Content Generation and current source to one complete Compatible Export; verified export provenance may prefill a proposal, but the user must see and confirm every association. Filename, basename, directory, selection order, count, visual similarity and conversion preset never establish a pair. One Design Asset or export may appear in only one executable pair, and a proposed export that is another pair's old source creates a blocking cross-item dependency rather than an inferred execution order.

The batch review shows every old/new source association and its format, extension, dimensions, color, bit depth, compression, quality and professional-unit consequences. One batch confirmation may explicitly authorize moving every successfully displaced old source to operating-system trash, but it never authorizes conflict replacement, asset merging, relationship detachment or another item-specific destructive choice for all items. No remembered prior decision or plugin/export preset bypasses this review.

Execution is an item-committed coordinator, not a filesystem or library-wide transaction. Every pair freshly runs ADR 0324 relationship checks and independently follows ADR 0323 commit/cleanup/recovery, the ADR 0325 cancellation boundary and ADR 0327 shared volume-lane scheduling. A no-op, conflict, warning, validation failure, cleanup partial success or recovery state on one item does not roll back successful items or stop unrelated safe pairs. Batch cancellation durably stops unstarted pairs; an in-progress pair settles at its own Source Format Change Commit Boundary, and restart reconciles each started item without redispatching accepted cancellations or repeating ambiguous trash calls.

The **Source Format Change Batch Result** groups successful changes, same-source no-ops, relationship conflicts, acknowledged cross-library warnings, Format Changed With Old Source Remaining, failed, recovery and cancelled items with their normal item actions and receipts. It offers no batch rollback or format-change undo. ADR 0328 permits bounded automatic retry only before commit and defines Retry Failed Source Format Changes; successes are never rerun, and conflict replacement, relinking or merging cannot be applied to all. The current application has no cross-format source-change batch coordinator or result surface. This ADR records target architecture only and exports, accesses, creates, copies, relinks, merges, moves, rewrites, restores, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
