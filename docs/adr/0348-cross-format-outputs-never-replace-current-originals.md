# Cross-Format Outputs Never Replace Current Originals

Cross-format rendering or conversion produces only a **Compatible Export**: a separate user-owned output that never replaces, relinks, rewrites or deletes the current original through the application. A single-file original remains that file, and a Compound Original such as RAW plus validated XMP remains the same complete group; the application therefore provides no Change Referenced Source Format or Use Exported File as Current Source workflow. This supersedes the current-source replacement requirement in ADR 0322 and all of ADRs 0323 through 0328.

Preview does not violate this boundary. The Preview Broker may decode the original and apply capability-validated companion effects into memory, Required Preview Storage or clearable cache, while AI uses brokered visual sources and ephemeral model inputs under ADR 0137. Those derivatives may use JPEG, PNG, tiles or another internal representation, but they never become an original, Source Content Generation, handoff payload or implicit TIFF/DNG replacement.

Compatible Export may render RAW plus XMP into TIFF, JPEG, PNG, DNG or another capability-supported target and must disclose preserved, embedded and lost information. Core or extension-provided exporters may add formats and controls, but their outputs remain source-separated. ADR 0383 places compatible outputs in a destination-reviewed mode separate from source-exact Original Asset Export and forbids mixing their success/fidelity meanings in one task. Same-format Rewrite Referenced Source and Rewrite Referenced Compound Source remain available only where trusted capabilities prove that the current format, member structure and promised professional information are preserved; otherwise the original stays untouched and export is the only conversion path.
