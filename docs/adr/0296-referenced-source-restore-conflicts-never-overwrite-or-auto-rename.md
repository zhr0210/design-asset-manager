# Referenced Source Restore Conflicts Never Overwrite Or Auto-Rename

An occupied original path during Restore Referenced Source File is a **Referenced Source Restore Conflict**, not permission to overwrite, suffix, merge, or create another Design Asset automatically. If stable real-format and complete-content validation prove that the occupying regular file is byte-identical to the Referenced Asset's last verified Source Content Generation, the application restores the existing Design Asset relationship to that file without moving the receipt-linked system-trash item. Asset Restore then completes with the same Design Asset identity and metadata, the now-unneeded receipt is retired, and its former trash item remains untouched as ordinary user-controlled system-trash content.

If the occupying file differs, the conflict surface keeps it untouched and offers three explicit outcomes. **Restore Source to New Location** uses a trusted destination picker to return the exact receipt-linked trash item to one user-selected safe empty path, updates the Referenced Asset relationship, validates it and completes Asset Restore. **Use Existing File as Replacement** keeps the trashed original untouched, validates the occupying file, reconnects the same Design Asset and creates a new Source Content Generation under the existing explicit-replacement rules. **Cancel** leaves the Design Asset and receipt recoverable in Asset Trash. Neither content difference nor matching filename allows automatic replacement, destination overwrite, generated suffixes, sibling scanning, ownership change, duplicate asset creation, or silent fallback between these outcomes.

For an ADR 0346 Referenced Compound Source Trash Receipt Set, each occupied member destination uses these same explicit evidence and path choices inside the one group restoration. No resolved member independently completes Asset Restore or exits Referenced Compound Source Delete Recovery; every resulting member relationship and the complete capability group must validate before the one Design Asset becomes active. This specialized source-path resolution precedes ADR 0071's generic Restore Conflict default because no second Design Asset need exist. If a separate Design Asset identity/content/link conflict remains after the source path is resolved, ADR 0071 still opens its Restore Conflict Sheet and defaults to Restore as Copy. The current project implements neither Asset Trash nor referenced source restore, content-generation persistence, trusted restore destinations, or these choices. This ADR records target architecture only and reads, hashes, moves, restores, overwrites, renames, relinks, or deletes no runtime/user file and changes no public IPC, database schema, or AI Worker API.
