# Referenced Source Path Batch Cancellation Stops Only Pre-Commit Work

Accepting **Referenced Source Path Batch Cancellation** durably stops dispatch of every unstarted item in that batch and records those items as cancelled. An item may also cancel after validation but before its filesystem commit call begins. Cancellation never requests a reverse operation for a completed item, discards an existing conflict or recovery obligation, or changes the relationship or recovery state of an item that has already reached a truthful outcome.

An in-progress Transfer Referenced Source Across Volumes may observe cancellation only at a safe checkpoint before final-path publication begins. It stops further copying and may remove only its exact application-owned Referenced Source Transfer Staging under ADR 0303; if ownership or removal cannot be proven, the item enters item-scoped attention rather than claiming cancellation. Once publication begins or the transfer enters old-source cleanup, it must settle into success, Transferred With Old Source Remaining or its existing recovery state. Once a same-volume relocation's atomic filesystem move begins, it likewise runs to a proven result or reconciliation because force-interrupting the call could make the source path ambiguous.

An ADR 0345 Referenced Compound Source Path Operation is one batch item: cancellation may stop its unstarted work and proven staging, but after any member relocation/publication begins the whole item must settle into complete relationship commit or Referenced Compound Source Path Recovery rather than cancelling or rolling back selected members. Items that were already in conflict review or recovery remain there, while safe unrelated in-flight items independently obey their own boundary and ADR 0317 volume-lane scheduling. The batch result groups cancelled, completed and attention outcomes without rolling back success. Restart reconciliation preserves an accepted cancellation request so queued items are not silently dispatched later, but it still reconciles every operation that had crossed its non-cancellable boundary. The current application has no referenced-source path batch coordinator or these file-operation cancellation boundaries. This ADR records target architecture only and accesses, creates, copies, removes, restores, moves, renames, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
