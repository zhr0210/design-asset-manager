# Simple Same-Volume Relocation Has A Verified Thirty-Second Undo

After Relocate Referenced Source succeeds into a previously vacant destination or a reviewed unique name without displacing another file, the application exposes **Referenced Source Relocation Undo** for 30 elapsed seconds. Invoking it within that window requests a reverse Relocate Referenced Source from the current location to the prior location; it is not an unconditional filesystem rollback, does not restore a snapshot and creates no additional file copy. A request accepted before the deadline may finish after the transient affordance expires.

The reverse operation freshly proves the same Design Asset, current Source Content Generation, current source identity and location, same physical volume, prior destination boundary, permissions and path safety. A safely vacant prior path allows the normal atomic move and relationship commit. If the prior path is occupied, it opens Referenced Source Relocation Conflict Review with current evidence instead of overwriting, silently renaming or abandoning the source. Changed or unprovable source content, a moved source, unavailable volume or other stale evidence makes undo no longer directly eligible and reports the truthful outcome without automatic fallback.

Expiry, dismissal, restart or Library Switch removes only the short-lived affordance and performs no file action. Use Existing Identical Relocation Destination and Replace Relocation Destination never receive this one-click undo because they displaced independent files with Local File Recovery receipts; moving the active source again remains an ordinary explicit relocation and those receipts remain independent. ADR 0314 keeps batch items independently committed, and ADR 0315 coordinates only the still-eligible simple relocations through a short batch-result affordance. The current application has no Referenced Source relocation journal, reverse-relocation affordance or relocation conflict surface. This ADR records target architecture only and accesses, copies, restores, moves, renames, trashes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
