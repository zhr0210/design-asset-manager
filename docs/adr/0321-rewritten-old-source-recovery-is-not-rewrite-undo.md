# Rewritten Old Source Recovery Is Not Rewrite Undo

A successful Rewrite Referenced Source has no transient or one-click undo. Its **Rewritten Old Source Recovery Receipt** enters Local File Recovery, where **Recover Rewritten Old Source File** restores only the exact receipt-linked pre-rewrite source to one explicitly selected safe empty location as an ordinary untracked external file. Recovery never overwrites, moves, relinks or replaces the active rewritten source, changes the Design Asset or current Source Content Generation, creates another asset, or represents automatic revision history. The former source path is available only if it has later become safely vacant and the user explicitly selects it; an occupied path receives no suffix, overwrite or fallback.

The receipt retires only after verified recovery, explicit clearing with a loss-of-recovery warning, or authoritative proof that the exact system-trash item no longer exists. Restart, cache cleanup, settings reset, storage pressure and plugin/preview/AI maintenance do not clear it. ADR 0308 retains it by default after Forget Library Registration, includes it in the unpreselected Uninstall Preparation Keep-or-Clear decision and excludes it from portable library state, backup, merge, offline projections, search and export.

If the user wants recovered bytes to become the asset's current source, **Use Recovered Rewrite Source as Current** requires the originating library to be active and starts a new explicitly confirmed Rewrite Referenced Source. It compares the recovered input with the current source, copies the input into complete same-volume staging without modifying the recovered external file, validates all ADR 0319 format and structure consequences, then protects the current source through the same trash-before-publication and ADR 0320 recovery boundaries. Success creates a new Source Content Generation even when the resulting bytes match an earlier generation, because the current source materially changed again; it retains a new receipt for the source displaced by this new operation. It never reactivates an old generation identifier, erases intervening evidence or consumes the recovered external file as hidden history.

ADR 0347 groups materially displaced compound-member receipts in one Compound Rewritten Old Source Recovery Receipt Set. Any member may still be restored only as an ordinary untracked external file; making prior compound bytes current requires a new complete Referenced Compound Source Rewrite Plan that resolves all current member consequences and never treats one recovered companion as member-level undo.

The current application has no referenced-source rewrite, rewritten-source receipt or recovered-input replacement flow. This ADR records target architecture only and accesses, creates, copies, restores, relinks, moves, rewrites, trashes, removes, deletes, reads or writes no runtime/user file and changes no public IPC, database schema or AI Worker API.
