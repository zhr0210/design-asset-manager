# Library Merge Imports Advisory History But Not Acknowledgement Authority

ADR 0187 Merge Into Current Library imports committed result provenance and source-library Model Advisory Acknowledgement records only as **Imported Advisory Decision History**. The imported history retains opaque source Portable Library Lineage Identity, Model Advisory Semantic Fingerprint, reviewed generation/capability scope, source decision/time and statement provenance for explanation. It has no authority to resolve, suppress or acknowledge Model Result Advisory attention owned by the target library.

Before confirmation, Merge Dry Run classifies advisory-bearing imported results into: **Covered By Target Acknowledgement**, **Requires Target Review**, and **Imported History Only**. Coverage exists only when the target library already has its own valid ADR 0195 acknowledgement with the exact same semantic fingerprint and a scope that covers the imported result generation/capability. Shared model name, artifact digest, statement sequence, source acknowledgement or similar result content is insufficient. Matching target acknowledgement is reused once rather than duplicated.

Requires Target Review creates one target-library pending advisory per homogeneous semantic fingerprint/generation scope after the imported results commit, not one warning per asset. The target user then chooses Keep Existing Results, Delete Results or a previewed Reanalysis Plan under ADRs 0193–0195. Imported results remain visible, normally ranked and searchable before and after that choice; pending attention does not quarantine or de-rank them.

Imported Advisory Decision History is immutable source provenance, not an Import Conflict resolution choice. Keep Current/Use Imported/Keep Both for result values cannot silently convert the source acknowledgement into a target acknowledgement. If the result itself is excluded or rolled back, history owned only by that excluded imported result is removed with the merge transaction; pre-existing target acknowledgements/history remain unchanged. A failed/cancelled merge leaves no new attention or partial history.

The merge preview reports aggregate imported advisory statements, affected assets/result classes, already-covered target scopes and target reviews that will be created, without asset names or result content in logs/public status. Different reasons, severity/response classes, trust roots or generation scopes remain separate groups under ADR 0100 homogeneous-set principles. One batch Keep Existing Results action cannot cover heterogeneous imported statements.

Merge does not refresh catalogs, contact GitHub/mirrors, download models/runtimes, install dependencies, select a model or start reanalysis. ADR 0198 permits offline merge using Last Verified Trust State/Not Assessed freshness and reconciles signed metadata only after connectivity returns. The resulting target Full Library Backup includes target-owned acknowledgements plus imported non-content decision history as authoritative provenance, while preserving the target Portable Library Lineage Identity.

The current project has no Full Library Merge executor, imported advisory-history class, target-coverage matcher, advisory dry-run counts or transactional attention projector. This ADR records target behavior without reading/merging a runtime library/backup, accessing model/result/private data or changing public IPC/schema/AI Worker APIs.
