# Capture Inbox Lives Inside the Asset Workspace

Status: Superseded by ADR 0026 for Capture Inbox placement and candidate
selection.

The Capture Inbox should live inside the Asset Workspace as a lightweight
right-side panel, with the ability to expand into a full batch-processing view.
It is not a separate primary surface and should not compete with the Asset
Library as another long-term collection.

This keeps everyday capture review close to browsing, filtering, and
inspection, while still giving large Pinterest or webpage batch captures enough
space for queue review, duplicate decisions, metadata edits, AI suggestions,
and commit actions.
