# Preview Broker Routes Format Specific Workers

Broad preview coverage uses one Preview Broker contract backed by isolated format-specific workers rather than one universal decoder process. Signature and structure detection select a declared Capture Format Capability before decode. Sharp/libvips remains the fast common-bitmap lane; OpenImageIO handles professional raster and structured image metadata; LibRaw handles camera RAW; PSD/PSB prefers a validated Embedded Composite Preview and may use ImageMagick or psd-tools as bounded fallbacks; PDFium handles PDF-compatible AI and PDF; ImageMagick provides an allowlisted long-tail compatibility lane. Native macOS Quick Look or Windows preview providers may be opportunistic final fallbacks but cannot establish cross-platform support by themselves.

Under ADR 0147, PSD, PSB, layered TIFF, and equivalent professional sources produce a persistent sRGB overview and an artifact-specific On-Demand Render Manifest instead of permanent full-source-dimension sRGB and P3 images. RAW may expose a validated embedded camera preview immediately, but System Preview Ready also requires the full-decode render path; AI uses artboard/page rendering when a compatible PDF representation exists. Requested regions and destination gamuts are rendered lazily and cached as bounded tiles. Legacy or proprietary AI constructs, unsupported Photoshop effects, missing fonts, and similar fidelity limits remain explicit capability evidence; successful file opening alone never claims faithful support.

Every worker runs without network access and receives read-only access to one staged original plus write-only access to its derived-media staging area. Byte, pixel, page, frame, memory, disk, time, recursion, and process limits are enforced; indirect reads, arbitrary delegates, shell expansion, and undeclared output paths are denied. Worker crashes are isolated from Electron and become structured preview failures. Third-party Format Capability Packs additionally require the per-plugin execution cell, platform confinement evidence, failure budget, and quarantine behavior in ADR 0156. A format is declared supported only after macOS and Windows fixtures prove composition, orientation, alpha, color evidence, dimensions, failure safety, and output validation for its selected lane.

ImageMagick is a compatibility worker, not the source of truth for every format. Delegate licenses and executables are separately governed; Ghostscript is not bundled into the MIT application without an explicit AGPL-compliance or commercial-license decision. Permissively licensed core workers ship with the base application, while ADR 0151 allows large, rare, constrained, or independently evolving workers only through verified optional Format Capability Packs. Preview provenance records worker, decoder version, capability revision, embedded-composite use, and known fidelity limits without exposing private paths.

Preview Broker output is also the visual decode boundary for AI analysis under ADR 0137. AI providers do not reopen arbitrary professional originals through Pillow, Sharp, or provider-specific decoders when a brokered Analysis Visual Source is required.
