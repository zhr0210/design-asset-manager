# AI Analysis Does Not Block Candidate Promotion

AI analysis readiness is independent from Candidate Promotion readiness. ADR 0168 waiting intent, pending, queued, running, paused, partial, failed, capability-unavailable, cancelled, or stale tag, OCR, embedding, caption, palette, and Deferred Detail Analysis work does not block Candidate Promotion, Quick Promote, or default Batch Promotion by itself. Promotion still enforces original integrity and safety, stable identity and file ownership, automatic fallback membership under ADR 0413, required technical/core identity metadata, conflict policy, and System Preview Ready under ADR 0123. A supported format's ability to produce an Analysis Visual Source remains a backend capability target, but optional model completion is not a user-facing admission gate.

Tag Suggestions remain unconfirmed advisory metadata under ADR 0016. Low confidence, disagreement, background sensitivity, Partial Analysis Coverage, or absence of a local model may keep a suggestion unconfirmed or visible for later review, but cannot turn the Candidate into permanently ineligible inventory. Duplicate Signals and core promotion conflicts retain their existing reviewed-promotion behavior because they concern identity, ownership, or duplication decisions rather than completion of optional AI enrichment. Safety, integrity, and required preview failures remain non-overridable.

Promotion performs a Promotion Analysis Handoff instead of cancelling or duplicating analysis. Durable Analysis Intent and admitted Execution Job identity, source and recipe generation, completed View-Level Analysis Evidence, remaining Analysis Coverage Plan, and active Asset Analysis Projection move from Candidate context to the new Design Asset context through the Promotion Link. Workers address stable artifact and generation identity rather than a mutable Candidate path. Results that complete after promotion attach to the Design Asset while Candidate History retains only the lightweight trace required for provenance.

ADR 0419 unresolved Custom Field Value Suggestions follow this handoff without
becoming confirmed values. Already accepted Custom Field Values transfer through
ADR 0416 instead, and neither state blocks Promotion by itself.

A user or workflow may explicitly choose Await Analysis for one visible promotion action or batch. The wait declares the exact recipes, coverage and terminal states required before that action proceeds; it is cancellable back to ordinary promotion when all non-AI readiness gates pass. Await Analysis is not a global default, cannot be inferred from provider availability or an unresolved suggestion, and cannot silently expand from overview to exhaustive analysis. Failure or capability unavailability stops that requested wait and presents the choice to continue without the optional result or retry after capability recovery.

Promotion feedback and Asset Inspector show analysis continuing, partial, unavailable, or failed without presenting those states as file or promotion failure. Search and organization use whatever compatible projections exist and refresh when later evidence activates. Promotion never fabricates placeholder tags, OCR, captions, or embeddings to make analysis appear complete.
