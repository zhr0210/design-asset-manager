## 产品价值

素材库解决“积累和找回”；工作模式把参考持续放在正在进行的设计旁边。
产品闭环扩展为：收录 → 理解 → 找回 → 组成工作集 → 边参考边创作 → 安全复用。
多素材、多窗口、可恢复的工作上下文与AI结果连接，是核心体验的一部分。

已核实的竞品信息（2026-09-14，官方页面说明，不代表本机实测）：

- Eagle已有独立图片窗口、置顶和多参考窗口，不能宣传它完全没有悬浮参考。
  [Eagle官方说明](https://eagle.cool/blog/post/eagle-image-pin-on-top-for-designers)
- PureRef提供置顶参考画布及场景保存/加载，可以借鉴参考排布与持续可见的交互。
  [功能手册](https://www.pureref.com/handbook/features/)、[保存设置](https://www.pureref.com/handbook/2.0/settings/)
- macOS ScreenFloat提供录屏、悬浮显示、拖出及从视频当前位置提取静帧。
  [官网](https://www.eternalstorms.at/ScreenFloat/)、[使用说明](https://eternalstorms.at/ScreenFloat/tips/mac/)

上述资料不足以断言某个竞品没有“可保存多素材工作集”的全部组合。
本项目以完整工作流、少切换、可恢复和AI分析的实际收益验证差异，而不依赖功能独占。

## 工作集、窗口与素材库

- **工作模式**：创作时使用的轻量参考表面，允许多窗口并存；主库窗口可以收起，
  应用继续运行。它与库浏览/专注查看协同，不是复制一套资料库。
- **工作集**：用户挑选的素材引用及顺序、展示布局、工作备注；一个集合窗口能放
  多张图片、视频和其他已支持的素材。同一素材可出现在多个工作集，默认不复制原件。
- **工作窗口**：展示某个工作集的原生悬浮窗口，可置顶、调整尺寸/位置、暂时隐藏。
  多窗口分别展示不同参考任务；同一工作集的重复打开默认聚焦已有窗口，克隆视图可后续评估。
- **保存与恢复**：保存工作集及其展示设置，下次可打开。名称、成员和布局是持久内容；
  屏幕位置/缩放及设备展示偏好与当前设备关联。模型请求、权限token和云端执行不随配置恢复。

工作集不是Collection、标签分类或另一份素材所有权；对工作集的操作不静默改变
素材在原库中的组织。跨库混合是后续能力，初期每个工作集绑定一个Library身份。
同一活动库内可以打开多个工作窗口。切库或关库撤销旧窗口的素材访问；工作集保存
记录保持，重新授权打开该库后再恢复，不能靠旧路径绕过当前库权限。

## 功能与交互范围

| 操作 | 工作模式中的目标行为 |
| --- | --- |
| 建立工作集 | 从资料库选择多份素材，加入新建/已有工作集；也能在工作窗口轻量搜索并追加已有素材 |
| 增删参考 | 添加、从工作集移除、调整排列；“移除参考”仅解除成员关系，明确区别于删除库中素材 |
| 多窗口参考 | 多个工作窗口同时存在，各自置顶/取消置顶、移动/缩放、隐藏/恢复；提供找回所有窗口入口 |
| 保存与下次继续 | 命名保存、再次打开、另存工作集；未保存/保存中/失败有明确状态，关闭不静默丢失改动 |
| 素材查看 | 图片缩放/平移/适配，视频播放/暂停、时间定位与参考帧；其他格式依据已验证的预览能力展示 |
| 参考与AI | 查看颜色占比、描述、标签和提示词，执行有能力证据的分析/反推、复制结果；范围与外发确认和主库一致 |
| 创作工具 | 可用的图片派生工具及已授权插件命令可在上下文调用；输出经宿主确认/入库，不改原件 |
| 工作备注 | 可编辑工作集自己的参考意图/备注；不自动覆盖素材的全局描述或确认标签 |
| 跨应用复用 | 拖出单个/多个素材到接收文件的设计软件或网页输入区；清楚区分原件、视频文件和导出的参考帧/兼容副本 |
| 素材整理 | 分类、标签管理/确认、全局元数据编辑、合并去重、迁移、Trash等在资料库完成；工作窗口可“在资料库定位” |
| 外部文件加入 | 可调用同一受控导入流程；不是未经入库即可获得素材身份，也不借此恢复内置网页浏览 |

这是“保留创作时常用能力，排除资料库整理”的边界；不把主库的菜单原样塞进小窗口。
既有卡片的描述编辑等功能当前保持，本规格不会通过文档直接删除代码；正式迁移时按
上述边界归入工作备注或资料库入口，并保留已有未提交编辑的恢复机会。

窗口设置的建议基线：名称、成员/顺序、布局与视图尺度、窗口大小/位置、置顶状态。
视频播放位置可恢复，重开默认暂停，不能突然出声或自动开始分析。多视频有播放/解码
资源预算，后台视频按明示策略暂停；不承诺无限数量同时解码。自由画布、点击穿透、
绑定特定软件等是后续UX候选，不是用户本轮已要求的首版前置。

屏幕被拔除、缩放改变、窗口离屏时回到可见区域；隐藏与关闭窗口不等于删除工作集。
素材离线、入Trash或被永久移除时显示对应状态，不静默从已保存工作集中消失。
从工作集移除参考、删除工作集、删除视频参考帧关系均不得顺带删除素材原件。

## 跨软件拖拽的真实交付边界

拖出通过宿主进行身份/可用性检查和原生文件交接，优先提供Copy语义及受管交接副本，
不能让接收应用获得移动/重写库中原件的隐含权限。Renderer不得把缩略图URL或私有路径
字符串冒充可交付素材；接收方可能延迟读取，交接内容保留到安全清理条件满足。

原件、选定视频帧和兼容导出是不同交付物，明确显示选项及格式。目标不支持该格式、
原件离线、交接取消时提供准确失败与复制/显式导出的替代入口。“能拖拽”需要分别验证
macOS/Windows及具体接收应用；不能承诺任何软件、网页输入区或任意网络端口都接受。
拖入第三方网页可能由接收方上传，但不允许本应用附带自动云端上传或扩大素材范围。

## 录屏插件与视频参考能力

录屏插件负责取得用户选择的屏幕/窗口/区域和可选音轨，控制开始、停止及实际支持的
暂停，产生录像；宿主负责经检查的入库和长期资产。屏幕、系统音频和麦克风遵守各自
系统权限和本次选择；普通插件权限不默认开启录制。网页在Chrome/Edge中运行，
无须重新嵌入浏览器，也不要求分析页面代码才能录制。

建议把基础视频查看、手动挑选多个参考帧、帧与视频的关联、来源网址持久保存作为
宿主的素材能力；录屏执行和自动挑帧/深度分析通过插件或可替换提供者扩展。这样用户
自行导入的视频也能使用参考帧，卸载录屏插件不会失去已录视频及其参考信息。
这一分层不要求默认批量解码或使用视频大模型，具体支持格式仍要以实现证据确认。

一个动态参考可包含：

- 主视频素材及其来源内容版本。
- 用户选定的多个参考帧，每个有实际展示时间戳、顺序、备注和必要的解码/派生信息。
- 网站来源网址、可选标题与录制时间；由用户填写/确认，未来浏览器连接器可辅助提供。
- 相关AI分析，标明分析的是哪些帧/时间段，不把少量截图结论宣称为整个视频的理解。

这里的“关键帧”指用户选中的**参考帧**，不等于编码器的I帧。时间跳转要反映实际解码
结果，不能把最近I帧或近似seek结果伪装成所选帧。参考帧初始是与视频关联的持久记录，
不是必然生成一堆独立库素材；用户可显式保存为独立图片或拖出派生图片，并保留来源关系。
用户选帧与备注不能作为普通缩略图缓存被清理；派生静帧的保存策略需保证来源变化后仍能
解释/保留已确认的参考。原视频不覆盖；删帧关系不删视频，删视频不级联删除已保存的独立图片。

录制被取消、中断、磁盘不足时应报告可恢复/不完整状态，不能把未完成文件当作可播放
成功素材；插件返回文件提案，Capture Gateway仍负责校验、身份、幂等及入库。
来源网址不包含Cookie、认证header或隐含页面登录权；登录令牌及凭据型网址参数不得持久保存；其余敏感网址内容在保存前确认/清理。
网址失效不影响已保存录像与参考帧，打开网址使用外部浏览器。

## 未来的实现分析

录屏保存视觉效果与交互时序，适合记录滚动、悬停、过渡和多步骤状态。
它不保存完整DOM、样式、原始组件、后台逻辑或所有交互分支。未来本地模型或显式
授权的云端AI可以基于选定视频片段/参考帧提出“怎样实现类似效果”的分析和代码建议；
这不等于恢复网站原始源码，也不自动授权执行生成代码或向外部发送整段录像。
新云端开发接口仍遵守ADR 0484的暂缓范围。

## 当前实现与后续验证

2026-09-14源码核对：Main的Asset Card controller仅持有一个窗口/一个当前素材快照，
支持受限素材顺序导航、置顶、会话草稿及既有AI/图片工具；窗口壳有sandbox和Library
generation校验。视图使用图片预览。它是可复用基础，尚非多工作集、多窗口持久恢复、
视频工作模式或跨应用原生文件交接的交付证明。
[当前模块](../../src/main/asset-card/README.md)、[契约](../../src/shared/contracts/asset-card.contract.ts)。

建议实施顺序（不是自动执行队列）：先验证多素材工作集/多原生窗口/保存恢复与安全拖出，
再补受支持视频的查看、时间定位与多参考帧，最后用录屏作为实际插件需求验证采集接口。
视频和其他支持素材属于工作模式目标，不因第一步只用图片验证就宣称整个模式完成。

关键验收包含：两个工作窗口独立工作；保存后重启恢复；增删成员不改变原件/标签；
关库撤销全部访问；显示器变化能找回窗口；不同来源/格式拖出字节与声明一致；
多参考帧可回到正确视频位置；视频来源变化可识别；插件卸载后素材和参考记录仍可使用。
本轮只更新产品/领域文档，不运行应用、录屏、访问真实库或改变IPC/schema。
