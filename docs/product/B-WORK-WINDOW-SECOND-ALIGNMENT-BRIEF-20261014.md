## 用户结果

从正式B入口打开工作集，使用仅以素材引用为内容的原生工作窗；按素材数量展开到与Dropover一致的档位，紧凑背景/边缘双击快速停靠，底部原生材质胶囊完整显示滚动名称，并从右上角调用系统及本机文件/图像功能。

## 已确认的决策

1. 彻底移除工作集自己的颜色和文字备注能力，包括历史数据清理。不是只隐藏两个模块。不删除素材笔记、素材颜色理解、独立Palette Folder或原件。该取舍见[ADR0494](../adr/0494-work-sets-retire-own-notes-and-palettes.md)。Host进行显式、有版本、可恢复的迁移；只读打开不得偷偷破坏性升级，失败保留旧库和其他内容，公开可恢复副本先验迁移及重开。
2. 展开尺寸按数量及屏幕可用上限自动决定，取消手动缩放但允许移动位置。原版实测1–2张400×207、3/5张400×310、6–7张400×435pt；静态策略≤2/3–5/≥6，与数量边界样本吻合。扩展到空工作集、小屏及其他支持素材类型时要复核，不能凭四点强行推广。DAM已展开时增减素材也平滑调尺寸，继续沿用中心/左右边缘及垂直中心锚点，边界夹取不当用户移动；保留选择和滚动位置。原版当次7减5不即时缩小、重新展开才变310，DAM即时调整是明确产品取舍。
3. 仅紧凑背景/边缘双击停靠，图片、胶囊、关闭和菜单保留各自操作。沿用当前停靠抓手、点击恢复和可中断运动；不把展开窗双击新增为停靠入口。右侧位置原版已实测；静态已恢复最近可用边缘、双击零速度0.3秒停靠，后续已补中部偏左→左停靠及靠左停靠/恢复；精确等距/多屏仍待补。原版距任意边缘≤26pt并排除可见交互控件，按这一精确资格对标。双击不能误清空/删除引用或通过第二下触发相邻控件。
4. 底部展开按钮是两端完全圆角的原生材质胶囊。内容为工作集名称与固定方向箭头；长名称采用滚动、两端渐隐，短名称稳定显示。实际原版有两文本图层、12pt间距及独立视口/渐变mask；长标题已连续实测循环滚动。原版整窗玻璃和胶囊自定义控件须区分，不声称已证明它是独立NSGlassEffectView。减少动态效果应保持名称可读和入口可操作，不让滚动动画阻塞点击、拖动或中断。
5. 尽可能完整覆盖实际菜单的本机功能。云端/第三方服务另行确定，本轮不接云账号、上传或做空菜单。紧凑态全部，展开态所选优先且显示范围/数量，沿用此前范围规则；系统支持列表依实际素材类型和本机可用应用生成。

上述菜单是功能对标，原版翻译错误/固定应用列表不复制为DAM产品文案；不把包内候选或菜单存在当执行成功。原件保护使某些文件动作的语义与Dropover直接持有文件不同，这项取舍已明确确认。

## 保留的验收边界

正式B入口→唯一Host→原生交互→正确结果→保存/重开→取消、失败与撤权保护。当前已指定公开生成PNG继续用于原版对照及后续验证，不替换为用户私有素材。

数量尺寸与胶囊每个状态必须绑定实际frame/材质树和连续画面；旧阶段时序/黑框证据不能替代新移除模块后的布局资格。菜单动作须验证实际输出/系统选择器、取消、无支持应用及失败；任意“成功”提示或空按钮不算完成。迁移只在真实可恢复公开库副本实验，恢复原件和非工作集内容，失败不降低保护标准。
