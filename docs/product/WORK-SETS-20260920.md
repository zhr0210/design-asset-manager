# 多素材工作集、原生悬浮窗口与布局恢复

2026-09-20，批准顺序第3项。素材引用、排列、工作备注和颜色正式持久化，多个原生窗口独立工作，
下次打开资料库后可以恢复。工作模式与原型共享WorkReferencePanel，保留当前灰色/玻璃设计。

## 用户流程

- 全部页多选→加入工作集；详情栏可将单个素材加入新建/已有工作集。
- 工作模式页可新建、编辑、另存和删除工作集。编辑器支持按名称搜索已有素材、追加、移除与调整顺序。
- 点击工作集卡片打开原生悬浮窗口；重复点击聚焦已有窗口。每个窗口可展示多张图片、切换1–4列、
  前移/后移参考、编辑独立工作备注并保存。移除参考或删除工作集不删除库素材。
- 图片配色菜单和色板页可将HEX颜色加入选定工作集。原生窗口在备注上方显示色板，支持复制/移除。
- 悬浮窗口按空格打开同窗口专注查看，支持缩放/平移、工作集顺序画廊及正式图片笔记。
  信息只读；“在资料库中复用/检查与分析”定位主界面，使用已有编辑、AI和图片工具。
- “添加参考”返回资料库并打开对应工作集编辑器，即使主窗口此前停在设置等页面也能定位。
- 每个窗口可置顶/取消置顶、移动、调整大小、隐藏、找回和关闭。隐藏保留草稿；关闭窗口不删工作集。
  “收起资料库”让设计工作旁边只保留参考窗口，至少显示一个工作窗口避免全部不可见。
- 原单素材卡片及其工具在工作模式的兼容展开区保留，已有描述/提示词草稿继续使用原链路。

## 保存、恢复与失败

工作集保存名称、成员顺序、1–4列设置、备注与颜色。素材离线/在回收站时保留成员身份，显示不可用；
恢复素材后重新出现，不静默从工作集中删掉。工作备注独立于素材全局描述和标签。

首次工作集保存显示v7升级确认；取消/读取不升级。原笔记/文件夹/色板/AI/下载与恢复兼容v7，
不会降回旧版本。工作集每个版本独立，冲突保留当前输入/窗口草稿，用户核对后重新读取。
原生窗口Save将工作集内容和当前实际尺寸/位置/置顶一起提交；任一写入失败整次事务回滚。
普通移动/缩放会延迟记录窗口位置，失败显示位置未保存，不伪装成功。

设备布局按应用设备档案隔离；搬到另一个设备不会套用旧屏幕位置。关闭应用前保存的打开窗口，
在重新授权打开相同资料库后，通过“恢复工作窗口”显式重建。重启不自动分析或发声。
找回窗口将其放回当前可见工作区。真实显示器拔除未在本轮实测；相关钳制算法以合成工作区验证。

窗口有未保存工作集或笔记时，关闭/退出/切库有保留编辑的选择。隐藏不丢草稿；明确放弃或应用
崩溃会丢失尚未保存的内存内容，已保存记录仍在库中。显式Close将当前设备的open状态设为false，
工作集保留，可再次点卡片打开。仅Hide的窗口仍属于本次可恢复工作空间。

## 存储与权限

新增work_sets、work_set_members、work_window_layouts；工作集在Active Library数据库中，
窗口几何按device_id隔离。app-state.sqlite仅保存随机设备档案身份，不含工作集素材数据。
每次写入校验活动库、generation、绑定会话与工作集revision；关库阶段禁止重开退休会话窗口。

work-window.cjs为独立sandbox预加载，不暴露electronAPI或assetCardAPI。Main只接受自己拥有的
frame与token，拒绝其他窗口令牌。每个窗口使用独立内存session；本窗口专属dam-preview处理器
验证当前成员范围，旧窗口/移除成员/Trash素材拒绝读取。外部HTTP(S)网络被禁用（开发模式只放行
自身开发入口），没有路径或进程能力。笔记读写也被限制在当前工作集成员。

当前最多200个工作集、每集200份参考和64种颜色；最多同时存在8个原生工作窗口，隐藏也计入。
达到上限可用“关闭窗口”释放槽位，保存的工作集不删除。图片按需加载，未声称无限解码能力。

## 验证与交付边界

全部使用生成素材、独立profile/素材库。Main测试覆盖升级确认、v7重开、设备隔离、重复打开、
两个窗口的sender/token隔离、成员范围预览/笔记、备注/排序、置顶/隐藏/恢复、回收保留、
原子保存失败回滚、移除/删除不删素材、离屏位置找回、退休会话拒绝。

实际Electron验证两个原生窗口、无广域预加载API、外部网络拒绝、跨工作集素材访问拒绝、
独立备注、排序、窗口尺寸/位置/置顶、空格查看、原生窗口笔记保存、色板复制、隐藏恢复、
关闭确认、取消切库保留草稿、从设置页定位、主库收起、关库撤销和完整应用重启恢复。
原图哈希保持；既有AI/下载/图片工具/恢复的v7回归独立执行。证据目录由TASK收尾记录。

本轮是已支持图片的工作模式。没有实现视频/参考帧、屏幕录制、原生跨软件拖出、点击穿透或插件SDK。
在资料库复用的按钮是显式导航，不冒充文件交接。macOS未打包运行已经验证；Windows、打包产物、
跨Space/全屏应用和真实多显示器切换没有本轮实测证据。
