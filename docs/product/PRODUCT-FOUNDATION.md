# 产品定位与能力边界

更新：2026-09-14。依据：本轮用户确认的产品愿景与文档调整请求。
本页是当前产品范围与优先级的统一入口；架构理由分别见
[ADR 0483](../adr/0483-ai-plus-core-product-and-extension-boundaries.md)和
[ADR 0484](../adr/0484-extension-contracts-and-deferred-agent-development-access.md)；
本轮新增的工作模式和录屏分层见[ADR 0485](../adr/0485-work-mode-preserves-reference-context-and-host-owned-media.md)。
接受方向不等于批准所有实现、已完成功能或允许访问真实数据。

## 产品定位

面向视觉设计相关工作者，以本地AI理解为核心的素材管理与创作工作台，
通过统一扩展契约提供实用工具。AI+是标准产品体验和差异化重点，
基础管理负责可靠、顺手地支撑“收录 → 理解 → 检索 → 检查 → 复用”。
工作模式把选定参考持续展示在实际设计工作旁边，补上素材库到创作现场的连接；
AI+理解、可恢复的参考工作上下文与实用插件共同构成产品差异化。

普通用户不应为了基础分析逐个安装第三方插件。内置能力可使用可替换的分析器与
模型适配器；“内置”不意味着写死某个模型，“可替换”也不意味着第三方能替换
素材写入、权限和原件保护规则。无模型时基础管理可用是降级保障，不是降低AI+优先级。

## 能力分层

| 层 | 当前产品目标 | 约束与优先级 |
| --- | --- | --- |
| 可靠基础 | 本地导入、素材浏览/检索、标签、检查器、复用、可恢复操作 | 支撑AI+闭环；不要求首版复刻竞品全部长尾功能 |
| 内置AI+ | 颜色分解/占比、标签建议、画面描述、提示词重建、必要OCR及统一检索 | 当前核心；使用适配目标设备的开源小参数模型与确定性算法，效果/资源须实测 |
| 工作模式（暂名） | 图片/视频及其他支持素材的工作集、多悬浮窗口、保存恢复、增删参考与跨应用拖出 | 内置核心；不承担库整理，移除参考不删原件；按格式/平台核实交付 |
| 可选专业工具 | 录屏、抠图、分层/可编辑图层、复杂生成、行业或编辑器工具 | 按需插件；不进入默认分析队列，不成为核心交付前置 |
| 扩展平台 | 统一数据/任务/权限/版本契约、按需激活、SDK和参考插件 | 随具体插件需求逐步验证，不一次冻结完整生态 |
| 远景 | Chrome/Edge连接器、云端AI开发接入、社区分发及更完整生态 | 留接口边界与文档；按后续明确任务推进，不阻塞当前AI+ |

内置网页浏览、网页采集、网站登录和外部来源搜索已移除；独立图片直链下载、
本地文件导入及既有Eagle相关能力保持各自现有状态。高阶工具按产品角色和资源
成本划分，不把“插件”定义为只能高算力执行的功能。

## 从素材库进入创作现场

[工作模式与动态设计参考](WORK-MODE-AND-MOTION-REFERENCE.md)是核心产品规格。
工作集保存素材引用、顺序、布局和工作备注，可在多个原生窗口中持续参考，下次恢复。
查看、适用的AI/工具及安全复用按能力保留；分类、标签管理和全局素材整理回资料库。
窗口设置不保存活跃权限，切库撤销访问；从工作集移除或关闭窗口不删除素材。

录屏由可选插件完成，结果仍经宿主受控入库。视频、用户选择的多个参考帧、时间位置
与来源网址由宿主持久管理，可服务普通导入视频；卸载插件不删除已收录内容。
手动选帧/视频参考作为基础媒体能力的具体交互见规格建议；自动选帧和复杂分析可扩展。
录像保留观察到的效果/过程，不代表保存源码；未来AI可给出类似实现建议，云端分析仍需
选定素材/帧范围的明确授权。新增云端开发服务仍暂缓。

## 素材整理与颜色复用（2026-09-14补充）

资料库当前设计采用全部、文件夹、工作模式、回收站四图标，配合底部搜索/标签与布局滑条；
普通/AI文件夹和色板集中在文件夹页，工作集集中于工作模式。此前宽侧栏方案被本轮极简
画布取代；素材整理的领域边界保持。[设计与研究](../design/MINIMAL-CANVAS-20260914.md)。
AI文件夹只对有AI标签分析证据的素材动态匹配，成员是引用而非文件副本；一个素材可以
命中多个分类，未分析和无匹配不能伪装已分类。AI建议与用户确认标签保持不同状态。
普通文件夹、工作集和AI文件夹分别表达手动组织、创作上下文与分析条件，不互相覆盖。

色板收藏色值并按色板文件夹管理，同一文件夹内同值去重。图片配色色块左键复制，
右键可选择/创建色板文件夹或添加到工作窗口；工作色板在备注上方，增删不改变
原图配色或全局收藏。检查器将配色置于预览下方，移除重复素材标题。
工作模式中聚焦素材按空格预览，输入框和视频播放键不受干扰。当前均为原型交互，
正式动态索引、色板持久模型与原生快捷键接线另行验证。

## 统一分析与检索

- 颜色比例来自有版本的图像计算口径，注明采样/近色合并/透明像素与分母处理；
  AI可解释配色风格，不能凭文本生成伪装成测量比例。
- 区分测量数据、AI观察/推断、提示词创作推演和用户确认/编辑的内容。结果归用户，
  保留素材版本、输入视图、模型/算法/插件与recipe来源；模型更新不覆盖手工内容。
- 标签、描述、OCR、反推提示词和颜色结果都须有持久保存、索引、修正及复用路径。
  临时创作草稿/普通搜索历史不默认混入持久素材索引；AI建议可在明确标注的搜索
  范围参与匹配，但不能成为已确认标签或精确用户事实。
- 颜色占比/尺寸等用结构化条件，文字用词法检索，设计语义用经验证的语义通道。
  混合检索解释命中来源；提示词命中不能冒充画面客观事实，缺少分析不等于负面结果。
- 产品核心不等于全部自动运行。轻量颜色计算可先行；受控的标签/描述/OCR/embedding
  渐进生成；提示词重建默认按需或用户明确配置的批次执行。历史全库回填单独选范围。
- 候选素材可先进入可用状态；AI任务等待、失败、未确认或模型缺失不阻塞基础工作。
  一个可信宿主管理本地资源、任务取消/恢复与权威写入，插件复用已有结果和模型资源。

## 云端推理、AI开发与社区是三条边界

| 概念 | 做什么 | 不代表什么 |
| --- | --- | --- |
| 云端模型推理 | 经API对本次披露并授权的素材/文字执行分析 | 配置provider不授予素材上传、代码修改或插件安装权限 |
| 外部AI开发接入 | 未来让云端/本地AI客户端理解SDK，在授权开发工作区读写代码、运行检查、生成插件包 | 不默认访问真实素材库、密钥、模型缓存、已安装应用或整个硬盘 |
| 社区插件分发 | 开发者使用自己的AI开发，经验证后由用户选择分享和安装 | AI生成、签名、安装或社区上架都不代表无限执行权限或已通过质量验证 |

现有OpenAI-compatible等推理接线保持当前能力和确认规则；本轮没有取消它，
也没有将它扩展为远程开发服务。新增云端开发API/MCP连接器、托管服务、账号、
计费和市场运营暂不优先，在没有已验证需求/付费依据时不建设完整云平台。
“预留”指清楚的能力/身份/数据边界和可适配契约，不是空服务器、占位公开端口或
先开放通用文件/命令执行API。用户以后提出具体任务时再选择协议版本、传输和实现。

AGENTS.md/SDK指南/能力目录帮助AI理解产品；MCP是可选上下文与工具接入协议。
实际授权、身份校验、路径/数据范围、资源与外发限制必须由宿主和执行边界实施，
不能交给提示词、MCP声明或插件自己的自觉。开发、推理、安装/启用、发布是不同动作，
已经明确批准的具体范围可持续复用，范围扩大再确认。

## 文档与开发方式

- 最新用户请求确定任务。AGENTS.md负责协作和安全边界，本页负责产品范围，
  ADR负责决策理由与明确替代关系，CONTEXT.md只定义领域词汇，DESIGN.md负责UX/UI。
- 实现状态只从[实施状态](../agents/implementation-status.md)、模块说明与代码/验证
  核实；ADR Accepted、未来规格和旧TASK不会变成已交付功能或自动执行队列。
- 先明确核心任务流和状态，形成低保真UX及简短数据/接口约定；以真实能力纵向验证
  后细化UI。不要先精修全部页面，也不要仅凭视觉规范直接冻结完整SDK。
- 当前核心范围包括内置AI分析到检索/复用，以及能在设计时持续使用的工作模式。
  按具体请求验证这些闭环，再用少量实用插件验证契约，录屏可作采集类参考需求。云开发、
  社区市场、复杂格式/图层和所有长期SDK贡献面不构成当前工作前置。
- 历史记录保留。发生冲突时按新ADR的具体替代范围处理，不能借“最新方向”废除
  原件保护、用户状态优先、无静默外发和真实证据要求。
