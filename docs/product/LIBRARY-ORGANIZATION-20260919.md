# 普通文件夹与色板正式保存

2026-09-19，按批准顺序完成第2项。沿用已批准的磨砂文件夹、底部搜索与标签、浮动导航，
将普通文件夹、成员关系和颜色收藏接入正式素材库，不使用原型localStorage。

## 使用流程

- 文件夹页或底部菜单新建普通文件夹/色板。进入子页后可继续新建同类子文件夹。
- 选择素材后“加入文件夹”，可选已有位置或新建并一次性加入；详情栏也有单项入口。
- 文件夹子页与全部使用相同素材网格、搜索、标签与尺寸控件，支持前进/后退。
  多选后“从此文件夹移除”只删成员引用，不删素材。全部的“未分类”现在按普通文件夹成员查询。
- 文件夹编辑支持改名、移动上级位置和删除。父文件夹有子项时拒绝删除，先移动或删除子项。
  不允许把文件夹移入自己/后代，也不允许普通文件夹与色板相互嵌套。
- 图片配色左键复制HEX，右键“添加到色板”可选已有色板或新建；专注信息栏也使用同一路径。
- 色板页可添加颜色代码/使用系统颜色选择器、复制、移除、按HEX搜索。颜色统一为大写6位HEX，
  重复收藏同色只保留一份。重新打开资料库和重启应用后，文件夹与颜色均恢复。

## 本地配色口径

正式详情栏原先没有可消费的配色来源。本轮增加受控预览的确定性采样接口，完成真实
“图片→颜色→收藏”路径：Main在当前库写锁范围内读取受控预览，最多128×128采样，转换sRGB，
透明像素按alpha加权，4bit颜色直方图取最多5个候选中心，按RGB最近中心汇总权重。
比例按最大余数法保留两位小数，非空结果合计100%；全透明图返回空结果，解码失败可重试。

界面标注“预览测量”，不是原件全分辨率精确分解，不执行模型，也不使用演示比例。
颜色菜单收藏保存HEX及可选来源素材引用，不保存这次占比。工作窗口中的色板共享仍待后续实现。

## 数据和安全

v6在当前库控制目录数据库新增library_folders、library_folder_assets、library_palette_colors及
版本记录。首次写入需要确认升级；提示旧版应用无法打开v6。普通读取、打开库和取消不升级。
升级与命令写入同一事务；失败全部回滚。每次写入检验库身份、generation、当前绑定token、
全局组织revision及输入字段；过期请求拒绝并保留输入，刷新后再由用户重试。

普通文件夹是组织关系，不对应磁盘目录。加入多个文件夹不复制文件；删除叶文件夹只删除
其成员/颜色记录。回收站成员不显示于活动计数，原关系保留，素材恢复后自动回到原文件夹。
同级同类文件夹不允许重名，最多2000文件夹、20层，单色板最多5000色，单次最多500素材。

## 当前边界

- AI动态文件夹仍未接通，不用已保存标签视图冒充AI/普通文件夹。
- 文件夹封面来自当前已加载的真实成员，色板封面来自已收藏颜色。
- 当前子页展示直接成员；父页不隐式合并所有后代。搜索根页名称/当前色板HEX。
- 不自动整理外部Eagle目录、不移动原件、不新增文件格式解码或云端上传。
- 一次组织写入使用全局revision，并发修改无关文件夹也可能需要刷新重试。
