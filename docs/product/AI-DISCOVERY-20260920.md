# 第四步：AI 结果、可解释搜索与动态文件夹

状态：正式数据接线；验收只使用合成素材、临时库、测试进程持有的本机 HTTP 响应。
未启动真实模型，未读取或写入真实 Eagle/用户库，不宣称推理质量已验证。

## 用户流程

1. 选择素材，在侧栏直接展开「AI 分析与提示词反推」。配置服务不代表执行授权；
   现有 prepare/run 确认页继续说明所选素材、模型、本地/外部地址与受控预览范围。
2. 完成后显示模型/时间、画面描述、建议标签、反推提示词及 OCR。用户描述优先，
   另存的 AI 描述可展开；建议以小星形标记，与已确认标签分开。
3. 底部搜索匹配标题、文件名、确认标签/别名、AI 建议、用户描述、AI 描述、
   反推提示词和 OCR。卡片说明具体命中字段；仍是词法匹配，不是向量/语义检索。
4. 文件夹根页显示普通文件夹、AI 文件夹、色板。「全部已分析」「标签待确认」及
   按当前 AI 标签生成的分类使用相同 FolderCard。子页复用素材网格、底部搜索、
   标签、专注模式与工作集入口；名称搜索可找分类。普通分类不会冒充 AI 分析资格。
5. 建议无需确认即可搜索/分类。点击侧栏建议可确认，既有确认接口保存用户标签；
   确认不复制素材、不覆盖用户描述，也不强制每条建议必须处理。
6. 重新分析成功后分类跟随新结果；旧结果不累加为当前分类。已确认标签独立保留。
   失败保留上次已提交结果。关闭分析面板不阻断 Main 通知更新；重启从库内证据恢复。

## 数据规则与兼容

- 现有素材读投影增加可选 `visualAi: VisualAiSummary`，包含 evidenceId、模型、时间、
  画面描述、提示词、OCR、当前标签与待确认标签；旧字段含义、所有写接口保持不变。
  Preload/Renderer 同步映射，缺失摘要视为没有当前有效分析，不依赖旧 ai_status 默认值。
- 当前摘要取同 Asset revision、preview reference 的最新一次完整提交，按 createdAt/id
  排序；分析与反推均沿用现有统一输出格式。历史证据仍可在分析面板查看，不能混充最新结果。
- 标签建议按对应证据读取决定，已拒绝建议排除；与当前确认标签做规范化比较后计算待确认。
  移除确认标签不会删除历史 AI 证据，该建议可再次显示为待确认。
- 素材列表在 held Active Library connection 中查询，一次读取摘要与相关建议；不逐卡
  发送 N 次 Renderer IPC 请求，不读取 Original。选定素材读取保留 ID 范围。
- AI 文件夹是当前有效摘要派生的 Asset ID 集合，不持久化第二份成员表、文件或浏览器缓存。
  阅读 v1–v7 不升级库；首次分析仍按已有确认流程按需启用 v2 证据表，v5/v6/v7不降级。
- Trash 与失效 revision/preview 不进入当前分类；证据列表和确认操作也检查预览一致性。
- 「未标签」继续指没有确认标签，「未分类」继续指没有普通文件夹成员关系。
  AI 分析不自动替用户完成整理。

本轮不添加用户自定义 AI 规则编辑器、嵌套 AI 文件夹、自动批量推理、embedding、
Runtime/模型下载、外部开发连接器或插件市场。固定汇总和标签分类覆盖本轮找回闭环。
不宣称真实硬件推理、真实 Eagle 接线或百万素材性能已经验证。
