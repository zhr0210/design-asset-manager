## 已确认的方向

面向设计师的 AI 素材管理应用，素材管理与应用交互全面对标 Eagle，后续
扩展设计工具。保留功能目标与软件基础框架，允许简化内部实现和重做 UI/UX。
用户已同意按功能盘点、信息架构、交互原型、逐步替换、证据清理的顺序推进。
随后明确要求“恢复禁用的功能并继续”。因此禁用能力恢复属于本次重构的
完成条件，不能以只完成新外壳或继续显示不可用作为整体交付。

Electron / React / SQLite / Python AI 的现有分工暂作基础。保留本地优先、
原件 ownership、用户编辑优先与外发授权约束。入口迁移不改变数据权限。
本草案不是删除清单、已完成规格或生产修改证明。

## 导航与设置结构草案

主入口建议为素材工作区、采集、工具箱；设置作为稳定辅助入口。
资料库切换与管理贴近素材工作区。保留总览信息、标签管理、Eagle 连接和旧库找回
的可达入口，其最终呈现层级交由原型验收。

| 设置归属 | 包含内容 | 作用范围 |
| --- | --- | --- |
| 外观与操作 | 主题、显示习惯、快捷键 | 应用偏好；视图临时状态由工作区持有 |
| 资料库配置 | 当前库信息及可用的管理动作 | 当前资料库；打开和切换从资料库菜单进入 |
| AI | 能力配置、模型、服务、资源预算、提示词、隐私 | 应用默认；动作外发授权在动作发生处取得 |
| 采集 | 来源账号、下载与采集偏好 | 采集配置；任务执行在采集区域 |
| 高级维护 | 诊断、恢复与经批准的迁移 | 按具体动作显示作用范围和可用性 |

各项只有一个权威编辑入口，其他页面可以提供深链和状态摘要。
模型管理可保留独立子页，不要求把全部配置压成一个大设置组件。

## 已解决：首轮恢复范围

用户选择首轮包含恢复禁用功能。可以分切片执行，但 AI、下载、模型运行环境、

继续使用旧写入路径；已有素材库 authority、来源保护和外发授权规则仍适用。

## 交互原型

[原型说明与启动](../../src/renderer/routes/refactor-prototype/README.md)。
用户已确认 A 作为主界面、C 作为查看模式，B 不再独立；新增桌面悬浮卡片。
底部提供资料库/专注查看/悬浮卡片三个模式，使用液态玻璃、背景模糊和圆角矩形，
切换顺序为画面模糊、显示目标模式名、渐变到新页面。模式不改变素材身份或权限。

当前原型共享 16 个合成样张和内存状态。卡片从上到下显示图片、基础信息、AI 与
工具操作、提示词反推草稿；可拖动、固定位置、预览编辑并保留示例副本。
设置分类已统一，撤下旧 B 独立界面；没有自动把原型代码提升为正式实现。
原生浮窗的跨应用置顶/多屏生命周期、真实图像编辑与反推仍是正式接线工作，
浏览器内卡片不等于完成原生桌面能力。原件不覆盖和逐动作外发授权继续保留。

## 后续步骤与完成标准

1. 继续补齐复用、格式支持与每项 AI 能力的直接调用链，形成可审阅的完整保留清单。
2. 按已确认的三模式信息架构完善合成素材原型，验收交互细节与玻璃动效。
3. 原型结论稳定后，生成短规格和有明确依赖的实施切片；逐条记录用户验收与聚焦测试。
4. 调用方迁移完成后才评估对应旧代码清理，不以文件大小或行数作为删除依据。

恢复的依赖次序是：当前资料库的标签/分析写入能力 → 有身份和版本约束的 AI
任务提交/结果接收；模型管理和 Runtime 生命周期提供实际执行条件；下载执行
独立推进，但进入素材库仍依赖 Capture Gateway。配置与诊断按同一目标范围
注入依赖，避免重新创建读取全局状态的单例。前端定稿影响入口呈现，不改变
这些恢复要求。正式接口变更应在具体切片中给出调用方、兼容语义和验收证据。

完成检查必须包括：基础无模型流程、每种 AI 的真实执行与失败、动作级外发授权、
下载取消/重试/真实入库、关闭切库后的陈旧结果拒绝、用户编辑保留、标签维护
一致性、模型安装/激活区别和恢复、只读库/来源保护，以及 Windows/macOS
分别可证明的实际能力。没有真实外部来源或 Runtime 条件的项明确列为未验证。

## 2026-09-12 恢复进展

正式 Library/原生卡片增加视觉 AI 分析、画面文字、标签建议与提示词反推。
Main通过配置的兼容HTTP服务执行，用户确认具体模型和素材预览范围后才发送；
无隐式fallback。结果绑定素材版本与预览，保护手工描述，标签逐项接受，提示词
只追加到草稿。首次确认AI动作会升级该库到可重开的v2证据schema；旧应用不支持v2。
原生卡片关闭/换图与Library变化会撤销旧任务；跨窗口变化刷新当前库。

下载页、来源搜索与网页采集入口恢复直连PNG/JPEG/WebP的确认、真实传输、取消、
重试与Capture入库。32MB上限、不发送Cookie、不跟随重定向，无断点续传。
部分Capture失败保留恢复记录并显示需要恢复；重启历史不证明素材仍存在。
集中表恢复download enqueue/retry后余90项；AI通过新的受控接口提供，旧aliases
继续拒绝。因此channel数量不能衡量已完成的功能数。

证据：合成集成测试证明HTTP传输、撤销、配置变化、用户状态保护、标签接受、下载
取消/重试和v2持久化；macOS未打包Electron验证正式Preload、原生卡片确认/分析/
提示词追加/标签刷新和下载入库。未读取真实用户库、未执行真实模型；不声称模型
输出质量、完整Runtime/模型安装、图像编辑、高级标签或整个应用重构已完成。
