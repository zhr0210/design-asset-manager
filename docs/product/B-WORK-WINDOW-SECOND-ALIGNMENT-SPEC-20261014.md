# B工作窗第二轮：素材引用、数量尺寸、快速停靠与系统菜单

2026-10-14，本地规格准备。用户已确认共同理解达成，并明确“补齐调研与规格准备，暂不实施”。该准备状态已由2026-10-15用户显式 implement 替代，授权实施全部15项并在可恢复公开库副本验证；未发布Issue。实施资格见[当前状态](../handoff/CURRENT-STATE.md)。确认来源见[准备稿](B-WORK-WINDOW-SECOND-ALIGNMENT-BRIEF-20261014.md)，原版证据与限制见[对标调研](../../artifacts/reverse-engineering/dropover-5.2.0/second-alignment-20261014/RESEARCH.md)。

## Problem Statement

98cace0基线的B工作窗包含工作集自己的颜色和文字备注，固定640×520展开，紧凑背景双击不提供快速停靠，名称按钮使用普通生硬底色；系统菜单能力较Dropover不完整。用户要求聚焦素材引用与本机复用，以实际原生机制对齐数量尺寸、停靠、胶囊名称和功能菜单，同时保持唯一Host及库内原件保护。

这项修订替代前轮规格中的固定展开尺寸和工作集颜色/备注保留要求；此前已批准的轮廓修复、锚点、分段呈现、选择背景160ms、取消/撤权与素材笔记保护继续成立。原版存在与DAM不同的数据权威和取消语义，功能对标不复制其原件改动或未经证实的回滚承诺。

## Solution

正式B入口→工作模式→打开/恢复工作集，使用220×240pt紧凑窗。工作集仅保存名称、素材引用及顺序等有效内容；颜色/文字备注彻底退役并通过Host的显式版本迁移清理。按原版数量档位和屏幕上限展开两列网格，增减素材自动调档，窗口可移动而不可自由缩放。紧凑可用边缘区域双击快速停靠，胶囊名称使用原生材质与溢出滚动。从同一菜单安全调用本机系统查看、分享、文件和图像能力，所有对文件产生改变的动作操作独立交付副本。

## User Stories

1. 作为使用工作集的设计师，我希望主工作台、工作集编辑器和原生工作窗都移除工作集颜色/备注入口，以免退役能力在另一入口继续出现。
2. 我希望历史工作集颜色/备注经明确迁移清理，同时成员、名称、顺序和布局保持，以便继续原有参考工作。
3. 我希望素材笔记、图像配色理解、独立色板和原件保留，以免删除工作集模块影响其他内容。
4. 我希望迁移前具有可恢复备份、迁移失败保留旧库，取消不会修改库，以便安全接受这项变化。
5. 我希望升级和旧客户端兼容限制明确，以免旧程序错误写回退役字段。
6. 我希望1–2项以400×207、3–5项以400×310、6项及以上以400×435pt展开，以便数量不同有合适窗口尺寸。
7. 我希望新增或移除成员时展开窗平滑调档，保留当前有效选择和查看位置，以免必须先收起再展开。
8. 我希望自动尺寸受当前屏幕可用范围约束、容量外可滚动，以免窗口超出可操作范围。
9. 我希望窗口仍能移动，尺寸由数量决定，以免手动尺寸与自动调档互相覆盖。
10. 我希望中心/边缘锚点、未移动回原位和移动后跟随的关系保持，以免数量变化造成位置漂移。
11. 我希望空工作集仍可接入素材，目标为空的菜单不可执行，以免空状态伪造成功结果。
12. 我希望双击紧凑窗的可用边缘背景就能快速停靠，以便不必拖到屏边。
13. 我希望图片、名称胶囊、关闭和菜单的双击保留各自操作，以免文件操作触发窗口移走。
14. 我希望停靠方向使用最近可用边缘并排除相邻屏幕冲突，抓手能恢复，以便保留既有停靠保护。
15. 我希望新输入或再次操作立即接管旧运动，以免旧完成把窗口拉回旧位置。
16. 我希望名称入口是完全圆角的原生材质胶囊，边缘和高光与玻璃底板协调，以免出现普通矩形色块。
17. 我希望短名称稳定显示，长名称在有限视口中循环滚动并淡化边缘，以便读到完整名称且箭头保持稳定。
18. 我希望名称变化、隐藏或退出后旧滚动失效，减少动态效果时名称仍可读，以免动画残留或阻塞操作。
19. 我希望菜单清楚显示“全部N项/所选N项”，紧凑不受保留选择影响，以免误交付素材。
20. 我希望打开方式来自本机支持当前类型的应用，Finder与显示信息能查看实际交付结果，以免固定假列表。
21. 我希望新增原生Quick Look，同时保留DAM独立大预览，以便两种查看方式各有入口。
22. 我希望AirDrop、邮件、信息及更多系统服务使用系统选择器，由我决定目的地并可取消，以免后台自动发送。
23. 我希望服务随类型和数量变化，并明确不支持/不可用原因，以免某个服务失败冻结无关功能。
24. 我希望剪贴板添加、文件/路径复制、目标文件夹复制/移动、改名、ZIP和废纸篓都能产生真实结果，以免只复刻菜单文字。
25. 我希望这些文件动作只处理独立交付副本，目的文件不被覆盖，库内原件不变，以便安全复用。
26. 我希望调整大小、转换、压缩、元数据清理、标注/遮挡、拼接、OCR和PDF输出独立结果，以便在外部创作中使用。
27. 我希望单张“设置桌面图片”等系统动作对合适类型可用，取消或不执行时不改变系统，以免选择菜单就产生副作用。
28. 我希望清空和移至新工作集只改变引用，多个窗口仍由同一Host管理，以免复制成第二个素材库。
29. 我希望自定义名称、窗口指示器/常显、固定及当前Space设置能保存恢复，以便管理多个窗口；指示器颜色只是窗口标记。
30. 我希望操作开始后范围和身份固定，失败、部分结果、取消和撤权有准确反馈，以免旧结果影响新工作集或被当作完整成功。
31. 我希望新尺寸、窗口标记和停靠重开后正确恢复，以便下次继续工作。
32. 我希望暂不接入云端账号、费用和原版云品牌菜单，以便本轮交付范围明确。

## Implementation Decisions

- 复用现有唯一Host、工作集控制器、AppKit原生子进程和独立大预览，不新增测试专用产品入口。AppKit负责窗口/胶囊/系统选择器；Host负责引用、修订、库/会话、文件任务与执行资格。
- 实施复核后使用Managed schema v16完成工作集字段迁移（准备阶段上限为15）。显式升级前建立并验证可恢复副本；事务中去除工作集note/colors_json及其有效读写契约，保留成员外键、排序、名称、修订、created_at、设备布局与其他表。版本/manifest只在有效提交后前进。备份不可用、磁盘失败、未知提交不盲重发、不删除旧库。禁止把只读打开改成清理；旧客户端拒绝新版本，不能重新引入退役字段。备份不是可继续编辑的“隐藏旧模块”。
- 清除全部工作集颜色/备注消费者，包括从素材配色/独立色板加入工作集的路径、原生浮层、草稿和冲突提示中的退役字段。保留素材Notebook及既有交付、图像处理、OCR权威。升级/编辑的会话、修订、权限、幂等和撤权检查保持。
- B数量档位以当前全部有效成员数量计算；不按展开所选数量缩水。原版≤2/3–5/≥6策略已由1/2/3/5/6/7图像实测支持。空紧凑窗是接入状态，展开胶囊隐藏；已展开时清空仍显示可接入的空网格并按最低档/屏幕约束结算，不让清空删除工作集或丢失焦点。混合支持素材按成员数归档，其类型渲染分别验收，不冒称已被PNG测试覆盖。
- 默认两列原生网格，素材按比例完整显示，容量外滚动。207pt可能小于220×240紧凑高度，“展开”表示内容呈现而不是宽高都单调增加。更新旧展开最小高度校验、布局恢复、固定前景尺寸和所有数量/列数消费者，避免Host拒绝原生实际终态。旧已保存展开尺寸归一化到当次档位，保留原始布局恢复材料。
- 数量调档与展开/收起共用锚点；屏内夹取不平移原紧凑关系。保存实际终态，不把动画中间frame写成用户尺寸；连续增减/反向切换/拖窗使旧运动和完成失效。维持已批准的180/230ms窗框、分段前景和160ms选择背景；数量调档不重建业务选择或素材笔记草稿。取消手动resize样式，拖动位置继续可用。
- 原版双击资格：距任一窗口边缘≤26pt、当前为紧凑且未拖出素材、未停靠覆盖接管，点击点不落在可见交互控件。本轮以该边缘背景作为精确对标；不为整个图片/按钮区域注册双击停靠。选择最近可用左右边缘，无可用边缘明确拒绝；零拖动速度的双击走0.3秒EaseOut，同一停靠运动/回执/抓手恢复路径。中部偏左和靠左已有真实移位后的限定对照，精确等距/多屏/触控板资格仍需补验，不能用静态推导关闭实体验收。
- 胶囊原版是原生自定义Control叠在整窗玻璃，不是独立NSGlassEffectView。使用公共AppKit/QuartzCore与系统颜色/材质，按高度一半圆角、低透明度轮廓、内高光、柔和阴影形成相同层次；保留上一轮系统窗口轮廓修复，禁止生产私有setter。短名称稳定；长名称双文本图层间隔12pt、15%两端渐隐、先停顿2秒，再按max(10秒,周期距离/20)与EaseInEaseOut向左滚动，完成接续。不可见/短名/名称变化撤销旧计划；减少动态效果静态显示名称并提供完整名称的可达替代。
- 本机菜单能力按实际支持类型/数量和系统服务生成，不复制机器上的应用名或原版错译。参考NSWorkspace、NSSharingService、NSOpenPanel/SavePanel及QLPreviewPanel；系统选择器是正式结果的一部分，系统内最终发送由用户决定。AirDrop网络关闭等失败不得自动改变网络/权限。
- 保留已有交付项，新增系统/文件/图像组，合并重复ZIP/图像处理入口。紧凑全部、展开所选优先，捕获目标集合后重验当前Library/Session/成员/actor/修订/撤权，不能因选择动画未完使用旧集合。任何复制/移动/改名/废纸篓/图像处理操作只拿Host生成的独立文件；路径复制同样复制可复用副本路径，不泄漏库内存储路径作为外部改动入口。
- 系统打开/分享交出的副本须有明确保留生命周期，实际进程/接收未确认不得清理；重复名称、目的文件已存在、取消/未知结果与部分成功分别处理。取消只承诺当前受控任务语义，不宣称系统服务或已产生的外部结果被事务回滚。原版本地动作可能部分成功/无法即时取消，这不是降低DAM保护的理由。
- 指示器颜色、常显、固定/Space是窗口元数据，严校验后按设备布局权威保存，独立于退役Work Palette；名称仍属于工作集。保持一个工作集一个窗口、数量上限、复开聚焦与退出保护。

## Testing Decisions

正式路径为B入口→指定公开库/工作集→原生点击/键入→适用真实Host/系统动作→实际结果→保存重开→取消/失败/撤权。内部接口/模拟依赖可验证契约与故障，不能替代原生路径。

| 验收接缝 | 必须证明 |
| --- | --- |
| 显式迁移与旧库打开 | 正式确认后升级；取消/只读无写；验证备份可恢复；成员/原件/Notebook/独立色板和其他库内容保持；事务故障/磁盘失败/未知提交不破坏旧库；旧客户端有兼容拒绝 |
| 数量与位置 | 0/1/2/3/5/6/7/更多、两种顺序与横/竖/方混合；中心/左右/上下夹取；增减跨档/立即反向；选择/滚动保留；实际终态经Host保存和正常重开 |
| 双击与中断 | 紧凑边缘26pt内/外、可见按钮/素材排除、左/右/中心、相邻屏拒绝；真实鼠标与触控板；停靠抓手恢复；新输入接管；旧回执拒绝 |
| 胶囊 | 短/长/边界名称、两端完整圆角、明暗材质、连续循环与停顿；隐藏/退休/改名/快速展开中断；减少动态效果/辅助显示与键盘可达，不按模型alpha冒称可见 |
| 系统与菜单 | 一张/多张/无选择/所选/空集/不支持类型的动态服务及数量；实际Quick Look、Finder/打开方式、分享选择器与取消；云项不出现可执行假入口 |
| 文件与图像结果 | 指定真实公开副本实际复制/移动/改名/ZIP/回收、标注/转换/压缩/元数据/拼接/OCR/PDF；真实内容/尺寸/可读产物、目的文件不覆盖、原件SHA保持；失败/取消/部分结果及并发改选择/切库/撤权 |
| 保存/生命周期 | 名称、成员、指示器、固定/Space、锚点/实际布局正常退出重开；任务未退出不假释放；有效草稿和原件保持；快速切换旧任务不覆盖新结果 |

最小相关测试后按风险扩大，修改测试执行，必要构建不跳过。物理多屏、Spaces、高帧率和完整输入矩阵没有证据时保持未验，不以测试数量或静态菜单存在关闭用户目标。

## Out of Scope

本轮准备不修改产品代码、清理实际库、发布Issue或自动推送。云账号/费用/上传服务、任意用户脚本、全局摇晃/刘海入口、浏览器任意文件/SQL/终端能力、原版服务端、对库内原件的直接移动/改名/删除不纳入本轮。

## Further Notes

原版当次展开7减5仍435、收起再展开才310；DAM即时调档是用户明确选定的差异。原版26pt区域、最近可用边与0.3秒双击运动属于静态机制，右侧实际路径已见；后续重新建窗并由用户真实拖到中部，已补证中部偏左→左停靠、左抓手恢复/再次停靠；精确等距、多屏与触控板仍未验。当前工具drag事件送达但deltaX/deltaY为0，不能据此声称原版不支持拖动。

2026-10-15关键菜单实际结果见[菜单补证](../../artifacts/reverse-engineering/dropover-5.2.0/second-alignment-20261014/menu-key-20261015/RESULT.md)：改名/重名取消、移动、ZIP、JPEG转换、缩放副本、PDF和Trash恢复已验证。原版重名可选择替换，DAM保留已批准不覆盖；PNG压缩配置称忽略不支持类型，DAM必须执行前明确资格与实际范围。成功操作配置会持久化，取消未提交配置不改变前次默认，须独立验证恢复。

完整菜单包含单张专属标注/桌面图片和不同系统服务，多项版本含拼接；因此菜单不是一份固定列表。系统Chooser取消/局部失败不得扩大权限或自动重试发送。正式规格落地前重新核对源码版本和新增原版证据，当前基线为98cace0。
