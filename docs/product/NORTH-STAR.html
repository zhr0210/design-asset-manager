Product North Star

让视觉创作者
记得住、找得到、用得快。

一个真正本地优先、由 AI 增强的视觉素材工作台：它理解图片、视频、版式、文字、颜色、镜头与创作上下文， 让设计师、剪辑师和编导从“我记得见过”直接抵达“就是这一份”。

本地优先，不默认上传 Eagle 式高密度资产体验 自然语言 + 以图搜图 + 关键词 AI 解释为何命中 原始素材永不被静默改动
NORTH STAR PROMISE

一批混乱素材进入后，十分钟内用一句自然语言找到想要的那一份。

不要求先建文件夹、不要求手工打标签、不要求理解模型或运行时。用户能看到结果为何匹配： 可能来自画面语义、OCR 文字、视觉相似、颜色、来源、时间、已确认标签或项目上下文。 如果 AI 尚未完成，产品仍以词法和元数据工作，并诚实显示覆盖范围。

10分钟
第一次“原来它真的懂我的素材”
Private Alpha 的首个成功，不是模型安装成功，而是创作者找回一个原本会丢失的创意线索。
Core loop

从采集到复用，一条完整闭环。

每个阶段都必须逐步可用。入库不等待所有 AI；AI 不抢走用户控制；检索不依赖某一个模型； 任何会改变素材、元数据或外部状态的动作都先预览，再确认。

01 / INTAKE

收进来

文件、文件夹、浏览器、剪贴板、拖放和后续插件统一进入安全 Intake。普通添加默认 Copy Into Library。

02 / UNDERSTAND

逐步理解

预览先可见，随后颜色、OCR、标签、短描述、embedding 各自完成；失败互不伪装成成功。

03 / DISCOVER

快速找回

关键词、自然语言、图片、颜色、构图、镜头和结构化条件汇入一个 Workspace 查询。

04 / DECIDE

比较判断

大图预览、候选对比、相似族、版本关系和为何命中，让选择来自证据而非黑盒排序。

05 / REUSE

带着上下文复用

原件交付、兼容导出、拖入创作工具、生成 Brief Pack；来源、许可和原始身份不丢失。

Who it serves

不是“管理图片”，而是保存创作记忆。

同一资产对不同职业意味着不同线索。产品以统一资产底座服务差异化工作流，而不是为每个职业复制一套应用。

从“素材仓库”升级为“创作记忆基础设施”。

这些方向建立在可靠 Intake、Discovery 和原始素材安全之上。它们值得大胆探索，但不允许抢跑成为 Alpha 依赖。

NEXT / HIGH POTENTIAL

Creative Memory Graph

连接资产、来源、相似族、项目、选择、拒绝、导出和实际使用。它回答的不只是“这是什么”，还包括“我为什么曾经喜欢它、在什么语境用过、和哪些东西一起出现”。

NEXT / HIGH POTENTIAL

AI 将 Brief 转成可编辑视觉意图与检索计划，产出候选板、依据、缺口和来源清单。成果是可操作对象，不是一段难以复用的聊天记录。

FUTURE / VIDEO

Time-aware visual search

视频不再只是“一个文件”。镜头、动作、台词、声音、时间码和情绪变化成为一等检索证据，可直接跳转到命中区间并比较相似节拍。

FUTURE / TRUST

Provenance-aware reuse

产品在交付时主动聚合来源、许可、生成/改写证据与缺失项。它不冒充法律顾问，但让创作者在错误发生前看到不确定性。

EXPLORE / AESTHETICS

Explainable Style DNA

用多个可解释维度表达品牌或项目风格：冷暖、留白、构图、排版密度、材质、镜头运动、节奏。用户可以纠正每个维度，而不是接受黑盒“像/不像”。

EXPLORE / AGENTIC

Reviewable Creative Agent

Agent 可以提出“整理这一批”“找出重复变体”“为这个 Brief 建候选板”的冻结计划，展示预计变化与证据；没有确认，它只有建议权，没有写入权。

AI capability strategy

模型会变，产品能力与证据契约不变。

不把“最佳 AI”写死为一个模型名。每个 capability 都有质量门、硬件档位、真实评测集、许可与资源预算； Adapter 可以替换模型，而 Workspace、索引和证据 Interface 保持稳定。

Locality

一个能力的规则、状态与测试放在同一领域附近。不要在 Renderer、Main、Worker 和 README 各保留一份不同事实。

Depth

调用方说“生成 embedding”或“导入这批素材”，不需要知道模型文件、临时目录、GPU probe 或 SQLite 语句。

Evidence

每个 AI 结果带模型空间、配方、来源 generation、覆盖与执行位置。UI 只投影必要证据，不制造确定性。

Original Safety

外部来源不是 cleanup target。Preview、normalized copy 与 export 不能冒充 Original；破坏性动作必须有独立授权。

Progressive Availability

素材先可见、再可词法搜索、再得到 OCR/语义/视觉增强。缺少模型不应让整个产品不可用。

One Commit, Two Profiles

Dev 与 Stable 来自同一 commit。Stable 用明确 runtime allowlist，不打包 ADR、测试、工具、缓存或私密本地内容。

Private Alpha

三十天，只证明一件事：它真的能帮人找回素材。

架构基线只占前三天；之后每一阶段都要交付可看见的产品纵切、自动验证、Git commit 和可回滚证据。

Truth and guardrails

未来可以大胆，事实必须克制。

这些规则比任何单一功能更重要。它们决定产品能否被视觉创作者长期信任。

原始素材

Copy 不等于 Move。 选中的外部来源始终保持不变。Reference 是高级显式模式。任何 rewrite、delete 或 ownership conversion 都是新的、独立确认的工作流。

AI 与云端

配置 provider 不等于同意上传。 默认使用本地能力；云端只服务当前披露的动作或批次，不记住隐形授权，不静默 fallback。

搜索与分类

Unsorted 是正常状态。 不打标签、不建文件夹、不接受 AI 建议，都不能让完整资产变成次等素材或阻塞检索。

AI 结果

建议不是事实。 保留 provenance、model space、coverage 和 confidence；模型更新或信任变化不能静默改写已经提交的用户状态。

开发事实

ADR Accepted 不等于 Implemented。 每个产品声明都要有当前代码、真实模型路径和聚焦测试证据；Runtime Probe 只能证明 probe。

产品优先级

长尾不能阻塞主循环。 Custom Field、复杂 Export、跨库、插件市场和高级来源操作保留设计位置，但必须在核心留存之后交付。
