## 2. Logic Chain

1. **R1 UI Wiring**: The `PlatformAiBranchStatusPanel` relies on `PlatformAiActionPlan` generated by `platform-ai-action-plan.workflow.ts`. Since the panel forwards `onAction(kind)` to the parent console tabs, any change in missing dependencies properly navigates the user to either the `models` tab (to download GGUF/models) or the `runtime` tab (to check Python setup).
2. **R2 Realization**: Integrating real local inference for `JoyCaption` and `Qwen-VL` requires passing the real Python inference worker tasks through `AiWorkerManager`'s subprocess providers. Since mock logic is routed via `joycaption.py` and `qwen_vl.py`, the real implementation should replace these mocks when actual models/backends are available.
3. **R3 Fail-Closed**: Setting `DESIGN_ASSET_MANAGER_STRICT_REAL_AI=1` triggers `guard_mock_inference()` in `mock_policy.py`, which correctly throws a `MockInferenceBlockedError`. In translation, this error is intercepted by `TagLocalizationService` which preserves tag localization flow by falling back to title-cased English tag structures labeled as `"localized_by": "fallback"`. This avoids silent degradation while maintaining UI integrity.
4. **R4 TTL Caching**: Probing models is expensive. The main process limits this by caching probe results for 5 minutes (`5 * 60 * 1000` ms) in `llama-multimodal-evidence.store.ts` and `ai-runtime.ipc.ts`, ensuring status updates are swift.

---

## 3. Caveats

- **External Backends**: We assume that if local GPU capabilities are missing or insufficient, the user will configure an OpenAI-compatible external URL which acts as the fallback route.
- **Dependency Paths**: The probe checks for module imports (`models.ram_tagger`, etc.) to infer dependency status, which assumes Python library availability represents active capabilities.

---

## 4. Conclusion

The codebase is fully equipped with structural pathways to implement the R1-R4 requirements:
- Navigation triggers in the UI Console are wired to redirect to specific setup screens depending on the missing capability details.
- Fail-closed constraints will correctly raise `MockInferenceBlockedError` in production settings, which triggers English translation fallbacks without crashing the background workflow.
- Evidence checks are properly cached for 5 minutes to prevent redundant subprocess spawns and network requests.
