## 状态词的统一解释

- **CODE**：当前正式调用链里有代码；不意味着用户操作或真实模型通过。
- **ISOLATED_PASS**：注明环境和替身的隔离检查通过；不能跨平台、跨版本借用。
- **CU_PASS(scope, build, client)**：对应构建/客户端/路径的可见操作证据。
- **REAL_PASS(tuple)**：准确的平台、依赖、模型/账号、动作和数据范围。
- **UNAVAILABLE / NOT_RUN / BLOCKED**：分别为实现不支持、尚未测试、工具/条件无法执行。
- **PARTIAL DELIVERY**：有限范围可以交接，但完整承诺仍然打开。

不要把这些维度合并成一个布尔 `verified` 或项目完成百分比。工作区可用、干净候选可构建、正式路径可执行、真实效果有质量，是四道不同门。
