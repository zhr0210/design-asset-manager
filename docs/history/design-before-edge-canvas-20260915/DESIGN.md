# Gallery & Glass — 素材工作台设计规范

2026-09-15。由用户最终确认的可交互原型反向整理，适用于正式 `/library` 与共享展示组件。
本文件定义产品表面、布局和交互；[mobbin.md](mobbin.md)提供同一设计的精确 token、材料和使用理由。
最新用户反馈优先；正式应用不能因已有组件或旧 ADR 使用另一套简化界面。

## 设计依据与边界

视觉验收基准是 `src/renderer/routes/work-mode-prototype/` 最后确认版本：四图标导航、
低底色无描边玻璃、灰色选择、可缩小的侧栏重排、专注硬切与图片笔记。原型中的样例数据、
模拟保存和浏览器窗口不构成正式数据能力。迁移的是展示和交互，正式数据由宿主适配。

参考素材的应用范围：

| 参考 | 采纳 | 不继承 |
| --- | --- | --- |
| 用户提供的 Eagle 导航截图 | 全部、分类、回收、标签等素材管理语义 | 已被后续反馈替换的宽树形主导航 |
| 用户提供的极简画布合成图 | 窄图标栏、底部搜索/标签、右侧尺寸滑条、内容优先 | 早期较厚玻璃底色和大滑条 |
| 用户提供的磨砂文件夹图 | 露出 2–3 张素材、半透明前盖、下方名称计数 | 外部图中具体品牌物件 |
| 用户标注的详情截图 | 预览下紧接配色占比，删除重复标题 | 浮动详情窗口、旧边框 |
| [mymind](https://mymind.com/) | 轻导航、视觉浏览与随时找回参考的方向 | 网站文案、专有图形和功能交付承诺 |
| [Google DESIGN.md](https://github.com/google-labs-code/design.md) | 机器可读 token 与用途说明并列 | 把格式示例当作本产品视觉要求 |
| Apple 材料设计方向 | 控制层与内容区分、克制半透明与背景模糊 | 宣称 CSS 等于原生 Liquid Glass 光学效果 |

历史截图仅在未被后来反馈替换的范围内使用。最新反馈明确取消网格动态模糊、专注渐变切图、
实色材料手动开关、主导航描边、图片描边、上下预览说明条默认展示。

## 产品表面

主流程：收进素材 → 渐进理解 → 找回并解释命中 → 检查比较 → 安全复用。
左侧从上至下为品牌/资料库入口、全部、文件夹、工作模式、回收站；底部为主题、设置。
普通文件夹、AI 文件夹、色板集中在文件夹页；工作集集中在工作模式，不恢复宽导航树。

| 页面 | 主内容 | 搜索与操作 |
| --- | --- | --- |
| 全部 | 当前库所有已支持格式的素材；模型未就绪不阻塞浏览 | 底部搜索、标签、随机、未标签、未分类、菜单 |
| 文件夹根页 | 普通/AI/色板的视觉文件夹；封面用真实成员引用 | 搜索文件夹名称；不适用的素材筛选禁用并说明 |
| 文件夹子页 | 与全部相同的素材网格；保持文件夹上下文 | 同一底部组件；前进/后退恢复目的地 |
| 色板页 | 按文件夹管理已收藏颜色；支持新建与选择目标 | 搜索颜色；不冒充素材原件 |
| 工作模式 | 保存的工作集、多素材参考窗口；成员移除不删除素材 | 参考查看/笔记/色板/复用；不承担库整理 |
| 回收站 | 与全部相同的内容和底部布局；恢复动作显式 | 名称/标签不在当前正式接口时禁用对应查询并说明，不能显示无效可用搜索 |

未实现的数据能力保留正确的视觉位置和说明，不能用“已有标签视图”冒充普通/AI 文件夹，
不能用单个原生卡片冒充多窗口工作集。新增功能的上线状态见模块 README，不由本表证明。

## 材料、颜色与字体

精确值统一从 mobbin.md 生成共享 tokens.css。搜索区浅/深底色为 40%/48%，
弹层 48%/58%，标签 27%/32%。此处百分比指不透明度：数值越小越通透。
搜索模糊 20px、饱和度 1.04；标签 14px/1.02；菜单 24px/1.02。
无装饰描边、内高光线或整块渐变底托；背景内容透过玻璃提供色彩。

选择状态用中性灰；图片胶囊文字约 80% 不透明，按真实底色/对比需要选深浅文本。
不要给所有标签固定黑字压在暗图上。作品图片保持自身颜色和比例。
系统字体优先，中文正文行高 1.6；系统色板/文件对话框不伪装为网页控件。
系统减少透明度或不支持模糊时提供可读实色回退，界面不提供手动实色切换。

## 交互与动效

- 单击图片打开右侧占位详情。保留数组顺序及原有列数，按剩余空间向小缩放；
  尽量保持选中项纵向视口位置。取消“绝对原位置和大小”的旧要求，避免留白与遮挡。
- 重排使用 200ms 位移/缩放，曲线 cubic-bezier(.2,.75,.25,1)，不使用动态模糊。
  侧栏从右侧 24px 滑入，200ms；显式密度调整清除旧尺寸锚点。
- 空格或双击进入专注模式；按打开时实际筛选与排序浏览，左右键、箭头按钮、缩略图等价。
  图片直接硬切，不保留淡出图片、不加 blur/opacity 动画。
- 点击多选圆点只改变选择；点击图片标签加入/取消筛选。取消顶部标签立即更新结果，
  播放约 420ms 胶囊消散/12 粒子动画；减少动态效果时直接移除。
- 菜单/筛选在点击外部或 Escape 时收起。颜色菜单支持右键、Context Menu、Shift+F10；
  左键复制 HEX，菜单提供复制、添加到选定/新建色板、添加到工作窗口。
- 详情顺序：预览 → 配色及占比 → 简要格式 → 素材理解和标签 → 提示词 → OCR/视频参考
  → 工作窗口与编辑动作。删除重复标题。没有分析结果时说明缺失，不显示演示分析。
- 开启高级标签、描述、AI、图片工具时保留现有行为与错误状态；不能让旧面板默认挤满新详情。
- 前进/后退保留目的地语义；普通文件夹和 AI 分类引用素材，不复制原件。

## 专注画布与笔记

| 输入 | 行为 |
| --- | --- |
| + / −、鼠标滚轮 | 放大/缩小，滚轮以指针位置为中心 |
| 0 / 1 | 适应居中 / 预览像素 1:1；只有拿到原件才可称原件像素 |
| 默认拖动 / 绘图时空格拖动 | 平移 / 临时平移，不落笔 |
| Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z | 当前页撤销/重做 |
| Delete/Backspace | 删除选中标注；输入控件保持文本语义 |
| Escape | 先取消文字编辑或收起便签，再关闭专注，恢复触发焦点 |

图片下方为原图、多张笔记页、末尾添加笔记。每页独立笔迹、名称和撤销记录，支持画笔、
矩形、椭圆、文字、便签、颜色/粗细、选择/删除。便签在图中显示编号点，点击展开文字。
图片和标注一起缩放平移；归一化坐标不改原图。视频绘图需参考帧，不能假装静态图片工具可编辑视频。
未提交文字/绘制中阻止切图或整体保存；保存失败保留草稿。正式保存须绑定素材和库权限；
会话草稿、原型浏览器保存、正式持久化分别标明，禁用的保存按钮必须有原因。

## 状态与验收

必须区分初次加载、空库、无匹配、首次失败、刷新失败但保留内容、预览不可用、库关闭。
切库/关库撤销旧请求和旧视图，不把失败伪装空库；底层权限、Copy、恢复约束继续生效。

验收分为两条同时成立的证据：

1. 视觉/交互：以修改前批准原型快照及共享组件为对照，同窗口、同合成素材、同主题比较。
   记录导航、卡片、文件夹、玻璃控件、侧栏、专注、笔记、菜单、明暗及缩窄状态。
   布局坐标差异目标 ≤1 CSS px；裁剪区域像素差异单独记录，不能以共享 CSS 本身宣称零差异。
2. 正式数据：Electron 实际入库、检索、预览、标签/描述编辑、错误恢复、关闭与重新打开。
   合成视觉适配器不是 Main/Preload 接线证据；真实链路通过也不等于视觉通过。

本规范不把仍未实现的文件夹/色板持久化、多原生窗口或任意格式解码标为已交付。
本轮实施状态和实际差异见 [对齐记录](docs/design/GALLERY-PARITY-20260915.md)。
历史入口保留追溯链接，不再携带有效的新界面像素规则；产品权限与原件保护没有被废止。
