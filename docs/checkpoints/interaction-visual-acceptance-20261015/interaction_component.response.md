2. **视觉检查**：从正常设置入口进入，检查删除后无空壳、异常留白、错位或溢出；字体、间距、层级和控件状态一致。覆盖适用宽度、明暗主题、长文案及相邻区域。设置仍占满主窗口，主页导航、工具条和素材搜索栏隐藏，返回入口清楚。
