# AI材料检索行为验证接线

2026-10-15用户采纳：供AI读取材料改变含义、适用范围或检索路径时按批次自动验证，纯排版做结构检查。生效方法归CONTRIBUTING的document-retrieval-validation，AGENTS写文档行提供触发导航，开发规范/工程专题链接方法；不在根入口堆完整协议。

## 实施与候选

本轮只改7份文档/任务/访谈记录，无产品代码/模型/资料变化。baseline.json及before保存修改前字节；acceptance-criteria.json是在派发前依据用户采纳内容及既有Host取舍写的独立判据，不给验证代理看。

candidate.json记录明确的独立副本和2300份第一方文档/源码文本身份。副本排除Git、当前TASK、原始用户要求、历史、研究、检查点/答案、生成/运行产物、模型缓存与用户配置/资料，不是完整可运行checkout。文件0444并给明确只读指令；实际工具没有OS沙箱强制限制，不能声称恶意写入被技术阻止。验证期间固定这些字节，结束检查未改写或新增内容。

三名子智能体均用fork_turns=none、gpt-6.1-sol、low。各自只收到普通任务、候选路径和只读/资料边界，没有期望文件/ADR编号、正确路径、评分答案或前序代理结论。两个代表/边界场景先派，第三个相邻普通方案研究单独制定既有取舍判据再派；它们不共享上下文。

## 场景与可观察证据

- 语义/检索批次：合并精简约束、术语、功能索引，定义与定位变化；检查是否自主找到触发/验证/写回规则。
- 纯排版边界：仅标点、空白/对齐且不改原意/入口/召回；检查是否正确避免额外行为探查和产品测试。
- 普通方案研究：评估窗口进程自行管理工作集保存、素材访问和交付；检查是否自主发现相关原文、区分可优化呈现与Host权威，不只复述新验证协议。

probe-sessions.json与各trace.json只保存本任务子会话的用户任务、可观察工具调用/返回和最终回答，以及实际模型/思考设置；没有隐藏推理记录。原始工具输出与最终自报分开，由主Agent按独立判据核对，不把“我读过”当证据。结论和实际限制见evaluation.json与delivery.json。

## 范围

通过只覆盖固定候选及实际探查场景；不证明所有未来模型/提示都会遵循，不代替代码独立审查或产品UI/真实推理/原生验收。流程按批次自动触发是Agent工作协议，不是后台daemon或定时服务。验证代理不能递归派验证代理；缺工具/子智能体要显式保留未验缺口。


## 本轮实际结果

三次均为PASS_SCOPED，按acceptance-criteria.json逐项核对工具调用及返回正文：

- 语义批次：3次只读工具调用，自主从AGENTS找到CONTRIBUTING完整协议，给出独立判据/冻结候选/不泄题/低思考新上下文/可观察轨迹/修复重验及检查点写回。
- 格式边界：3次只读工具调用，正确免除严格纯排版的额外子智能体探查，仍要求差异/适用结构检查；Markdown结构或含义变化须重新判断。一次无匹配搜索exit1被如实保留，未因此宣布无相关ADR。
- 方案研究：6次只读工具调用，沿任务/主题目录阅读ADR0485/0489/0491/0493原文、相关子系统/技术契约及针对性源码，识别唯一Host和原生呈现的分工，未把Accepted当产品验收。

实际设置已由各子会话turn_context核对为gpt-6.1-sol/low；fork_turns=none不继承编写会话。宿主仍提供正常根AGENTS和环境上下文，不能称完全无项目指令。子会话初始任务不在rollout里，dispatch-record.json单独记录主Agent派发任务及边界摘要；trace中的prompts为空不冒充没有收到任务。

候选2300个文件及其目录没有新增/缺失/变更，四份生效规范与候选字节一致；见candidate-integrity.json。格式探查读了指南1–190行，仍是限定指南/小型索引，未读全部ADR或raw元数据目录；这是本次路径观察，不能据此保证未来所有任务都能达到最短阅读量。

没有失败或需要修补的判据，本轮没有为了展示“微调”随意增加导航规则；repair/retest流程已写入协议，后续出现失败须实际执行并留原失败。本结果不是通过重复派同一知情代理刷绿，也不意味着每份历史文档都已经行为验证。

现行文档链接/锚点、既有迁移保全和context索引检查通过，见structure.json、migration.json、context.json。只改指引未改变执行算法，没有新写镜像测试/运行全产品检查。未启动应用/真实推理，不下载模型，不操作用户资料库，不提交/推送/发布。
