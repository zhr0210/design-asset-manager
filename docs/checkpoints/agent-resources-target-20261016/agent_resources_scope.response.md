应归独立的 **Agent资源与配置管理子系统**，目前是目标规划，尚未交付。不是素材库，也不应直接并入插件系统。

- **资源管理负责**：指令、SKILL.md及附带资源、Hooks声明、MCP配置的目录、来源、版本、适用目标、启用与分发记录。
- **素材库负责**：图片、视频、笔记、工作集与素材事务。
- **插件运行边界负责**：可执行代码、隔离、权限和生命周期。导入Skill或Hook声明不自动授权执行。
- **Host负责**：身份、凭据、文件与执行授权；AI系统负责连接、模型和推理。

当前基础是可复用的内部模块：`src/main/local-host/README.md`描述统一Host、命名Client、会话与持久化边界；`src/main/ai-gateway/README.md`描述连接、凭据白名单投影、受控推理、取消及资源准入。它们不是现成的资源管理API；Pi也不是Skill/插件执行器。

`docs/subsystems/agent-resources.md`明确：当前没有正式页面、Schema、分发器、实现文件、公开SDK或可运行闭环；项目AGENTS和开发者Skills只是开发工具，不能算产品已有功能。插件系统同样是目标规划。

方案首先要确定**仅供DAM内置AI使用，还是也向外部Agent分发**。前者需关联会话/任务；后者另需目标格式适配、自有写入记录、备份回读及撤销。建议首轮只选择一种资源、一个目标完成纵切，再扩充；遇到未知归属或解析失败须保留现有配置，不能按空配置覆盖。

只读核对了指定工作区内文档及相关模块说明，没有修改、联网或运行应用/模型/服务。
