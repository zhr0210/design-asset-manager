# 相关ADR读取时机归位

2026-10-15用户采纳：普通开发、排障、重构、测试和审查都按实际影响范围消费已有ADR；读取已有决定与新增ADR的条件分开。

## 当前行为

- AGENTS在工程任务行直接导航相关ADR，术语、文档维护、新取舍各自独立。
- CONTRIBUTING、开发规范、领域文档、ADR阅读协议及子系统审查同步要求核对有效状态、前提、明确替代范围与链接的详细契约。
- 出现冲突时写明ADR/条款、原因和变化前提；遵循最新明确用户决定及具体替代范围，不静默推翻，不扩大成逐内部接口审批。
- 新建ADR仍须同时满足有意义的反转成本、需要背景解释、存在真实取舍；读取没有这个门槛。Proposed/Historical与Accepted、实际交付分清。
- context:route仍提供有界ADR/contractReferences线索；预算延后或未命中不代表决定不适用，需按相关子系统/索引补查。不要求每次通读493篇。
