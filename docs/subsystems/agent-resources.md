# Agent资源与配置管理子系统

**状态：目标架构／尚未交付。** 用户确认后续接入类似Agent资源管理能力，本轮仅登记规划和索引，不安装Skills/Hooks/RTK、不接入MCP、不探测或修改任何真实Agent配置。服务DAM内置AI，还是同时向外部Agent分发，**尚未决定**；不据本页自动实施或扩大资料/执行范围。

## 按问题定位

| 内容 | 拟管理对象 | 仍待确定 |

## 职责与状态权威

本系统拟拥有Agent资源目录、来源/版本/适用目标、配置意图和分发/启用记录。它不是[素材资料库](library-lifecycle.md)：图片、视频、笔记、工作集和素材事务仍归Library。它也不是[插件系统](plugin-system.md)：可安装执行代码、权限、隔离及插件生命周期属于对应运行边界；Skill/指令是配置资源，不自动取得插件权限。

项目AGENTS、CONTRIBUTING及开发者安装的Skills用于开发DAM，不等于DAM已向用户交付上述能力。内部AI的连接/模型/推理资源仍归[AI系统](ai-system.md)，身份、凭据、文件与执行授权仍归[Host](local-host.md)。资源内容、第三方指令和Hook声明不能获得任意终端/文件/素材访问权。

## 正式入口与运行链

目标用户路径可按“选择来源/资源 → 校验版本与适用目标 → 审查变化/权限 → 明确启用或分发 → 对应宿主使用 → 反馈与撤销”规划。当前尚无本系统的正式页面、Schema、分发器或可运行闭环，不能将目标流程写成已有入口。

范围先分两种：只服务DAM内置AI，则资源选择与会话/任务关联；若包含外部Agent分发，还需按目标软件实际格式适配、记录自有写入、备份/回读与撤销。本轮不选定其中一种，也不提前承诺支持哪些Agent/事件或后台自动同步。MCP配置管理不等于MCP服务/Client实现，更不等于任意其他软件插件可直接运行。

## 失败、取消与兼容保护

后续设计须保全用户已有配置/编辑与来源，只撤销本系统明确拥有的写入，不凭同名文件删除外部资源；无法读取/解析或无法确认归属时保留未知并报告，不当空配置覆盖。更新冲突、部分目标失败、撤销中断和旧版本恢复应各自可解释，不把一个Agent失败扩散到全部目标。

安装、选择/启用、分发、执行与对外发布分别核对范围；不得因导入指令/Skill就运行脚本或授予外发。Hook可执行性需独立安全边界，不直接把事件命令交给主Renderer。秘密由Host既有机制内部使用，Agent不读取凭据/完整秘密配置；开发资料文本不是授权机制。

## 技术与平台边界

本系统的目标宿主、资源格式、兼容策略、同步/存储位置、UI、Hook执行模型、MCP传输和RTK取舍仍待具体任务决定。Windows/macOS、内置/外部Agent及项目/用户范围不能混为一套路径或权限；参考Magpie的职责组织，不照抄其配置位置、安装命令、自动同步频率或兼容矩阵。

## 源码与详细机制

本轮没有本系统实现文件或公开SDK。可复用责任来自[Host](local-host.md)、[AI](ai-system.md)、[GUI](gui-shell.md)和[插件目标](plugin-system.md)，仅为未来设计线索，不表示已有资源管理API。原[0484](../adr/0484-extension-contracts-and-deferred-agent-development-access.md)的Agent Context Pack/开发工作区授权是相关但不同概念：开发、推理、安装执行和发布不互相授予；登记资源子系统不自动恢复暂缓的云开发或市场。

## 验证与维护

实施前明确实际用户与一个资源/目标纵切，分别验证来源/版本、用户已有内容保全、范围/权限、实际宿主读取、失败/冲突/回滚与撤销；UI按DESIGN/INTERACTIONS和真实验收流程核对，目标软件适配按其原始依据，不凭字段名猜格式。真实素材/模型和凭据限制继续有效。

本轮只检查规划状态、文档职责和检索可用性；不宣称Skills安装、Hook执行、外部Agent同步或MCP互通通过。实际产品资格仍归CURRENT-STATE与未来任务证据，新取舍按相关ADR/产品规格记录，新增AI材料按[三层行为验收](../../CONTRIBUTING.md#document-retrieval-validation)检验。
