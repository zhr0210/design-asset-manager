## 职责与状态权威

插件系统的目标职责是公开版本化能力、发现/协商兼容、管理插件包及激活生命周期、在隔离边界执行，并将工具/UI贡献接入正式用户流程。详细贡献面仍以原契约和0484明确替代范围为准，本页只组织系统关系，不新建第二份SDK字段/权限Schema。

| 拥有者 | 插件可请求/提议 | 不下放的权威 |
| --- | --- | --- |
| [Host与系统集成](local-host.md) | 有范围的输入句柄、命名能力调用、任务/进度与取消 | 会话/来源/角色、授权/撤权、文件访问与实际进程/交付生命周期 |
| [资料库](library-lifecycle.md) | 元数据建议、派生素材/导出提案，经审查后提交 | 原件、人工内容、库身份/修订/事务与正式结果；不能直写SQLite |
| [AI能力与执行](ai-system.md) | 适用分析提供者、按既定服务/模型的受限调用 | 外发目的地、费用、资源准入、结果验证；插件包/模型制品/Runtime身份分开 |
| [GUI](gui-shell.md) | 已声明命令/面板等受限贡献 | 主Renderer/Preload权限与任意Store，不得伪造应用授权对话框 |
| 插件子系统（目标） | 清单/版本兼容、能力绑定、隔离单元、配额与生命周期记录 | 不取代上述业务/信任拥有者，也不开放通用终端/文件/SQL接口 |

基础标签、描述、OCR和确定性配色仍是核心能力，不要求用户先安装插件；录屏、专业处理等可选能力按产品范围选择。安装、激活、能力就绪与信任是独立状态，不能用一个enabled代表全部资格。

## 正式入口与运行链

以下为目标流程，不是当前可点击功能；具体首批插件、语言/运行单元、UI插槽、包格式和稳定兼容承诺仍须结合实际消费者确定，不在文档任务冻结。

1. **开发**：模板/Schema/类型/示例与测试 → 明确开发工作区 → 校验/打包。开发授权不默认包括真实库、凭据、执行生成代码或发布；外部AI开发连接器仍按0484暂缓范围处理。
2. **安装/更新**：用户选择来源/包 → 看兼容性与权限 → 完整校验与暂存 → 原子登记；失败保留旧版本。权限扩大的更新不能自动激活，签名不代替安全/质量验证。
3. **激活/执行**：用户动作或独立声明获准的后台条件 → 当前能力/授权/资源复核 → 隔离运行 → 受控输入与有界结果 → Host验证/审查/事务提交 → 回读与可理解反馈。结果“收到”和“正式保存”分开。
4. **禁用/撤权/卸载**：拒绝新准入 → 取消或收敛在途任务 → 等待实际终态 → 撤销注册/句柄。既有用户素材及归属明确的结果保留；插件缓存、用户创作数据和明确删除数据意图按契约分别处理。

### 协议与宿主边界

公共业务契约与传输解耦。MCP可作为工具/资源适配候选：DAM调用其他软件需要出站Client，其他软件调用DAM需要入站Server；带面板/预览/生命周期的插件还需要扩展运行时。MCP不自动提供运行时、推理API或授权引擎，不保证其他宿主插件原包直接运行，具体版本/传输留实施时核验。

可选命令、分析、声明式UI及Host审核的派生/导出提案见0484；不能把完整市场、计费、云开发、全部贡献面和旧候选语言矩阵当首个插件闭环的前置，也不能用此理由取消隔离/权限/数据保护。未来浏览器Producer不恢复已退休网页/素材下载执行器。

## 失败、取消与兼容保护

第三方代码不在Main/主Renderer/Preload以完整权限加载；独立进程本身不足以证明隔离。校验来源/权限、限制输入句柄、路径/网络目的地、并发/字节/时间/资源及结果大小；不把原件路径、凭据或内部IPC交给插件。对应细则见[0155权限](../adr/0155-extension-permissions-use-tiered-consent-and-update-reapproval.md)、[0156隔离](../adr/0156-third-party-extensions-run-in-isolated-execution-cells.md)、[0158撤销](../adr/0158-extension-revocation-is-risk-classified-and-non-destructive.md)。

授权/库代际/输入版本变化使旧句柄失效；任务取消/超时不等于插件进程退出或远端零费用，UNKNOWN不能盲重发或假释放。崩溃不能破坏Host/用户数据，卸载不抹去历史来源与已提交结果。稳定API承诺须明确兼容/迁移政策；首个稳定SDK之前标实验性，不虚构旧ADR的支持窗口已对外承诺，已实际发布的承诺仍须兑现。

## 技术与平台边界

插件代码包、数据型模型制品、可执行Runtime和外部工具服务各自有身份/信任/升级/资源生命周期，不因共用下载或JSON合并。普通扩展贡献、敏感权限、外发范围和开发工作区授权分别披露；一次可信审查可以包含多个明确授予，不要求重复弹窗。

Windows/macOS按实际目标验证安装/执行隔离、系统交付、取消/退出、UI及兼容性；Browser共享UI不替代原生行为。文档存在不授予下载/安装模型、启动服务或读取秘密；正式推理验收继续只用现有模型。
